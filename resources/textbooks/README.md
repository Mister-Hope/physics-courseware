# 教材库 — 人教版高中物理（Markdown 版）

> 人教版高中物理全套教材（必修三册 + 选择性必修三册）的 Markdown 化版本，供课件生成时**教材先行**使用。
>
> **核心约定：制作任何课件之前，先读对应章节，确保知识点顺序、公式符号、物理表述与教材完全一致。**

## 目录与命名

按分册分子目录（目录名即册名），每册内 `N-text.md`（正文）+ `N-question.md`（习题）：

```text
resources/textbooks/
  必修第一册/          1-text.md ~ 4-question.md     教材第 1–4 章
  必修第二册/          5-text.md ~ 8-question.md     教材第 5–8 章
  必修第三册/          9-text.md ~ 13-question.md    教材第 9–13 章
  选择性必修第一册/    1-text.md ~ 4-question.md     教材第 1–4 章
  选择性必修第二册/    1-text.md ~ 5-question.md     教材第 1–5 章
  选择性必修第三册/    1-text.md ~ 5-question.md     教材第 1–5 章
  README.md            本索引
```

编号忠实教材：必修三册全书连续（1–4 / 5–8 / 9–13），选择性必修三册各自从第 1 章开始；目录名已区分分册，同名文件不冲突。

```text
必修第一册        第 1–4 章   运动的描述 / 匀变速直线运动 / 相互作用 / 运动和力的关系
必修第二册        第 5–8 章   抛体运动 / 圆周运动 / 万有引力 / 机械能守恒定律
必修第三册        第 9–13 章  静电场及其应用 / 静电场中的能量 / 电路及其应用 / 电能 / 电磁感应与电磁波初步
选择性必修第一册  第 1–4 章   动量守恒定律 / 机械振动 / 机械波 / 光
选择性必修第二册  第 1–5 章   安培力与洛伦兹力 / 电磁感应 / 交变电流 / 电磁振荡与电磁波 / 传感器
选择性必修第三册  第 1–5 章   分子动理论 / 气体、固体和液体 / 热力学定律 / 原子结构和波粒二象性 / 原子核
```

## 使用与补充

制作课件时按课题定位分册与章节，读取 `N-text.md` 与 `N-question.md` 对齐知识点顺序、公式写法（如 $C=\frac{Q}{U}$、$\varepsilon_r$）与物理术语；教材中的"问题 / 思考与讨论 / 练习与应用"是"先问后答"的天然素材。补充新章节时把原文录入对应分册目录的 `N-text.md` / `N-question.md`（章节号遵循本册编号），并更新上表。
