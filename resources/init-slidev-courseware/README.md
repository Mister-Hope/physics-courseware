# 课件初始化工具 — 教师使用指南

> 这是一套**高中物理交互式课件**（不是 PPT，是能在电脑上放映、带动画和模拟实验的网页课件）。
> 本文件夹是给**完全不懂代码的教师**用的：你不需要会编程、不需要懂任何代码，只要会用微信聊天、会复制粘贴、会点"下一步"，就能让 AI 帮你做出一套令人惊艳的公开课课件。

---

## 一、这是什么？

这里有一套已经做好的**设计标准**（《电容器的电容》就是用它做的），AI 会照着这套标准，帮你做**你的**那节课——每个课件都会生成一个**独立完整的项目文件夹**，拷到任何电脑都能用。

- ✅ 像 PPT 一样放映，用键盘 ← → 或翻页笔翻页
- ✅ 有动画、有模拟实验（比如"平行板电容器"可以现场拖滑块看数据变化）
- ✅ 会生成配套的**教案**和**逐字稿**（上课说的每句话都写好）

**你全程需要做的只有三件事：**

1. **把一段话复制给 AI**（下方"三、如何开始"）
2. **回答 AI 的几个问题**（课题叫什么、哪个章节、你叫什么、哪个学校）
3. **用语音或文字讲一遍你的上课思路**（想到哪说到哪，不用写正式教案）

剩下的全部由 AI 完成。遇到任何问题，**直接截图发给 AI 问它**，它负责修。

---

## 二、开始之前

你只需要：

- 一台电脑（Windows 或 Mac 都行，需要能连网）
- 一个能上网的浏览器（Chrome / Edge 等）

> 至于 Node.js、终端、pnpm 这些名词——**你不用懂**。AI 会在需要的时候一步步带你装，你只需要照着屏幕点"下一步"或"允许"。

---

## 三、如何开始

### 第 0 步：装 VS Code 和 AI 助手（Windows / Mac 完全一样，只装一次）

需要两个免费软件：**VS Code**（工作台）和 **DeepSeek V4 for Copilot Chat**（AI 助手插件）。

#### ① 装 VS Code（免费）

1. 打开 <https://code.visualstudio.com/> ，点"Download"按钮下载（Windows 是 `.exe`，Mac 是 `.zip`）
2. 双击安装：
   - **Windows**：一路"下一步"，装完自动打开
   - **Mac**：把下载的 `Visual Studio Code` 拖进"应用程序"文件夹；首次打开若提示"无法验证开发者"，到"系统设置 → 隐私与安全性"里点"仍要打开"

#### ② 装 AI 助手插件：DeepSeek V4 for Copilot Chat（免费）

1. 打开 VS Code，点左侧最下方的**"扩展"图标**（四个小方块）
2. 在搜索框输入 `DeepSeek V4 for Copilot Chat`，找到**发布者为 Vizards** 的那一个，点"安装"
3. 装好后，左侧会出现一个**对话图标**（Copilot Chat），点开就是和 AI 聊天的地方

#### ③ 准备两个"通行证"（只准备一次）

**通行证一：GitHub 账号 + 免费的 Copilot**（这个插件要借 Copilot 的外壳才能工作，免费档就够）

1. 打开 <https://github.com/> 注册一个 GitHub 账号（免费）
2. 回到 VS Code，点左下角账户头像（或点对话图标里的"登录"），按提示登录 GitHub，并启用 **GitHub Copilot 免费版**

**通行证二：DeepSeek 的 API key**（AI 的"钥匙"，用它向 DeepSeek 付费）

1. 打开 <https://platform.deepseek.com/> ，注册并登录（手机号或邮箱）
2. 左侧菜单点 **API Keys** → **创建 API Key**，复制保存好（以 `sk-` 开头）
3. 给账号**充值一点余额**（AI 按用量扣费，很便宜；不充值会报"余额不足"）
4. 回到 VS Code，按 `Ctrl+Shift+P`（Mac 按 `Cmd+Shift+P`）打开命令面板，输入 `DeepSeek: Set API Key` 并回车
5. 把刚才复制的 `sk-` 开头的 key 粘贴进去，回车

> ✅ 设置好后，在 Copilot Chat 左下角的**模型选择器**里就能看到 **DeepSeek V4 Flash** 和 **DeepSeek V4 Pro** 了。推荐选 **Flash**（快又便宜，做课件足够）。

### 接下来

1. 在 VS Code 里打开本文件夹：菜单"文件 → 打开文件夹…"→ 找到 `init-slidev-courseware` 文件夹 → 选择
2. 点左侧的对话图标，在左下角模型选择器里选 **DeepSeek V4 Flash**（或 Pro）
3. **把下面这段话整段复制进对话，然后回车：**

```text
你好！我是一名高中物理教师，不太懂电脑和代码。请先读取本文件夹中的
spec.md 文件，那是我和我的助手约定的完整工作规范。

请严格按照规范执行：
1. 一步一步引导我完成从环境配置到课件制作的全过程；
2. 每个操作之前，先用一句人话告诉我"这一步在做什么、为什么、要多久"；
3. 遇到任何需要我操作的地方，给出非常具体的指引（我该点什么、该输入什么）；
4. 遇到报错不要让我自己排查，你分析后直接修复；
5. 我提供上课思路后，先复述确认，再开始做课件。

现在，请从第 1 步开始。
```

> 💡 第一次用时 AI 会先帮你把电脑环境配好（一次性，约 10–20 分钟，需要你配合点几下鼠标）。配置好以后，以后每次做新课都直接从"课件制作"开始，几分钟就能上手。

## 四、之后会发生什么（全程概览）

AI 会带你经历两个大阶段，每个阶段它都会先告诉你"要做什么、为什么、要多久"：

### 阶段一：环境配置（只做一次，约 10–20 分钟）

| 步骤 | 做什么                                       | 你需要配合的                          |
| ---- | -------------------------------------------- | ------------------------------------- |
| 1    | 检查你的电脑系统（Windows / Mac）            | 无需操作，AI 会自动检测               |
| 2    | 安装 Node.js（运行课件的基础）               | 打开网址，双击安装，一路"下一步/继续" |
| 3    | 安装 Git（给课件"存档"，改坏了能找回）       | 一般是点几下安装                      |
| 4    | 确认 AI 助手能用（DeepSeek 能对话）          | 点"允许 / Allow"（授权时）            |
| 5    | 安装辅助工具（读取你的 Word 教案等）         | 点几下安装                            |
| 6    | 建一个空的工作文件夹（你的课件会在这里生成） | 无需操作，AI 会建                     |

### 阶段二：制作课件（每节课一次，约 30–60 分钟）

| 步骤 | 做什么                                  | 你需要配合的                                  |
| ---- | --------------------------------------- | --------------------------------------------- |
| 1    | **教材先行**：AI 读教材原文             | 告诉 AI 是哪本书哪一节，并把教材拍照/复制给它 |
| 2    | **讲思路**：你用语音/文字讲这节课怎么上 | 像跟同事聊天一样讲就行                        |
| 3    | AI 复述你的思路，你确认"对"或提修改     | 说"对"或补充                                  |
| 4    | AI 生成幻灯片草稿，你可以预览           | 看一遍，指出哪里不满意                        |
| 5    | 逐页打磨：AI 主动自查 + 你提意见        | 说出你的想法即可                              |
| 6    | 生成教案、逐字稿，构建成品              | 验收                                          |

## 五、遇到问题怎么办？

**什么都不用懂，记住一句话：遇到任何看不懂的、报错的、不想要的，截图发给 AI，说"这是怎么回事 / 帮我看一下 / 我想要 XX"。**

| 你可能遇到的情况                    | 该怎么做                                  |
| ----------------------------------- | ----------------------------------------- |
| 屏幕上弹出一个"允许 / Allow"的提示  | 点"允许"（这是 AI 在请求操作权限）        |
| 有一堆红字报错                      | 截图发给 AI："这报错了"                   |
| 课件里公式显示成 `$C=Q/U$` 这种乱码 | 告诉 AI："第 X 页公式没显示出来"          |
| 点页面中间翻不了页                  | **这不是坏**，用键盘 ← → 或翻页笔翻页即可 |
| 不知道课件放哪了                    | 问 AI："我的课件文件在哪里？"             |
| AI 做的事和你想要的不一样           | 直接说："我想要的是……" AI 会改            |

## 六、常见疑问（FAQ）

**Q：我完全不懂电脑，真的能做吗？**
能。这套流程的设计前提就是"使用者零代码经验"。你只负责说话、点鼠标、确认，AI 负责全部技术活。

**Q：做一次课件要多久？**
环境配置第一次约 10–20 分钟（以后不用再配）。每节课的课件制作约 30–60 分钟，其中大部分时间是你在讲思路、AI 在写。

**Q：做出来的课件能在大教室用吗？**
能。课件字号特意加大（教室后排也能看清），用键盘或翻页笔控制，带模拟实验和动画，适合公开课。

**Q：我能改课件内容吗？**
随时可以。你只需要用嘴说"我想把第 X 页改成……"，AI 帮你改。不用自己碰文件。

**Q：换一台电脑还能用吗？**
能。课件项目是保存在你电脑上的文件夹，拷到新电脑、重新配置一次环境即可（或让 AI 帮忙）。

**Q：这个文件夹里的 `spec.md` 是什么？**
是给 AI 看的"工作手册"，详细规定了它该怎么带你一步步走、什么能做、什么不能做。你不用看它，AI 会自己读。

**Q：这套东西需要花钱吗？**
VS Code 和 DeepSeek 插件都**免费**。需要花钱的只有两处：① GitHub Copilot 用**免费版**就行；② DeepSeek 的 API 按用量扣费，很便宜（做一次课件通常几毛到几块钱）。用之前需要先给 DeepSeek 充一点余额。
