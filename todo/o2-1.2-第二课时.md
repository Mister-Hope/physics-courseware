### P-新2 回顾：本课要用的三个式子
- `F_{\text{洛}} = qvB\sin\theta`（方向：左手定则；`v \perp B` 时 `F = qvB`）
- `r = \dfrac{mv}{qB}`（洛伦兹力提供向心力：`qvB = m\dfrac{v^2}{r}`）
- `T = \dfrac{2\pi m}{qB}`（`T` 与半径、速度无关）
- 一页讲清"这三个式子是本节所有题的**工具**"，不重复推导（推导在第 20/21 页）。

### P-新3 比荷 `q/m`（荷质比）
- 定义：电荷量与质量之比 `\dfrac{q}{m}`，表征粒子本身的固有属性。
- 由两个式子反解：`\dfrac{q}{m} = \dfrac{v}{Br}`、`\dfrac{q}{m} = \dfrac{2\pi}{BT}`。
- 意义：同种磁场下，"转得多快、半径多大"只由比荷与 `B` 决定 → 测出 `r`（或 `T`）就能算出比荷（1.4 质谱仪的原理，可作伏笔，不展开）。
- 量级参考（课堂示例，非教材原文数值）：电子 `≈ 1.76\times10^{11}\ \text{C/kg}`、质子 `≈ 9.6\times10^{7}\ \text{C/kg}`、`\alpha` 粒子 `≈ 4.8\times10^{7}\ \text{C/kg}`。
- 建议配一张小图（同一位形、同 `B` 下不同比荷 → 半径/周期不同）。

### P-新4 结论：轨道平面垂直于 `B`
- 论证链（教材 §1.3 的口径）：`F \perp v` 且 `F \perp B` ⟹ 力始终在垂直于 `B` 的平面内 ⟹ 速度也不离开该平面 ⟹ **粒子在垂直于磁感线的平面内做匀速圆周运动**。
- 配图：需要空间关系示意图（`v`、`F`、`B` 三者的方向 + 轨道所在平面）。

### P-新5 解题思路：作三角形（单独一页）
- 四步：**① 找圆心**（洛伦兹力指向圆心 ⟹ 圆心在垂直于 `v` 的直线上；两条这样的直线/一条直线加弦的中垂线定圆心）→ **② 画轨迹**（圆弧）→ **③ 求半径**（几何关系：弦长、弦切角、圆心角、勾股）→ **④ 确定圆心角**（对应时间 `t = \dfrac{\theta}{2\pi}T`）。
- 配图：一张"弦—半径—圆心角—弦切角"的几何关系图（标出 `\theta` 与圆心角的关系：圆心角 = 2 × 弦切角）。
- 这一页是**方法页**，不写具体题目。

### P-新6 例题 1（求 `B`）
**题干（干净呈现 + 干净题目图常显，点击后才出解答标注）**
> 一个带负电的粒子，比荷为 `\dfrac{q}{m}`，从坐标原点 `O` 沿 `x` 轴正半轴方向以速度 `v_0` 射入，磁场垂直纸面向里。粒子经过第四象限内的点 `P`，`OP` 与 `y` 轴夹角为 `\theta`，`OP = L`。求磁感应强度 `B`。

**解答要点（供教师核对）**
1. 带电性/方向自洽：`v` 沿 `+x`、`B` 向里 ⟹ `F = q(v\times B)` 方向**向下**（电子带负电）⟹ 轨迹确实落在 `x` 轴下方（第四象限）✓
2. 找圆心：圆心在过 `O` 且垂直于 `v` 的直线（即 `y` 轴）上，且在 `O` 下方，设 `C = (0, -r)`。
3. 几何：`P` 在第四象限，`OP` 与 `y` 轴夹角 `\theta` ⟹ `P = (L\sin\theta,\ -L\cos\theta)`；由 `|CP| = r`：
   `L^2\sin^2\theta + (r - L\cos\theta)^2 = r^2` ⟹ `L = 2r\cos\theta` ⟹ **`r = \dfrac{L}{2\cos\theta}`**
   （更快：取 `OP` 中点 `M`，`\triangle OMC` 中 `\cos\theta = \dfrac{L/2}{r}`，即"作三角形"）
4. 由 `r = \dfrac{mv_0}{qB}` 得 **`B = \dfrac{2mv_0\cos\theta}{qL} = \dfrac{2v_0\cos\theta}{(q/m)L}`**
5. 圆心角 = `2\theta`（弦切角 `\theta` 的两倍）；经过时间 `t = \dfrac{2\theta}{2\pi}T = \dfrac{\theta}{\pi}\cdot\dfrac{2\pi m}{qB}`（可作为追问，非本题所求）

### P-新7 例题 2（求比荷 + 判断电性）
**题干**
> 第一象限内有垂直纸面向里、磁感应强度大小为 `B` 的匀强磁场。一个粒子从 `y` 轴上的点 `(0, a)` 沿 `x` 轴正半轴方向以速度 `v_0` 射出，经过 `x` 轴正半轴上的点 `(b, 0)`。求粒子的比荷 `\dfrac{q}{m}`，并判断粒子带什么电。

**解答要点（供教师核对）**
1. 电性：粒子从 `(0,a)` 向右运动、轨迹向下弯 ⟹ 洛伦兹力**向下** ⟹ 由左手定则（`B` 向里、`F` 向下）可判出等效电流方向向右，故**带的电荷为负电**（也可用 `F = qv\times B`：`v` 沿 `+x`、`B` 沿 `-z` ⟹ `v\times B` 沿 `+y`，要 `F` 向下必须 `q<0`）。
2. 找圆心：圆心在过 `(0,a)` 且垂直于 `v` 的直线（即 `y` 轴）上；设 `C = (0, y_0)`，则 `r = a - y_0`。
3. 几何：`(b,0)` 在圆上 ⟹ `b^2 + y_0^2 = r^2 = (a - y_0)^2` ⟹ `y_0 = \dfrac{a^2 - b^2}{2a}` ⟹ **`r = \dfrac{a^2 + b^2}{2a}`**
4. 由 `r = \dfrac{mv_0}{qB}` 得 **`\dfrac{q}{m} = \dfrac{v_0}{Br} = \dfrac{2av_0}{B(a^2 + b^2)}`**，粒子**带负电**。
5. 轨迹始终在第一象限（起点 `(0,a)` → 终点 `(b,0)`，`x` 从 0 增到 `b`、`y` 从 `a` 降到 0）——与"磁场在第一象限"自洽，可让学生自己核对。
