## 一·五、接手前先知道这 4 个坑（本轮踩过）

1. **frontmatter 陷阱（最坑）**：分隔符 `---` 与 `clicks: 3` 之间**多一个空行**，Slidev 就不把它当 frontmatter → 多出一个空白页，还把 `clicks: 3` 当正文渲染。**`pnpm slide` 检测不出来**（它解析更宽松），必须用浏览器数页数：
   `node courses/o2-1.3-charged-particle-motion/.temp/probe-pages.mjs`（改了端口要改脚本里的 BASE）。

4. **`pnpm shots` 的页码 = 幻灯片真实页号**：一旦出现"页号与内容对不上"，几乎一定是坑 1（多出空白页），别怀疑截图工具。

## 四、两道例题的验算（供核对）

### 例 1（求 `B`）：带负电粒子，比荷 `q/m`，从 `O` 沿 `x` 轴正半轴以 `v_0` 射入，磁场垂直纸面向里；经过第四象限的点 `P`，`OP = L`，`OP` 与 `y` 轴夹角 `\theta`

- 电性/方向自洽：负电 + `B` 向里 + `v` 沿 `+x` ⟹ `F` 向下 ⟹ 轨迹在 `x` 轴下方（第四象限）✓
- 圆心在 `y` 轴上、`O` 下方：`C = (0, -r)`
- 取 `OP` 中点 `M`，`\triangle OMC` 中 `\cos\theta = \dfrac{L/2}{r}` ⟹ **`r = \dfrac{L}{2\cos\theta}`**
- **`B = \dfrac{mv_0}{qr} = \dfrac{2mv_0\cos\theta}{qL} = \dfrac{2v_0\cos\theta}{(q/m)L}`**
- 圆心角 = `180° - 2\theta`；经过时间 `t = \dfrac{180°-2\theta}{360°}T`（可作追问）

### 例 2（求比荷 + 判电性）：第一象限内有垂直纸面向里、大小为 `B` 的匀强磁场；粒子从 `(0, a)` 沿 `x` 轴正半轴以 `v_0` 射出，经过 `x` 轴正半轴上的 `(b, 0)`

- 轨迹向下弯 ⟹ 洛伦兹力向下；`v` 沿 `+x`、`B` 向里 ⟹ **带负电**
- 圆心在 `y` 轴上：设 `C = (0, y_0)`，`r = a - y_0`；由 `b^2 + y_0^2 = r^2` 得
  `y_0 = \dfrac{a^2 - b^2}{2a}`，**`r = \dfrac{a^2 + b^2}{2a}`**
- **`\dfrac{q}{m} = \dfrac{v_0}{Br} = \dfrac{2av_0}{B(a^2 + b^2)}`**，粒子带负电
