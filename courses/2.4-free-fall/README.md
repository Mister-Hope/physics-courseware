## 授课提醒

- **实物环节**：讲台上真的拿两张同样大小的纸（一张平铺、一张揉成紧实纸团）和一个小铁球比一比；能借到牛顿管最好，没有就用第 5 页的组件代替（**默认是"有空气"**，先看直觉、再点"已抽成真空"推翻它）。
- **第 3 页是本课的教学引擎**：不急着讲公式，先让学生自己把"捆在一起会更快还是更慢"想出来，再点出两条推论打脸——**每一步点击都要停下来等学生回答**。
- **第 5 页组件有"慢放 ×5"按钮**：真实下落只有 0.49 s，后排看不清就点慢放（物理时间与位置关系不变，只是播放速度）。
- **第 6 页是伽利略的真实思路**（原第 6、7 两页已合成一页）：涂油光滑斜面 → 测出 $x \propto t^2$ → 由 $x \propto t^2$、$v_0 = 0$ 推出 $v \propto t$ → 外推到 90° 就是自由落体。**不要用"点距变大 ⇒ 速度均匀增大"那套推理**。
- **第 8 页是 $g$ 的引入方式**：先测出加速度、发现**与物体无关、只与地点有关**，再把"这个确定的加速度"定义为自由落体加速度 $g$。
- **第 9 页只做结论性科普**：赤道小、两极大，海拔越高越小；**不引入自转离心效应与万有引力**。
- **第 11 页是"答题卡"**：请学生先在纸上画五幅图，再用第 12–16 页一页一幅对照（**每幅图先点击出图、再点击出分析**）。
- **第 19 页给竖直上抛的定义与公式**（向上为正），并说明"取向下为正"时同一套式子怎么写——第 20–23 页四幅图用的就是"向下为正"的约定。
- **第 20–23 页的四幅上抛图全用符号**：刻度与关键点坐标都写成 $v_0/g$、$v_0^2/(2g)$、$2v_0$、$g$，图上**不出现任何数值**（已知量只有 $v_0$ 与 $g$）。四幅图都**画到 $t=3v_0/g$**——抛出点可以很高（阳台、楼顶），球会落到抛出点以下，图线不能停在"回到抛出点"，这一段用青色画出来并标"抛出点以下"。
- **第 24–28 页是四道例题**：① 最后一段不是从静止开始（$A$、$B$ 间 $h_0$、$t_0$ 求 $H$，右侧配 O→A→B 分段示意图）② 绳断的惯性（直升机 10 m/s、球 3 s 落地，问最高点/落地速度/直升机此时高度）③ 相遇时速度大小相同（五问，含路程比 $1:3$；先一口气出五问，再逐条出计算与结果）④ 阳台抛球（距抛出点 15 m 的三个时刻，右侧配示意图）。
- **第 25 页的易错点**：绳断瞬间小球速度**不是 0**，而是向上 10 m/s；"直升机此时的高度"要看清是**断绳时（15 m）还是球落地时（45 m）**。
- **第 29 页只做课堂小结**：两个定义 + 两套公式；**不留课后作业**（作业按配套练习册）。
- **先问后答**：几乎每页都是"提问 → 点击出图/出结论"，初始态只有提问是有意为之（不是留白 bug）。

## 本课特有的工程约定

- 版面用 **`.page-grow`**（共享 addon 的 `workspace/shared/styles/layout.css`）：`h1` 固定在上方，正文在剩余空间里垂直居中 + 统一 `gap`。
- **本课信息密度最高**：通用原子是"一份源码、各课同一套值"，本课只在自己的 `:root` 里把行间距收一档（`--page-gap: 0.7rem`、`--stack-gap: 0.7rem`）。这是实测出来的值：不收会出现"正文顶到标题上"（E2E 的"正文越界"表抓到过 9–36px）。**要放大字号/间距就必须同时拆页**。
- **`.key`（左侧彩色竖线）一页最多一处**，只给这一页的落点用；并列条目、公式、叙述一律用 `.line`；例题的多个小问用 `.qa-split` + `.qa`（左列问题）/ `.qa-a`（右列计算与结果）。
- **例题页右侧示意图**：第 24、28 页用 `.split-fig`（左栏文字收窄、右栏 `.fig-side` 放定高示意图，SVG 走 `height:100%` + `width:auto`），对应组件 `FreeFallSegmentSvg` / `ThrowDistanceSvg`。
- **伽利略斜面是同一个交互装置** `<GalileoInclineDemo />`（第 6 页）：拖滑杆改倾角 θ（15°–90°）、点按钮换球（木球/铜球/铁球）；讲"外推到 90°"时把滑杆直接拖到右端。图里几何严格按 θ 画——球心沿斜面法线偏一个半径（贴着斜面，不是串在线上）、θ 圆弧与标签都画在夹角内部；θ = 90° 时斜面立成竖直并给出"自由落体"提示。
- **符号与单位一律走 LaTeX**（教师反复强调，见 `AGENTS.md` 四·八节）：HTML 里用 `<Latex tex="…" />`（写 `v_0` 不写 `v₀`，写 `\text{m/s}^2` 不写 `m/s²`）；**SVG 里嵌不了组件**，所以用 `font-family="KaTeX_Math"`（量，斜体）＋ `font-family="KaTeX_Main"`（单位与数字，正体）。
- **单幅图组件接口**：`<FreeFallGraphs chart="a-t" />`（`a-t` / `v-t` / `v²-h` / `h-t` / `v-h`，默认 `v-t`）、`<VerticalThrowGraphs chart="a-t" />`（`a-t` / `v-t` / `x-t` / `v-x`，默认 `v-t`）。图页用 `style.css` 的 `.graph-box`（定高，SVG 用 `height:100%` 主导尺寸）或 `.fig-full`。
- **坐标图用"固定坐标范围 + 真实公式算出来的曲线"**：范围写死，纵轴映射分两种（`mapY` 数值越大越高、`mapDown` 数值越大越低，后者给"向下为正"的 $x-t$ 图）；**坐标轴不自适应参数**（第 20–23 页干脆没有参数、没有滑块）。
- 组件里的数值一律由真实公式在 `computed` 里算：$h=\frac12gt^2$（牛顿管）、$x=-v_0t+\frac12gt^2$（上抛四图采样）、相遇模型 $v_{B0}=2v$、$H_A=H_{B\max}=\frac{2v^2}{g}$；$g$ 取 $10\ \text{m/s}^2$（教材"粗略计算"）。
- 正文里 HTML 块中的公式一律用 `<Latex tex="…" />`；`<v-clicks>` / `<v-click>` 与它们的子块必须顶到第 0 列（缩进 4 空格会被 markdown 当成代码块，整页 500）。
- 校验：`E2E_COURSE=2.4-free-fall pnpm exec playwright test e2e/layout-overflow.spec.ts`（四类检查：溢出画布 / 底部留白 / 点击位移 / 正文越界）。
