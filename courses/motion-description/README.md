# 质点与参考系·时间与位移 — 公开课交互式课件

> 高中物理公开课课件 | 人教版必修一 §1.1–1.2（第一章 运动的描述）| 东北育才学校
>
> 在线地址：**[https://courseware.mister-hope.com/motion-description/](https://courseware.mister-hope.com/motion-description/)**

## 项目简介

基于 [Slidev](https://sli.dev/) + Vue 3 构建的交互式公开课课件，面向大教室（50+ 人），课题《质点与参考系·时间与位移》（高一开学第一章）。

**不是 PowerPoint 的平替——是用 Web 技术重新思考"什么是令人惊艳的课件"。** 玻璃态卡片、平滑页面过渡、4 个物理交互组件、完整的授课逐字稿。

## 快速开始

```bash
pnpm install
pnpm dev:motion-description
```

浏览器打开课件地址，使用键盘 **← →** 或翻页笔翻页。

## 交互式组件

| 组件                 | 功能                                                        |
| -------------------- | ----------------------------------------------------------- |
| `ParticleJudge`      | 质点判断题：6 个情境，先猜后判，逐条揭示理由                |
| `ReferenceFrameDemo` | 参考系切换演示：地面（乘客随车运动）/ 车厢（乘客静止）      |
| `TimeAxis`           | 时间轴：显示时刻（点）与时间间隔（线段）                    |
| `DisplacementLine`   | 一维位移计算：拖动 $x_1$/$x_2$ 滑块，实时 $\Delta x$ 与方向 |

## 设计系统

- **玻璃态卡片**：`backdrop-filter: blur(16px)` + 半透明背景
- **深蓝渐变背景**：`#090d1a → #0c1122 → #0f1425`
- **暖金 `#e2a846`** + **深蓝 `#3b82f6`** 双强调色
- **基础字号 22px**，教室后排清晰可读
- **系统字体栈**（不依赖 Google Fonts）
- **封面渐变标题** + 亮度呼吸动画

## 技术栈

- [Slidev](https://sli.dev/) — 演示文稿框架
- Vue 3（Composition API + `<script setup>`）
- KaTeX — LaTeX 数学公式渲染
- MDI（Material Design Icons）— 图标系统
- UnoCSS — 原子化 CSS
- `pnpm` — 包管理

## 项目文件

```
slides.md              — 主课件（25 页 Markdown + HTML）
style.css              — 本课特有样式（通用设计系统见 shared/）
global-top.vue         — 顶栏薄壳：<CourseTopBar chapter="…" section="…" />
global-bottom.vue      — 底栏薄壳：<CourseBottomBar />
components/            — 4 个交互式 Vue 组件（自动注册）
content/
  思路.md              — 课程设计思路
  教案.md              — 公开课教案
  逐字稿.md            — 25 页完整逐句台词
```

> 顶栏、底栏、通用设计系统和学校 logo 均来自项目根的共享 addon（`shared/`），通过 `slides.md` headmatter 中的 `addons: [../shared]` 自动加载，详见 [shared/README.md](../../shared/README.md)。
