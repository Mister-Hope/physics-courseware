# 教案：质点与参考系·时间与位移

> 人教版必修第一册 §1.1《质点 参考系》+ §1.2《时间 位移》｜高一开学第一章

## 教学目标

### 知识与技能

1. 理解质点的概念，知道质点是理想化的物理模型
2. 能根据研究的问题判断物体能否看成质点
3. 理解参考系的概念，知道运动是绝对的、描述是相对的
4. 能区分时刻与时间间隔，知道时刻用点、时间间隔用线段表示
5. 理解位移的概念，会求一维直线运动的位移 $\Delta x = x_2 - x_1$，能区分位移（矢量）与路程（标量）
6. 了解位移—时间图像（$x$-$t$ 图像）的意义及测量位移和时间的常用方法

### 过程与方法

1. 通过雄鹰、足球、地球公转、列车等具体情境，经历"简化"思维过程，体会建立物理模型的方法
2. 通过质点判断题、参考系切换、时间轴、位移计算器等交互演示，经历观察、判断、归纳的探究过程
3. 通过北京→重庆一例，体会"位移与路径无关"的矢量思想，建立矢量与标量的初步认识
4. 通过交互式一维位移计算，体会用坐标系定量描述物理量的方法

### 情感态度与价值观

1. 体会"描述运动"从直觉到科学的演进，感受物理概念建立的必要性
2. 通过北斗导航、打点计时器等内容，体会物理与生活、科技的联系
3. 树立运动观：运动是绝对的，静止是相对的；避免"经验直觉"代替科学分析

## 教学重点

1. 质点的概念与判断方法（能否看成质点由研究的问题决定）
2. 参考系的概念与运动的相对性
3. 时刻与时间间隔的区别
4. 位移的概念与一维直线运动位移的计算

## 教学难点

1. 质点"理想化模型"的建立——如何根据研究问题取舍次要因素
2. 参考系的选择与同一运动在不同参考系下描述不同的理解
3. 位移（矢量）与路程（标量）的本质区别

## 教学过程

### 一、引入：如何描述物体的运动？

展示汽车、雄鹰、足球三种常见运动，提问"要准确描述它们的运动，难在哪里"。

学生讨论后归纳：任何物体都有大小和形状，物体各部分的运动情况一般说来并不一样。由此引出"如何化繁为简"的问题，进入质点学习。

### 二、质点：化繁为简的智慧

**情境分析**（先问后答）：雄鹰身体向前、翅膀上下；足球向前滚动、还在转动。结论：如何描述要看关注的问题——有时关注各部分，有时只关注整体。

**能否看成"点"**：地球绕太阳公转（直径仅约为地日距离的万分之一，大小可忽略）；列车在平直轨道行驶（只关注整体运动，忽略传动与车轮）。归纳"简化为点"的两个条件。

**定义**：忽略物体的大小和形状，把它简化为一个具有质量的点，这样的点叫作质点。强调质点是理想化的物理模型——突出问题的主要因素，忽略次要因素。

**思考与讨论**：香蕉球能否看成质点？（不能——旋转与径迹和形状有关）；研究什么样的问题可以？（只关心整体径迹时）。

**交互巩固**：用质点判断题组件，6 个情境学生先猜后判，教师点评，明确"能否看成质点由所研究的问题决定"。

### 三、参考系：运动是相对的

**情境引入**：列车中乘务员与旅客，车外人看是运动的、彼此看是静止的。提问"为什么看法不一样"，引出"描述运动要相对其他物体"。

**概念建立**：运动是绝对的（一切物体都处于永恒运动中）；运动的相对性（描述位置随时间变化总是相对于其他物体）；参考系的定义。

**交互演示**：切换参考系组件——地面参考系（树静止、乘客随车运动）vs 车厢参考系（列车静止、乘客静止、树后退），直观感受相对性。

**选择原则**：参考系可以任意选择；选取得当使研究简洁方便；通常以地面为参考系。强调：凡是提到运动，都应弄清相对哪个参考系。

### 四、时间：时刻与时间间隔

**过渡**：要描述位置随时间的变化，需要"位置"和"时间"两个概念。

**问题驱动**：上午 8 时上课、8 时 45 分下课——"8 时""8 时 45 分"与"45 min"有什么不同？归纳：时刻是瞬间（时间轴上的点），时间间隔是一段持续（两点间的线段）；"时间"一词要依上下文判断。

**交互演示**：时间轴组件——显示时刻（两个点）与显示时间间隔（高亮线段 + 45 min）。

### 五、位置与位移

**坐标系描述位置**：定量描述位置需要在参考系上建立坐标系。直线运动用一维坐标系（原点、正方向、单位长度）。长安街例子：正方向指东，$+30 \text{ m}$ 在岗亭以东、$-20 \text{ m}$ 在岗亭以西。

**北京→重庆**：三种交通方式，先问"哪种位置变化最大"，再归纳：路程（轨迹长度）随路径不同而不同，位置的变化相同——由初位置指向末位置的有向线段能准确描述位置变化。

**位移定义**：初位置指向末位置的有向线段叫作位移，用 $l$ 表示。位移是矢量（大小 + 方向）；路程、温度是标量。位移只与初末位置有关，不因路径而变。

**交互计算**：一维位移计算器——拖动 $x_1$、$x_2$ 滑块，实时画出有向线段并计算 $\Delta x = x_2 - x_1$、大小与方向。

**思考与讨论**：$x_A = 5 \text{ m}$、$x_B = 2 \text{ m}$，位移大小 $3 \text{ m}$、方向沿 $x$ 轴负方向。总结坐标之差的正负与位移方向的关系。

### 六、位移—时间图像与测量

$x$-$t$ 图像：时刻 $t$ 为横轴、位置 $x$ 为纵轴；初始位置为原点时成为位移—时间图像，可直观看出不同时间内的位移。

测量方法：频闪照相（同时记录时刻与位置）；打点计时器（电磁 8 V / 电火花，50 Hz，每隔 0.02 s 打一个点，点距 = 相应时间间隔的位移大小）。

科学漫步：全球卫星导航系统（北斗 2012 面向亚太、2020 面向全球；GPS、格洛纳斯、伽利略），体会时刻与位置的测量在生活中的应用。

### 七、课堂小结

四块回顾：质点（能否看成质点由研究的问题决定）、参考系（运动绝对、描述相对）、时间（时刻=点 / 时间间隔=线段）、位移（矢量，$\Delta x = x_2 - x_1$）。

### 八、课后练习

1. 质点判断选择题（四个情境，先做后对答案，强调判断依据）。
2. 一维位移计算：$x_1 = 3 \text{ m} \to x_2 = -2 \text{ m}$，$\Delta x = -5 \text{ m}$，方向沿 $x$ 轴负方向；讨论"路程能否小于位移大小"（不能，路程 ≥ 位移大小）。

```
一、质点                    二、参考系
    忽略大小形状 → 有质量的点     运动是绝对的、描述是相对的
    （理想化模型）             参考系：选作参考的物体
    能否看成质点：由研究的问题决定   通常以地面为参考系

三、时间                    四、位移
    时刻 → 时间轴上的点          初位置 → 末位置的有向线段（矢量）
    时间间隔 → 两点间的线段       Δx = x2 − x1（一维）
                             位移（矢量） vs 路程（标量）
```
