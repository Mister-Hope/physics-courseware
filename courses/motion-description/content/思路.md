## 一、引入（Slide 1–2）

**封面**：第一章 运动的描述 · §1.1–1.2，标题《质点与参考系·时间与位移》。装饰 SVG 用"坐标轴 + 位置随时间变化的运动轨迹 + 金色质点"，呼应"描述运动"主题。

**引入**：展示三种常见运动——汽车在公路行驶、雄鹰在空中翱翔、足球在草地上滚动。先问：要准确描述它们的运动，难在哪里？

（点击）答案：任何物体都有大小和形状，物体各部分的运动情况一般说来并不一样——这是全章逻辑的起点，为"质点"的引入做铺垫。

## 二、1.1 质点（Slide 3–8）

### 1. 质点的引入（Slide 3）

从雄鹰、足球两个具体例子出发：雄鹰身体向前、翅膀还上下运动；足球向前滚动、同时还在转动。先问"麻烦出在哪里"？

（点击）结论：我们有时关注物体各部分的运动，有时只关注整体的运动——如何描述要看关注的问题是什么。

### 2. 何时能看成"点"（Slide 4）

两个典型情境（v-click 逐条呈现）：

- **地球绕太阳公转**：地球直径约 $1.3 \times 10^4 \text{ km}$，不到地日距离（约 $1.5 \times 10^8 \text{ km}$）的万分之一——大小引起的运动差异可忽略，把它视为点。
- **列车在平直轨道行驶**：传动机构与车轮运动复杂，但只关注整体运动时——用一个点的运动代替整列列车。

（数据、表述均照教材，禁凭记忆改动）

### 3. 质点的定义（Slide 5）

定义：忽略物体的大小和形状，把它简化为一个具有质量的点，这样的点叫作质点。两个成立条件：① 大小形状可忽略；② 或各点运动完全相同，一点能反映整体。强调：质点是理想化的物理模型。

### 4. 思考与讨论：香蕉球（Slide 6）

先问：研究如何踢出"香蕉球"时，能把足球看作质点吗？

（点击）不能——旋转与弧线径迹和球的形状密切相关。

再问：研究什么样的问题可以把足球看作质点？

（点击）只关心足球从哪里飞到了哪里、不研究旋转时，形状就不重要，可看作质点。

### 5. 交互：质点判断题（Slide 7）

**ParticleJudge 组件**：6 个情境（地球公转 / 地球自转 / 列车沈阳到北京 / 列车过桥 / 踢香蕉球 / 足球整体径迹），学生先点"能 / 不能"再揭示答案与理由。用真实情境把抽象规则落到判断上。

### 6. 小结（Slide 8）

一个物体能否看成质点，由所研究的问题决定；同一物体，研究的问题不同，有时可以、有时不能。

## 三、1.1 参考系（Slide 9–12）

### 1. 引入：为什么看法不一样？（Slide 9）

列车中乘务员与旅客在交流：车外人认为他们随列车一起运动，彼此看对方却静止。

先问：为什么人们的看法会不一样？

（点击）描述位置随时间的变化，总是相对于其他物体而言的。

### 2. 运动的绝对性与相对性 + 定义（Slide 10）

- 运动是绝对的：一切物体都处于永恒运动中，绝对静止不存在。
- 运动的相对性：描述位置随时间变化，总是相对于其他物体而言。
- 定义：用来作为参考的物体，叫作参考系。

### 3. 交互：参考系演示（Slide 11）

**ReferenceFrameDemo 组件**：一辆列车、车内乘客、窗外一棵树、地面观察者。

- 以地面为参考系：树静止，列车和乘客随车向右运动。
- 以车厢为参考系：列车静止、乘客静止，树向左"后退"。

切换按钮实时切换两种视角，直观感受"同一运动，参考系不同描述不同"。

### 4. 参考系怎么选？（Slide 12）

三个要点卡片：可以任意选择 / 选取得当更简洁 / 通常选地面。强调：凡是提到运动，都应弄清相对哪个参考系。

## 四、1.2 时间 位移（Slide 13–22）

### 1. 引入（Slide 13）

要描述物体位置随时间的变化，需要哪些概念？（点击）位置——用什么描述；时间——"时间"到底是什么。承上启下。

### 2. 时刻与时间间隔（Slide 14）

上午 8 时上课、8 时 45 分下课。先问："8 时""8 时 45 分"和"45 min"有什么不同？

（点击）时刻：上课开始和结束的瞬间；时间间隔：两个时刻之间持续的一段时间。平时说的"时间"，有时指时刻，有时指时间间隔，要依上下文判断。

### 3. 交互：时间轴（Slide 15）

**TimeAxis 组件**：时间轴上 8:00 与 8:45 两个标记点。

- "显示时刻"→ 两个点 + 标签"上课时刻 / 下课时刻"；
- "显示时间间隔"→ 两点之间的高亮线段 + "45 min"。

直观对应教材"时刻用点表示、时间间隔用线段表示"。

### 4. 用坐标描述位置（Slide 16）

定量描述位置，需要在参考系上建立坐标系。直线运动用一维坐标系：原点、正方向、单位长度。长安街例子：$x$ 轴正方向指东，岗亭为原点 $O$；$+30 \text{ m}$ 在岗亭以东，$-20 \text{ m}$ 在岗亭以西。

### 5. 位置的变化：北京 → 重庆（Slide 17）

三种方式（火车 / 飞机 / 火车+轮船）。先问：哪种方式位置变化最大？

（点击）都一样——都从北京到达西南方向、直线距离约 $1300 \text{ km}$ 的重庆。路程（轨迹长度）随路径不同而不同，位置的变化却相同。

### 6. 位移的定义 + 矢量标量（Slide 18）

由初位置指向末位置的有向线段，能准确描述位置的变化——这就是位移，用 $l$ 表示。位移是矢量（大小 + 方向）；路程、温度是标量。位移只与初末位置有关，不因路径而变。

### 7. 交互：直线运动的位移（Slide 19）

**DisplacementLine 组件**：滑块拖动初位置 $x_1$、末位置 $x_2$（-10 ~ 10 m），SVG 坐标轴实时画出从初指向末的有向线段（箭头），并实时计算：

$$\Delta x = x_2 - x_1$$

显示位移大小 $|\Delta x|$ 与方向（正 / 负方向 / 零）。用真实公式计算，数值随参数真实变化。

### 8. 思考与讨论（Slide 20）

某物体从 $A$ 运动到 $B$，$x_A = 5 \text{ m}$，$x_B = 2 \text{ m}$。先问：位移大小？方向？

（点击）$\Delta x = 2 - 5 = -3 \text{ m}$：大小为 $3 \text{ m}$，方向指向 $x$ 轴负方向。总结：坐标之差为正→指向正方向，为负→指向负方向。

### 9. 位移—时间图像（Slide 21）

时刻 $t$ 为横轴、位置 $x$ 为纵轴 → 位置—时间图像；初始位置为原点时成为位移—时间图像（$x$-$t$ 图像）。从 $x$-$t$ 图像可直观看出不同时间内的位移。配静态 SVG 示例图（斜线 + 某时刻位移的虚线标注）。

### 10. 位移和时间的测量（Slide 22–23）

- 频闪照相：同时记录时刻和位置。
- 打点计时器：电磁式 8 V、电火花式；电源 50 Hz，每隔 0.02 s 打一个点；点距 = 相应时间间隔的位移大小。
- 科学漫步·全球卫星导航系统：北斗 2012 面向亚太、2020 面向全球；四大系统；从车载导航到海事救援，测量无处不在。

## 五、总结与练习（Slide 24–25）

**课堂小结**：四块回顾——质点（能否看成质点由研究的问题决定）、参考系（运动绝对、描述相对）、时间（时刻=点 / 时间间隔=线段）、位移（矢量，$\Delta x = x_2 - x_1$）。

**课后练习**：① 质点判断选择题（四个情境，先做后揭示答案 C）；② 一维位移计算：$x_1 = 3 \text{ m} \to x_2 = -2 \text{ m}$，$\Delta x = -5 \text{ m}$，路程不可能小于位移大小。
