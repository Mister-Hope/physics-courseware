# 楞次定律 — 授课思路

## 教师的要求

- 只做封面、引课、讲课、课堂小结；**例题由教师自己补**，课件里不设例题页。
- 不按 40 分钟卡课时，内容该讲多深就讲多深。
- 四种情况的记录做成**点击回放**。
- **右手定则本节讲**。
- 封面不加副标题。

## 一、引入

- 现象：把 N 极插入线圈，指针向右偏；把 N 极抽出，指针向左偏。
- 问题：同样是磁通量在变化，为什么感应电流的方向相反？
- 承接：此前只学过"磁通量变化就有感应电流"，那是"有没有"，没回答"朝哪边"。

## 二、实验：把四种情况分开

- 先问：要找出规律，应该改变什么、控制什么？
- 两个变量：磁极（N / S）、磁通量在增大还是减小（插入 / 抽出）；线圈、磁体、电流表都不变。
- 2 × 2 共四种情况，逐一做一遍，每种记两件事：磁体磁场的方向、感应电流的方向。

## 三、回放与记录

- 回放（四个按钮）：磁体一动指针就偏，磁体一停指针回零；四种情况偏向两两不同。
- 四格记录：图注写清插入 / 抽出；点击逐格叠出原磁场与感应电流方向。

## 四、换视角

- 先问：直接比较电流方向与磁通量变化，看不出规律，缺了什么？
- 换研究对象：磁体周围有磁场，感应电流也产生磁场。
- 用右手螺旋定则，由电流方向定出感应电流的磁场方向。
- 四格汇总：磁通量增大 → 感应电流的磁场与原磁场反向；减小 → 同向（增反减同）。

## 五、楞次定律

- 定义：感应电流的磁场总要阻碍引起感应电流的磁通量的变化（1834 年，楞次）。
- 辨析：阻碍的是"变化"，不是磁通量本身；阻碍不等于阻止。
- 能量守恒：插入、抽出外力都要做正功，功转化为电能；若"帮忙"就凭空产生能量。
- 检验：吊起的铝环，磁体靠近被推开、移开被吸回；剪开缺口则不动。

## 六、判定与右手定则

- 判定五步：定回路 → 画原磁场 → 判磁通量增减 → 增反减同定感应电流的磁场 → 右手螺旋定则定电流。
- 右手定则：从导体切割磁感线的具体情形推出来，再给出右手定则的表述与适用范围。
- 三个定则分工：安培定则（电→磁）、左手定则（磁+电→力）、右手定则（磁+运动→电）。

## 七、课堂小结

- 线索：四种情况 → 改看感应电流的磁场 → 增反减同 → 能量守恒。
- 两个易错点：阻碍的是变化；右手定则只管导体切割磁感线。
