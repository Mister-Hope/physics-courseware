# 抛体运动的规律 — 授课思路

> 老师口述思路的整理稿（保留原话与细节，不写迭代记录）。

## 一、总体安排

**两课时**，一个课件。省重点高中的讲法：知识要**连贯地讲完再练**。

- **第一课时**：平抛运动的规律 → 斜抛（初速度分解、分方向列式、轨迹方程、射高射程）→ **"45° 射得最远"并给出数学推导** → 空气阻力与炮弹的实际轨迹。规律讲完再做题：速度、位移、偏角、`Δv`、轨迹先连成一条线，然后才是例题。
- **第二课时**：平抛运动与各种"面"、以及平抛的临界问题——一份**详实的习题课**。
- 学生已上过 5.1 曲线运动、5.2 运动的合成与分解；5.3 平抛实验做过。

## 二、第一课时的引入与顺序

- **不要另外设计引课**（排球过网 / 出界那一页去掉）：**直接从 5.3 的实验结论引入**——上节课已经用实验判断出"水平方向以抛出速度做匀速直线运动、竖直方向做自由落体运动"，把这句复习出来，**一页讲完**，并直接给出建坐标系的结论（以抛出点为原点、`x` 轴沿 `v0`、`y` 轴竖直向下）。
- 之后按这个顺序讲：**先讲规律**（速度的分解与合成 → 位移 → 位移偏角与速度偏角 → `Δv = gΔt` → 轨迹方程），**再做例题**（落地速度方向、无人机投弹），最后用"落地量由谁决定"作检验。
- 这部分内容约 20 多分钟就能讲完，因此斜抛、45° 最远也放在第一课时里一起讲完。

**"位移方向与速度方向的关系"这一页要保留，并补两件事：**

1. **速度反向延长线的几何性质**：速度的反向延长线与初始 x 轴的交点，正好是当前点横坐标的一半；换句话说，从当前点向 x 轴作垂线，速度反向延长线正好交在这条垂线段的中点。这个几何关系做题要用到。
2. **Δv = gΔt，平抛是匀变速曲线运动**：速度随时间均匀变化。"匀变速"指的是**速度均匀变化**，不是速率均匀变化——这是学生经常不理解的地方，要讲清楚。

## 三、斜抛（第一课时后半段，与平抛连在一起讲）

- 斜抛与平抛受力完全相同，差别只在初速度方向：`v0x = v0cosθ`、`v0y = v0sinθ`。
- 分方向列式（水平匀速、竖直方向是竖直上抛）、轨迹方程、射高、射程。
- **一定要得到"45° 射程最大"，并给出数学推导。** 推之前先让学生自己动手：**在讲台上拖初速度箭头的末端改变抛射角**（组件复用），让他们自己感受"为什么 45° 最远"，然后才给推导与结论。
- 空气阻力：速度越大阻力越大，炮弹的实际轨迹不再是抛物线（教材 5.4 正文最后一段，单独一页配"理想 / 实际轨迹"对比图）。

## 四、平抛运动与各种"面"（第二课时）

- **打墙面 / 打水平面的比较已经讲过，学生已经理解**：本课件不再重讲，而是做成**两页检验、每页右侧配示意图**——**先"落到水平面上"**（下落高度被锁死：`t = √(2h/g)` 与初速度无关，初速度 2 倍则水平距离也 2 倍），**再"打在竖直墙面上"**（水平距离被锁死：`t = L / v0`，初速度越大越早到墙、撞墙时 `vy = gL/v0` 越小）；检验完顺势给出楼梯例题。
- **楼梯例题**：抛出点在楼梯底端、高于台阶的某个高度，水平抛出（平抛）；楼梯越往远处越高。落到**更远、更高**的台阶时：
  - 它离抛出点更近（下落距离 `H − h` 更短）→ **用时更短**；
  - 它同时更远 → **水平距离更大**；
  - 于是 `v0 = x / t` 分子更大、分母更小 → **初速度一定更大**。
    非常经典的例题；讲完再对比"落到更近、更低的台阶"。
- **平抛与斜面**（三种情形都要求出初速度 `v0` 与倾角 `θ` 的关系）：
  1. 垂直落在斜面上——条件用 `vx / vy` 表示；
  2. 从斜面顶部抛出、又落到斜面上——速度方向固定；
  3. 落在斜面上时位移正好垂直于斜面。
- **落在圆弧上**：
  1. 正好落入轨道——轨道的切线方向就是速度方向；图要画成**圆心在上方**的碗形圆弧，抛物线才"切"得进去；
  2. 从圆心出发落到 1/4 圆弧上——求初速度 `v0`、半径 `R` 与"落点与圆心连线跟水平线的夹角 `θ`"的关系；
  3. 半圆形轨道**从同一端**以很小和很大的速度平抛射入——速度反向延长线交抛出高度线于水平位移的一半，两个交点都落在**圆心左侧**，所以任何落点的速度方向都不可能过圆心。
- **平抛运动的临界问题**：羽毛球、乒乓球一类（恰好过网 / 恰好不出界）。
