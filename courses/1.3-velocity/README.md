# 位置变化快慢的描述——速度 — 公开课交互式课件

> 原创：张伯望（东北育才学校） ｜ 人教版必修第一册 1.3 ｜ 在线地址：**[https://courseware.mister-hope.com/1.3-velocity/](https://courseware.mister-hope.com/1.3-velocity/)**

**一个课件 = 一个课（两课时）**：

- **第一课时**（第 1–18 页）：概念建构，末尾是课堂小结；
- **第二课时**（第 19–30 页）：另起一张封面，从打点计时器的纸带出发，落到 $v$-$t$ 图像与拟合。

## 交互式组件

| 组件       | 功能                                                                                                                            | 页面 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------- | ---- |
| `XTSlope`  | x-t 图像上 A 点固定、B 点可拖：实时显示 Δt、Δx、割线斜率（平均速度），可切换显示 A 点切线，演示"割线斜率 → 切线斜率 = 瞬时速度" | 11   |
| `TrackRun` | 400 m 跑道示意图：起点画在**直道与弯道的交界处**，**点击跑道本身**黄点沿中心线跑完整整一圈（按弧长取点）；不占用翻页点击步      | 12   |

> 导航示意图、纸带示意图、三种方案跨度图、各张 v-t 图像都是 `slides.md` 里的静态 SVG，没有单独做组件。
> 第二课时的纸带数据：每 5 个点一个计数点（$\Delta t=0.1\ \text{s}$），位置 0、0.05、0.12、0.25、0.46、0.79、1.26 m → 各点速度 0.6、1.0、1.7、2.7、4.0 m/s（**加速度逐渐增大**，所以 $v$-$t$ 图是明显弯曲的曲线，折线与平滑曲线的差别才看得出来）。
