# §3.1 重力、弹力 — 授课思路

> 来源：老师手写教案（`todo/3.1.md`）。
> 教案原稿的页码逻辑顺序是：**初中回顾 → 力的分类 / 重力 / 重心 → 弹力 / 胡克定律 / 方向判断 → 绳模型与弹簧模型 → 轻杆模型**。

## 一、教学基本信息

- **课题**：§3.1 重力、弹力
- **教学目标**
  1. 认识重力以及 $g$ 的概念
  2. 理解弹力，了解弹性形变与塑性形变，并引入胡克定律
  3. 认识弹力的方向
  4. 理解重心的性质与测量
- **教学重点**：弹力的方向以及胡克定律；重心的测量
- **难点**：弹力的方向
- **教学方法**：讲授法
- **教具**：纸片、问卷、板书
- **课时安排**：本课分两课时——第 1 课时：力（三要素、矢量）、重力、重心（含正方体滚动、椰子装水、铁链三个演示），下课前做课堂小结；第 2 课时：形变与微小形变放大、弹力、胡克定律、弹力方向、绳 / 弹簧 / 轻杆三个模型与弹簧串并联，下课前再做一次课堂小结。

## 二、教学过程

### （一）从初中知识回顾总结什么是力

1. **力**：物体对物体的作用
2. **力的三要素**：大小、方向、作用点
3. **力的表示**
   - **力的示意图**
   - **力的图示**
   - _【原稿手绘图示】_
     - 画有物块受斜向右上方的力：一图标为力的示意图，标有拉力箭头与大小 $F = 100\text{ N}$；
     - 另一图画有标度线段标为 $10\text{ N}$，物体受与水平方向夹角 $30^\circ$、大小为 $F = 30\text{ N}$（三段标度长）的拉力图示。
4. **说明**：矢量；符号 $F$；单位牛顿，简称牛，符号 $\text{N}$
5. **力的分类**
   - 从效果（支持力、拉力、浮力）
   - 从作用范围（内力、外力）
   - 从作用对象（作用力、反作用力）
   - 从性质（重力、弹力、摩擦力、电磁力等）

### （二）重力

1. **定义**：由于地球的吸引而使物体受到的力
2. **大小**：$G = mg$，其中 $g$ 为重力加速度
3. **方向**：竖直向下
4. **作用点**：重心 → 等效集中在一个点，物体有且只有一个重心
   - **重心的位置**
     - 质量均匀 → 几何中心
     - 普遍测量 → 悬挂法 → 二力平衡

**重心变化的三道演示（一定要演示）**

- **正方体滚动**：正方体在桌面上滚动（绕底棱翻转）时，重心（几何中心）离桌面的高度 $h = \frac{a}{2}(\cos\theta + \sin\theta)$：平放时最低为 $\frac{a}{2}$，转到 $45^\circ$ 时最高为 $\frac{\sqrt{2}}{2}a$。交互上拖动滑块在 $0^\circ \sim 90^\circ$ 之间翻转，松手后小于 $45^\circ$ 会落回、大于 $45^\circ$ 会翻到另一面，另有重置按钮。**要找的极端点是 $\frac{\sqrt{3}}{2}a$**：沿体对角线把它立起来（一个顶点着地、体对角线竖直）时，重心在体对角线中点，离桌面 $\frac{\sqrt{3}}{2}a$——这是重心能到达的最高点。
- **椰子装水**：重心先下降后上升，极限在重心与椰子液面相重合处（椰壳比水轻得多，重心最低点会明显低于球心）。**这里一定要做一个动画，即展示为什么极限在那里**；水位要能从满一直放到空（不注水也可以）。
- **铁链**：铁链两端固定在两个固定点上，自然下垂成悬链线；托住最低点**往上推**，把它绷成两段接近直线的形状。**这里要用动态动画演示这个过程**：链长不变、悬挂点不动，自然下垂的悬链线是重心最低的位形（稳定平衡），越往上推、链条绷得越直，重心反而越高，松手后铁链又回到自然下垂的位置。

### （三）弹力

1. **形变**
   - 体积、形状发生变化
   - **分类**
     - 按形状：拉伸、压缩、扭转、弯曲；具有普遍性
     - 按能量：弹性形变、塑性形变；分界点（临界点）是**弹性限度**，超过就不再完全恢复
     - 刚体：理想化模型，不发生形变
2. **定义**：发生形变的物体恢复原状时对其接触物体的作用力
3. **条件**：发生弹性形变；接触
4. **大小**：弹簧弹力与其形变量成正比（在弹性限度内）
   - **胡克定律**：$F = kx$，$k$ 为劲度系数，单位 $\text{N/m}$
5. **弹簧的串并联**
   - **并联**：_【手绘图】_两根并排悬挂的弹簧 $k_1, k_2$
     - $F = F_1 + F_2$，$x = x_1 = x_2$
   - **串联**：_【手绘图】_上下相接串在一起的弹簧 $k_1, k_2$
     - $\frac{1}{k} = \frac{1}{k_1} + \frac{1}{k_2}$，$F = F_1 = F_2$，$x = x_1 + x_2$
6. **方向**：垂直公切面（曲面对曲面接触时，就是沿过接触点的**公法线**；两个球面之间即**两球心的连线**）
   - 面接触 / 点接触 / 曲面接触统一成一句：垂直于该点的**公切面**
   - _【手绘图 1】_斜悬挂的轻绳拉住一个球靠在竖直墙壁上，画出了沿绳向上的拉力 $F_T$ 和垂直接触面指向球心的支持力 $F_N$
   - _【手绘图 2】_半球形碗内搁置一根直杆，标出了碗底接触点支持力 $F_N$ 沿半径指向球心、碗沿接触点支持力垂直杆身向外的受力方向
   - _【手绘图 3】_小球卡在两竖直杆间，沿垂直方向画有 $A, B, C$ 三个位置点，文字标注："高度变化不影响弹力大小"
7. **弹力有无的判断**（方向讲完，再判断有没有）
   - 常用**假设法**：假设撤去这个接触面，看物体的运动状态会不会改变
   - _【手绘图 4】_地面上一个小球紧挨着右侧方块，下方附隔离受力分析：受竖直向下的重力 $G$、竖直向上的支持力 $F_N$，与右侧物块间水平方向无弹力
   - _【手绘图 5】_竖直绳悬挂一球靠在斜面上，文字标注："光滑 / 不光滑，一定没有"
   - _【手绘图 6】_球处于光滑斜角槽内（两斜面夹角处），文字标注："有可能"

### （四）三大常见模型：弹簧、绳、轻杆

**8. 弹簧**

- 理想弹簧：轻质（$m = 0$），劲度系数 $k$ 是有限值，且有一定弹性限度（伸长量应保持在范围之内）；两端受到的拉力相等，可同时提供拉力和压力
- 实际弹簧：有质量、有内摩擦，超过弹性限度就不再服从 $F = kx$
- **形变量对比模型（重点结论）**
  - _【手绘图 1】_左端固定在墙上，右端施加水平拉力 $F$，伸长量 $\Delta l_1$
  - _【手绘图 2】_两端同时受大小为 $F$ 的反向拉力，伸长量 $\Delta l_2$
  - _【手绘图 3】_弹簧连接质量为 $m$ 的滑块置于光滑水平面（$\mu = 0$），受水平拉力 $F$ 加速运动，伸长量 $\Delta l_3$
  - _【手绘图 4】_弹簧连接质量为 $m$ 的滑块置于粗糙水平面（$\mu \neq 0$），受水平拉力 $F$ 加速运动，伸长量 $\Delta l_4$
  - **结论**：$\Delta l_1 = \Delta l_2 = \Delta l_3 = \Delta l_4$

**9. 绳**

- 绳上的弹力实质上是**张力**（符号 $F_T$）：可以提供拉力，不能提供反向的压力；两端物体的距离缩短时，绳变得松弛、张力消失
- 理想绳：质量不计（$m \to 0$）的刚体——完全非弹性、不可伸长，$k \to +\infty$
- 轻绳（$m = 0$）：**一段绳**的拉力处处相等；"一段绳"指中间不存在新的（沿绳的）受力点的绳段
- **绳的方向**：弹力沿绳，指向绳收缩的方向
- **重绳受力特点**：_【手绘图】_竖直悬挂在天花板上的重绳：自由端拉力为 $0$、天花板处拉力等于绳的重力 $G$；设绳长 $L$，距自由端 $x$ 处 $T = \frac{x}{L}G$，与 $x$ 成正比——拉力从下往上**均匀增大**
- **拔河模型**：_【手绘图】_甲、乙在左、丙在右，三人拉同一根轻绳：两个自由端的拉力为 $0$，甲、乙之间为 $F_1$，乙、丙之间为 $F_1 + F_2$，故 $F_3 = F_1 + F_2$
  - _【手绘图】_绳跨过光滑滑轮，两端沿绳方向拉力大小均为 $F_T$
  - _【手绘图】_皮带轮传动示意，各段张力 $T_1, T_2, T_3$ 满足 $T_1 < T_2$、$T_3 < T_2$

**10. 杆**

- **分类**：重杆 $m \neq 0$；轻杆 $m = 0$
- 理想杆：完全不形变、质量不计；和弹簧一样既能提供拉力、也能提供压力，但弹力方向不一定沿杆
- **杆的弹力方向规律**
  - 多力杆（受力端严格固定）→ 任意方向
  - 连轴或铰链接触 → 沿杆
  - 二力杆 → 沿杆（两端铰链）
- **体会活动**：用手握笔，然后用另一只手按压感受杆的作用力方向——这就是多力杆

## 三、实验与演示

- **通过平面镜观察桌面的微小形变**（教材演示）：两块平面镜 $M$、$N$ **完全竖直地立在桌面上、平行相对**，激光笔斜放在两镜之间，光在两面镜子间来回反射、最后从镜顶掠过打到墙上形成光点；按压两镜之间的桌面，桌面下凹、两镜上端各向内转过 $\theta$，墙上光点明显移动。要点：这就是**光路放大法**——利用光沿直线传播和光的反射定律，每反射一次光线偏转 $2\theta$，多次反射把偏转角一次次累积起来，把看不见的微小形变变成肉眼可见的光点移动。
- **探究弹簧弹力与形变量的关系**（教材实验）：弹簧上端固定在铁架台横杆上、下端挂不同质量的钩码，弹簧弹力等于钩码重力；以弹力 $F$ 为纵轴、伸长量 $x$ 为横轴描点作 $F-x$ 图像，图像是一条过原点的直线，斜率即劲度系数 $k$。
- 教材习题 6 的数据（钩码质量 0～150 g、弹簧总长度 6.0～11.8 cm）用于课上处理数据、算劲度系数。

## 四、课堂小结

- 重力：$G = mg$、方向竖直向下、作用点是重心；重心位置与形状、质量分布有关，可用悬挂法测定。
- 弹力：接触 + 弹性形变才有弹力；方向垂直于接触处的公切面（绳沿绳、球面沿半径）。
- 胡克定律：弹性限度内 $F = kx$。
- 三个模型：轻绳张力处处相等；弹簧的形变量只由弹力决定；杆的弹力方向由受力情况决定（只有二力杆一定沿杆）。
