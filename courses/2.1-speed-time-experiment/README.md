# 实验：探究小车速度随时间变化的规律 — 公开课交互式课件

> 原创：张伯望（东北育才学校） ｜ 人教版必修第一册 2.1 ｜ 在线地址：**[https://courseware.mister-hope.com/2.1-speed-time-experiment/](https://courseware.mister-hope.com/2.1-speed-time-experiment/)**

这节课在**实验室**上，学生边听边动手，所以第 7、8 页做成"操作提示卡"式的整页提示，教师可以停在那两页等各组做完。

一节课的主线：**把纸带变成数据，把数据变成图像，让图像的斜率说出加速度**——
用该点前后一小段的平均速度代替瞬时速度 → 器材安装与实验要点 → 从起头一次性量出坐标 → 记录表 →
$v-t$ 图像（纵轴折断、十字线描点、拟合直线）→ 斜率就是加速度。

## 授课提醒

- **先通电、后放车**：用的是电磁式打点计时器，刚接通电源时振针还没稳定振动，**要等打点稳定后再释放小车**；
  顺序反了（先放车、后通电），小车最开始运动的那段信息没有被打下来就丢失了；同时用手挡在滑轮处，防止小车掉落。
- **量长度只量一次**：从起头（有效的第 0 个点）一次性量出各点坐标，不要一点一点挪着尺子量；每隔 4 个点取 1 个计数点（$T=0.1\ \text{s}$）。
- **纵轴要折断**：计时起点不是释放小车的时刻——纸带开头过密的点已经舍掉，第 0 个计数点处小车**已经有速度**（$v_0\neq0$）；
  纵轴从 0 画会把点挤在上方一条窄带里，白留一大段坐标纸。
- **记录与计算**：记录 2 位有效数字（引入科学计数法），计算过程用 3 位应对，结果保留最短位数，中间不要四舍五入。
- **第 12、13 页用的是示例数据**（$a\approx0.80\ \text{m/s}^2$），只用于演示"描点 → 拟合 → 求斜率"；
  第 9 页的记录表是空白的，课堂上由各组填自己纸带的数据。
- **第 7、8 页是操作提示卡**：上课时停在这两页即可，学生照着做。
