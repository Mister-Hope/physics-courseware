| 项目     | 内容                                                                                         |

### 教学目标（3 条）

1. 由法拉第电磁感应现象出发，理解麦克斯韦"变化的磁场产生电场、变化的电场产生磁场"的推广，建立电磁场与电磁波的概念。
2. 知道电磁波不需要介质、在真空中以光速传播，理解 `c = λf`，知道光是电磁波；了解赫兹实验与"捕捉电磁波"的证据链。
3. 了解电磁波谱的组成与各波段的应用，知道电磁波具有能量、是一种物质，能举例说明电磁波在通信中的应用。

### 与前后课时的衔接

- **上一节 13.3**：法拉第电磁感应现象——"变化的磁场在闭合电路中产生感应电流"。本节课的第一问就是从这里出发，把它推广到"没有电路的空间"。
- **本节**：麦克斯韦的电磁场理论 → 电磁波的预言 → 赫兹实验证实 → 描述电磁波（`c = λf`）→ 电磁波谱 → 能量与通信。
- **下一节 13.5**：热辐射、能量子、能级；本节"电磁波具有能量"是 13.5 讨论热辐射与光子能量的直接前提。
- **选择性必修第二册 4.2–4.4**：电磁振荡、电磁波的发射与接收、`E ⊥ B` 的横波图像与偏振等内容留到选必阶段，本课不提前讲。

## 三、逐页设计

> 说明：以下 `$clicks` 均指该页 frontmatter `clicks: N` 控制的页内步数；图组件内部按 `step` 切换显示。HTML 块内公式一律用 `<Latex tex="…" />`；物理量用斜体、单位用 `\text{}`。
>
> **全课统一的节奏**：每页第 0 步只出问题（或"题目原图 / 装置图"这类第一眼就该给的东西）；结论、答案、分析类标注（电流、辅助线、现象）一律点击后才出；分步只新增元素，不做替换或位移。

> **图幅约定（排版预算）**：第 3、4、5、6、8、9、13 页的图都放在 `base-flex` 的 `.figure` 里、按栏宽（约 883 px）100% 渲染，因此重画组件时把 viewBox 做成**宽而矮**，让图内字号接近 1:1：`ChangingBToESvg`≈820×260、`EmFieldRelationSvg`≈860×200、`EmWaveChain`≈880×250、`SunEarthBeamSvg`≈880×285、`HertzExperimentSvg`≈880×220、`WavePeakSvg`≈860×235、`MicrowaveOvenSvg`≈880×210、`EmSpectrum`≈880×130（谱带）；`SatCommSvg`≈640×330 放在 `.split-wide` 右栏（约 400×206）；`TiangongSvg` 用固有 352×257 进 `#fig`。图内正文级标注给 16–17，渲染后不小于 14。

### 第 1 页｜封面

- **标题**：封面布局取 headmatter 的 `title`（"电磁波的发现及应用"）；不另写 `#`。
- **布局**：`layout: course-cover`。
- **上屏内容**：
  - `chapter-no: "13.4"`、`chapter: "第十三章 电磁感应与电磁波初步"`；
  - `subtitle: 从麦克斯韦的预见到赫兹的实验`；
  - 装饰图 `<CoverDecorationSvg />`（默认插槽）：左侧竖直天线、向右传播的波、右下传播方向箭头。
- **点击节奏**：0 击（静态封面）。
- **交互组件与触发**：无。
- **教学意图**：用一句副标题点出本课"预言—实验"的主线，不提前给任何结论。
- **物理依据**：教材 13.4 章首与「电磁波」部分（麦克斯韦预言、1886 年赫兹实验）。
- **备注**：封面装饰**不标 E/B、不画正交双波**——"`E ⊥ B`、横波"属选必二 4.2，必修三不抢跑；装饰只画"一列波 + 传播方向"。

### 第 3 页｜变化的磁场产生电场（不写标题）

- **标题**：不写（页面已有 `.ask` 问同一件事；frontmatter `title: 变化的磁场产生电场` 仅保目录）。
- **布局**：`base-flex`，`clicks: 3`。
- **上屏内容与点击节奏**：
  - **第 0 步（初始）**：`.ask`：法拉第：变化的磁场能在闭合电路中产生感应电流。**如果没有闭合电路，变化的磁场还会在空间产生什么？**
  - **第 1 击**：图 `<ChangingBToESvg :step="$clicks" />` 左格出现——虚线框"变化的磁场"（`<FieldDots dir="in" />` 平铺 ⊗）+ 闭合导线环（手写 `<path>`）+ 电流表（`<CircuitMeter kind="a" />`，旁标"有示数"）+ 标注"感应电流"；**不标电流方向**（磁场是增强还是减弱未给定）。
  - **第 2 击**：右格出现——同样的"变化的磁场"，去掉导线，周围出现淡红色光晕 + `<Latex tex="E" />` 标注，表示"空间中有电场"。
  - **第 3 击**：`.tip-hint`：这个现象的实质是**变化的磁场产生电场**——跟有没有闭合电路无关。
- **交互组件与触发**：点击分步（`$clicks`）；固定 viewBox 的 SVG 内部按 `step` 切换显示（不参与页面布局，不会顶跑已有元素）。
- **教学意图**：把"电路中的感应电流"推进到"空间中的电场"，完成从法拉第到麦克斯韦的第一步。
- **物理依据**：教材 13.4「电磁场」第 2 段（"即使在变化的磁场中没有闭合电路，同样会在空间产生电场……实质是变化的磁场产生了电场"）。
- **物理边界**：右格只表示"空间中有电场"，**不画场线形状、不标方向**（方向取决于磁场在增强还是减弱，必修阶段不讨论），也不出现"涡旋电场 / 感生电场"（选必二 2.4 的内容）。

### 第 4 页｜变化的电场产生磁场 · 统一的电磁场（不写标题）

- **标题**：不写（同页 `.ask` 即主题；frontmatter `title: 变化的电场产生磁场` 仅保目录）。
- **布局**：`base-flex`，`clicks: 3`。
- **上屏内容与点击节奏**：
  - **第 0 步**：`.ask`：**既然变化的磁场能产生电场，那么变化的电场能产生磁场吗？**
  - **第 1 击**：一行正文：麦克斯韦确信自然规律的统一性与和谐性，大胆假设：**变化的电场就像导线中的电流一样，会在空间产生磁场**。
  - **第 2 击**：`<EmFieldRelationSvg :step="$clicks" />`——左框"变化的磁场"、右框"变化的电场"，上下两条弧形箭头分别标"产生"，把两条结论并置成对称关系。
  - **第 3 击**：`<DefinitionBox term="电磁场">`：变化的电场和磁场总是相互联系的，形成一个不可分割的统一的电磁场。
- **交互组件与触发**：点击分步；关系图只画"谁产生谁"，不画场线、不标方向。
- **教学意图**：用"对称之美"把第二个结论立住，并收束为"电磁场"这一个统一概念。
- **物理依据**：教材 13.4「电磁场」第 3 段。

### 第 5 页｜电磁波

- **标题**：写 `# 电磁波`（主题名，不提前给结论）。
- **布局**：`base-flex`，`clicks: 4`。
- **上屏内容与点击节奏**：
  - **第 0 步**：`.ask`：周期性变化的电场在空间激起周期性变化的磁场，这个变化的磁场又激起新的变化的电场——**这样下去会怎样？**
  - **第 1 击**：`<EmWaveChain :step="$clicks" />` 出现振源（天线）+ 第一个"电场区"（红色 `<Latex tex="E" />` 场线）。
  - **第 2 击**：箭头（标"激起"）+ "磁场区"（蓝色 `<FieldDots dir="in" />` 阵列 + `<Latex tex="B" />` 标注）。
  - **第 3 击**：箭头（标"激起"）+ 新的"电场区"（红色场线，**必须是 E 线，不能放 B 记号**）。
  - **第 4 击**：向右的传播长箭头 + `.tip-hint`：变化的电场和磁场交替产生，由近及远地向周围传播——空间可能存在**电磁波**。
- **交互组件与触发**：点击分步（4 步）。
- **教学意图**：把前两页的"相互产生"接成一条链，完成"电磁波"的预言。
- **物理依据**：教材 13.4「电磁波」第 1 段 + 图 13.4-1。
- **物理边界**：图是"谁激发谁"的因果链示意，**不是"这里只有电场、那里只有磁场"的空间分区**；结论句用教材原话，不引入"横波、`E ⊥ B`"。E 线只画线段（不画箭头，方向随时间改变），B 用 ⊗ 只表示"垂直纸面的磁场"，图是某一时刻的示意，不讨论绕向。

### 第 8 页｜捕捉电磁波

- **标题**：写 `# 捕捉电磁波`（教材"做一做"的名字，本身承担信息）。
- **布局**：`base-flex`，`clicks: 3`。
- **上屏内容与点击节奏**：
  - **第 0 步（初始，装置常显）**：`.ask`：麦克斯韦预言了电磁波——**怎样才能用实验"捕捉"到它？** 图 `<HertzExperimentSvg :step="$clicks" />`——A、B 为发射天线（接高压发生器 G），C、D 为接收天线（中间接电流表），两对天线平行、相距 `d`；下方一行操作说明：让接收天线与发射天线平行，改变两者距离，观察电流表示数。
  - **第 1 击**：A、B 间隙出现"放电火花"（发射端）。
  - **第 2 击**：C、D 回路标注"感应电流" + 电流表旁标注"指针偏转"（**不标电流方向**：电磁波相位未给定）。
  - **第 3 击**：`d` 标注高亮（表示"改变距离"）+ `.tip-hint`：接收天线中感应出了电流——赫兹用实验捕捉到了电磁波，证实了麦克斯韦的电磁场理论。
- **交互组件与触发**：点击分步；装置图属于"题目原图"性质，**常显**，火花、感应电流、指针偏转属于"分析类"信息，**点击后才出**；图内这些标注用 `v-click` 保留占位（不用 `v-if` 增删），保证装置与已出现标注不被顶跑。

## 四、交互组件清单

### 4.1 交互必要性判断（先判断，再动手）

本课**只有 1 个滑块**（`WaveCalc`），其余全部是点击分步或静态示意，理由：

- **值得用滑块**：`c = λf` 中"频率变、波长随之变"本身是教学对象，学生要亲手调 `<Latex tex="f" />`、看 `<Latex tex="\lambda" />` 实时反比变化并跨数量级，才能建立直觉（笔记里 A/B 类）。

- **只看形态**：电磁波谱、通信链路、卫星覆盖是**定性示意**，不编读数、不塞滑块。
- **不能硬塞数值**：第 13 页微波炉只作定性演示，屏幕上不出现温度、频率等数字。

### 4.3 用到的共享组件（不新画）

- `CourseArrow`：感应电流、传播方向、链路箭头（自动处理 marker 与尖端落点，**不手写 `<marker>`**）。
- `FieldDots`：磁场平铺阵列（`dir` / `cols` / `rows` / `spacing` / `size` / `color`；**注意不是 `gap` / `fill`**）。

### 4.4 边界情况

- **`WaveCalc`**：`\lg f` 范围 `7 \sim 16`（`<Latex tex="f" />` 从 `<Latex tex="10^{7}" />` 到 `<Latex tex="10^{16}\ \text{Hz}" />`，`<Latex tex="\lambda" />` 从 `<Latex tex="30\ \text{m}" />` 到 `<Latex tex="30\ \text{nm}" />`）；两端都不出 `NaN / Infinity`；单位换档后要再判一次（否则四舍五入会出现 `1000 nm` 这类读数）；波段判定只到"紫外线"为止（本课不给 X / γ 的波长分界数值）；四个预设按钮的值都必须落在量程内。
- **`EmWaveChain`**：`step` 夹在 `0 \sim 4`；固定 viewBox，分步不引起页面位移；第 3 个区必须是 E 线。
- **`EmSpectrum`**：第 12 页 `step` 夹在 `0 \sim 6`，第 0 步不高亮任何段；第 11 页静态版不接受 `step`。
- **`TiangongSvg`**：`s = 340\ \text{km} > 0`；辅助线只在 `step ≥ 1` 出现；`t \approx 1.13\times10^{-3}\ \text{s}`，解析里四舍五入到 `<Latex tex="1.1\times10^{-3}\ \text{s}" />`。
- **`HertzExperimentSvg`**：`step` 夹在 `0 \sim 3`；不显示任何距离数值（无实测数据）。
- **`MicrowaveOvenSvg`**：`step` 夹在 `0 \sim 2`；不出现温度、频率读数。
- **`ChangingBToESvg` / `EmFieldRelationSvg`**：`step` 夹在 `0 \sim 2`；不画方向、不画场线形状。
- **反向 / 负值**：本课没有可反向的参数（`f` 单调增大、`λ` 随之减小，`s`、`t` 恒为正），不存在负值或反向极值；`WaveCalc` 的滑块两端即是极值。
