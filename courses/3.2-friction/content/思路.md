# 摩擦力 — 授课思路

> 人教版《物理》必修第一册 §3.2（第三章 相互作用——力） · **两个课时，各约 40 分钟**
> 本文是老师手写教案（`todo/3.2.md`）的整理稿：条目、分支结构、旁注与手绘图示照原样保留。
> **本课分两个课时：第一课时只学滑动摩擦力，第二课时才学静摩擦力。**

**课 题**：摩擦力
**教学方法**：讲授法
**教 具**：板书；弹簧测力计、长木板、木块、细线、定滑轮

**教学目标**

1. 通过分析摩擦现象，理解滑动摩擦力的产生条件，会判断滑动摩擦力的方向
2. 会测量滑动摩擦力，理解 $F_f = \mu F_N$ 与动摩擦因数
3. 理解静摩擦力的产生条件与方向，会判断静摩擦力的有无

**教学重点**：计算滑动摩擦力；理解静摩擦力产生条件与方向
**难 点**：判断相对运动方向（以接触的另一个物体为参考系）；判断静摩擦力有无；静摩擦力大小计算

---

## 课时框架

- **第一课时 · 滑动摩擦力**：引入 → 产生条件 → 方向 → 怎样测出滑动摩擦力 → 大小与动摩擦因数 → 例题 → 小结。
  这一课时**完全不出现静摩擦力**——先让学生沉浸式地建立"两个物体有相对滑动时，接触面上会产生阻碍相对运动的力"这一认识。
- **第二课时 · 静摩擦力**：另起封面 → 相对静止时有没有摩擦力 → 产生条件与判断有无 → 方向 → 大小随拉力的变化与最大静摩擦力 → 大小计算 → 实例（自行车、皮带传动）→ 小结。

## 一、第一课时：滑动摩擦力

### 滑动摩擦力

1. **定义**：一个物体在另一个物体表面相对滑动时，受到另一个物体对其阻碍的作用
2. **条件**：
   - 粗糙
   - 接触
   - 挤压产生形变 $\Big\}$ 弹力
   - 相对运动
   - _（右侧旁注）_：（板擦、手抹在黑板上）
3. **光滑**：接触面光滑，就没有摩擦力
4. **大小**：$F_f = \mu F_N \quad \mu \Rightarrow$ 动摩擦因数，单位为 1
5. **方向**：
   - 与运动方向无关
   - 与相对运动方向相反
   - 判断相对运动方向的方法：**以跟它接触的另一个物体为参考系**，看它相对这个物体朝哪个方向运动，摩擦力的方向就与这个方向相反

### 怎样测出滑动摩擦力（由动转静）

- **方案一**：用弹簧测力计拉着物体做匀速运动，拉力的大小等于摩擦力。但测力计一直在运动，读数很难读准。
- **方案二**：在墙面上装一个定滑轮，用一根细线绕过定滑轮拉住物体，测力计用手拿着；物体放在长木板上，**匀速抽出长木板**。此时物体静止、测力计也不动，它的示数就是物体所受的滑动摩擦力。

### 动摩擦因数

- 同一接触面、改变压力测多次，$F_f / F_N$ 的比值基本相同；**多次更换物体、多次更换接触面**重复实验，结论一致。
- $\mu$ 可以大于 1：干燥洁净的铝—铝，工程手册的实测值可达 1.4——摩擦力完全可能比压力还大（教材表中没有这类数据）。
- 滑动摩擦力与接触面积、相对速度无关。
- 本阶段只做初中二力平衡能够判断的情形（水平方向一对力、或竖直方向一对力）；**不引入受力分析，也不探究支持力（压力）怎么算**——放在斜面等情形上一概不作定量判断。

## 二、第二课时：静摩擦力

### 静摩擦力

1. **定义**：一个物体在另一个物体表面有相对运动趋势，受到另一个物体对其阻碍作用。
2. **条件**：
   - 粗糙
   - 相互挤压
   - 具有相对运动趋势
   - 判断有无的关键就在最后一条：**有相对运动趋势才有静摩擦力**（水平桌面上静止的书，水平方向没有运动趋势，就没有静摩擦力）
3. **大小**：
   - $0 < F_f \le F_{fm}$，其中 $F_{fm} = \lambda F_N$，$\lambda$ 为最大静摩擦系数
   - 通常 $\lambda > \mu$，理想题目一般理想化 $\lambda = \mu$（无特殊说明的排除字例外）
   - $F_f$ 与 $\lambda$ 和 $F_N$ 都无直接关系，$\lambda F_N$ 决定其上限。
4. **方向**：与相对运动趋势相反。

## 三、演示：静摩擦力的大小随拉力的变化（教材，第二课时）

- **器材**：水平长木板、木块、弹簧测力计；在弹簧测力计指针下轻塞一个小纸团，随指针移动，作为指针到达最大位置的标记
- **操作**：沿水平方向拉木块，在拉力 $F$ 增大到一定值之前木块不会运动；继续用力，当拉力达到某一数值时木块开始移动，此时拉力突然变小
- **现象与结论**：木块不动时静摩擦力的大小等于拉力的大小；静摩擦力的最大值 $F_{\max}$ 在数值上等于物体即将开始运动时的拉力，实际产生的静摩擦力在 $0$ 与 $F_{\max}$ 之间，即 $0 < F \le F_{\max}$

---

## 四、课堂小结

- **第一课时（滑动摩擦力）**：产生条件（粗糙、接触挤压、相对滑动）→ 方向沿接触面、与相对运动方向相反 → 大小 $F_f = \mu F_N$，$\mu$ 可以大于 1
- **第二课时（静摩擦力）**：产生条件（粗糙、接触挤压、有相对运动趋势）→ 方向与相对运动趋势相反 → 大小由二力平衡求，范围 $0 < F \le F_{\max}$
