# 第一张图：竖直方向的穿透与相遇问题

### 【第 ① 题】长杆穿筒模型（自由落体与竖直上抛综合）

#### 题目完整叙述：

如图所示，一根长为 $L$ 的竖直长直杆悬挂在空中，其下端距离一个两端开口的薄壁圆筒上端的高度为 $H$。圆筒竖直放置，筒身长度为 $l$。重力加速度为 $g$，不计空气阻力。

1. **若圆筒保持静止固定不动**：现将长直杆由静止释放做自由落体运动，求直杆完全穿过圆筒所经历的时间 $\Delta t$ 是多少？
2. **若在直杆由静止释放的同时，圆筒以初速度 $v_0$ 竖直向上抛出**：求从开始释放到直杆完全穿出圆筒所经历的时间 $t$ 是多少？

#### 教案解析与结论：

- **第 (1) 问**：
  - 杆下端到达筒上端：由 $H = \frac{1}{2}gt_1^2$ 得 $t_1 = \sqrt{\frac{2H}{g}}$；
  - 杆上端离开筒下端：由 $H + L + l = \frac{1}{2}gt_2^2$ 得 $t_2 = \sqrt{\frac{2(H+L+l)}{g}}$；
  - 穿筒时间为：$\Delta t = t_2 - t_1 = \sqrt{\frac{2(H+L+l)}{g}} - \sqrt{\frac{2H}{g}}$。
- **第 (2) 问**：
  - 设杆完全穿出筒经历时间为 $t_2$。杆下落位移 $h_1 = \frac{1}{2}gt_2^2$，筒上升位移 $h_2 = v_0 t_2 - \frac{1}{2}gt_2^2$；
  - 两者相对位移满足：$h_1 + h_2 = l + H + L$；
  - 代入得：$v_0 t_2 = l + H + L$，解得 $t_2 = \frac{L + H + l}{v_0}$。

**这里要着重做一个动画。** 还有一种算法就是直接以杆儿为参考系，那么桶一直是 $v_0$ 向上做匀速运动。说我们可以不用任何复杂计算，直接用 $X = v_0 t$ 就算出来了。

也就是说在很多题里面，适当的变换参考系会使这个题非常的简单。

### 【第 ② 题】先后竖直上抛双球的空中相遇模型

#### 题目完整叙述：

在同一竖直线上先后向上抛出两物体 A 和 B。先以大小为 $2v_0$ 的初速度竖直向上抛出物体 A；间隔时间 $\Delta t$ 后，再以大小为 $v_0$ 的初速度竖直向上抛出物体 B。已知重力加速度为 $g$，不计空气阻力。

1. 若要使物体 A 和物体 B 能够在**空中相遇**，求抛出时间间隔 $\Delta t$ 必须满足的取值范围。
2. 若要求两物体**在物体 B 下降的过程中相遇**，求抛出时间间隔 $\Delta t$ 满足的条件（及最大时间间隔 $t_{\max}$）。

#### 教案解析与结论（配 $v-t$ 或 $x-t$ 抛物线轨迹图）：

- **第 (1) 问**：两球在空中相遇的条件为：$\frac{v_0}{2g} < \Delta t < \frac{4v_0}{g}$。
- **第 (2) 问**：当相遇点恰好落在 B 运动的下降沿时，其临界最大时间间隔为：$t_{\max} = \frac{v_0(1 + \sqrt{3})}{g}$。

# 第二张图：水平追及相遇与多车避碰模型

### 【第 (1) 题】追及相遇次数（0 次、1 次、2 次）的代数判据分析

#### 题目完整叙述：

在水平平直公路上，乙车位于甲车正前方相距 $d$ 处。某一时刻，甲车以初速度 $v_0$、加速度 $a_1$ 向右做匀变速直线运动；同时乙车由静止开始以加速度 $a_2$ 向右做匀加速直线运动。
试根据两车的运动规律，通过建立代数判别式，分别求出甲、乙两车在运动过程中**相遇 0 次（不相遇）、相遇 1 次、相遇 2 次**时，加速度 $a_1$ 需满足的数学物理条件。

#### 教案解析与结论：

- **位移关系方程**：
  设两车经过时间 $t$ 相遇，满足位移方程：
  $$v_0 t + \frac{1}{2}a_1 t^2 = d + \frac{1}{2}a_2 t^2$$
  整理为一元二次方程：$\frac{1}{2}(a_2 - a_1)t^2 - v_0 t + d = 0$。
  判别式为：$\Delta = v_0^2 - 4 \cdot \left[\frac{1}{2}(a_2 - a_1)\right] \cdot d = v_0^2 - 2(a_2 - a_1)d$。
- **相遇次数判据**：
  1. **相遇 2 次**（方程有两个不相等的正实根，$\Delta > 0$ 且 $t_1 > 0, t_2 > 0$）：
     $$a_2 - \frac{v_0^2}{2d} < a_1 < a_2$$
  2. **相遇 1 次**（$\Delta = 0$ 恰好相切，或方程只有一正根 $t_1 \cdot t_2 \le 0$）：
     $$a_1 \ge a_2 \quad \text{或} \quad a_1 = a_2 - \frac{v_0^2}{2d}$$
  3. **不相遇 / 相遇 0 次**（$\Delta < 0$，两车未追上即被拉开距离）：
     $$a_1 < a_2 - \frac{v_0^2}{2d}$$

### 【第 (2) 题】同向行驶三车防追尾（避碰）加速度临界求解

#### 题目完整叙述：

在同一直线平直车道上有三辆同向行驶的汽车甲、乙、丙，乙车在甲车前方，丙车在乙车前方，相邻两车之间的初始间距均为 $d = 3\text{ m}$。某一时刻，三车的速度分别为：
$$v_甲 = 9\text{ m/s}, \quad v_乙 = 8\text{ m/s}, \quad v_丙 = 6\text{ m/s}$$
此时甲车立即以加速度 $a_甲 = -1\text{ m/s}^2$ 开始刹车制动，为避免发生追尾碰撞事故，乙车和丙车同时开始刹车制动。已知汽车停止后不会倒车（避碰临界关系仅适用于速度大于 0 的过程）。
求：为了保证三车在整个运动过程中均不发生碰撞，乙车刹车加速度大小的最小值 $|a_乙|$ 以及丙车刹车加速度大小的最小值 $|a_丙|$ 分别为多少？

#### 教案标注与结论提示：

- 避碰临界核心是：后车追上相切时，后车速度恰好等于前车速度（$\Delta v = 0$），且此时位移差恰好等于初始车距 $d$。
- 原教案记录的演算参考值：$a_乙 \approx -1.14\text{ m/s}^2$。
