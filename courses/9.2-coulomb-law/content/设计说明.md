### 1.3 与前一节 / 后一节的衔接

- **学生已有什么**（§9.1，行 1–82）：电荷、电荷量、元电荷 $e = 1.6\times10^{-19}\ \text{C}$、电荷守恒定律、三种起电方式、验电器；**9.1 没讲"接触后电荷量平分"**——那是 §9.2 line 118 补的一条实验事实（本课时 P6）。
- **本课时要用到的旧工具**：力的合成（平行四边形定则，必修一）、万有引力定律 $F_{\text{引}} = G\dfrac{m_1m_2}{r^2}$（必修二，例题 1 用）、重力 $mg$ 与三力平衡（习题 5 用）。
- **下一节要用什么**（§9.3 电场 电场强度，行 193 起）：9.3 从"电荷 A 对 B 的作用力是 A 的电场给的"入手研究电场，靠的就是"静电力"这个抓手。所以 P15 小结必须把**力的大小、方向、适用条件**落稳，9.3 才能接着问"这个力是通过什么传递的"。

#### C2 `ChargeDistanceExperimentSvg`（P2）

- **屏幕上长什么样**：占满左栏。铁架台（底座 + 立柱 + 横梁，横梁用 `SurfaceHatch side="above"`）；带正电的带电体 C 固定在图的左侧（铁架台旁）；横梁上从左（近 C）到右有**三个悬挂点** $P_1$、$P_2$、$P_3$，每点各垂一根丝线、末端一个带正电的小球；三个小球受 C 的斥力，**一律向远离 C 的方向（向右）偏转**，悬挂点离 C 越远，丝线偏离竖直方向的角度越小（$\theta_1>\theta_2>\theta_3$）。

- **分步**：`showMarks`——第 1 击后出现 $r_1<r_2<r_3$ 的距离标注（**标在小球与 C 之间**，是球与 C 的距离，不是悬挂点间距）与偏角对比虚线。

#### C6 `CoulombForceLab`（P8）——唯一滑块交互

- **屏幕上长什么样**：左栏是两个点电荷视图（viewBox **560×290**，渲染 `max-height: 250px`；球半径 26）：两球位于同一条水平线上，间距按 $r$ 等比映射；同种电荷时两球都是红色 $+$，异种时一红 `+` 一蓝 $-$。右栏：**单列**——三个滑块（$q_1$、$q_2$、$r$）各占一行、吃满栏宽，然后是"同种 / 异种"开关、读数块、对照读数块。
- **交互**：
  - $q_1$、$q_2$：$0.5\sim5.0\ \mu\text{C}$，步长 $0.1$；
  - $r$：$5\sim50\ \text{cm}$，步长 $1\ \text{cm}$；
  - "同种 / 异种"开关：只改变力的方向（箭头由向外翻成向内），不改变 $|F|$；
  - 视觉反馈：$|F|$ 变大 → 箭头变长（长度按对数映射，**只表示相对大小**，此说明不上屏）；读数实时刷新；
  - 三个滑块都用共享 `CourseSlider` 的 `layout="tight"` + `label-width: 4.4rem`（"电荷量 $q_1$" 要一行放下：3.2rem 会折成竖排），读数用 `#value` 插槽给真 KaTeX 单位（$\mu\text{C}$ / $\text{cm}$）。
- **物理公式**：<Latex tex="F = k\dfrac{q_1 q_2}{r^2}" />，其中 $k = 9.0\times10^9\ \text{N}\cdot\text{m}^2/\text{C}^2$（教材 line 132），$q_1$、$q_2$ 单位为 $\text{C}$，$r$ 单位为 $\text{m}$（滑块读的 $\mu\text{C}$ 与 $\text{cm}$ 在组件内换算成 $\text{C}$、$\text{m}$ 再代入）。对照读数：$\dfrac{F(r/2)}{F(r)} = 4$（由公式实时算出）。
- **参数范围与边界**：最小 $r$ + 最大电荷量（$5\ \text{cm}$、$5.0\ \mu\text{C}$ 各一）时 $F = 9.0\times10^9\times\dfrac{(5\times10^{-6})^2}{0.05^2} = 90\ \text{N}$；最大 $r$ + 最小电荷量时 $F = 9.0\times10^9\times\dfrac{(0.5\times10^{-6})^2}{0.5^2} = 9.0\times10^{-3}\ \text{N}$。读数一律科学计数法保留两位有效数字（与教材一致），单位走 `<Latex tex="\text{N}" />`，**⛔ 不写纯文本 `N` / `mN`**。
- **分步**：`showForce`（第 1 击：力箭头）与 `showReadout`（第 1 击：公式 + 读数）→ `showCompare`（第 2 击：$r$ 与 $r/2$ 的对照读数，与读数块同宽、不另起一整块）。
- **版面预算（实测要求，不是审美）**：整个组件高度必须留在 **330px 以内**——`align-items: start` + 子项 `min-height: 0` + `max-height: 330px`；读数与对照读数都**用内联公式**（不再用 `display` 大公式）。原因见 §2 第 8 页的实测：不做这一步时页面初始态就顶出上沿 216.7px。
- **共享组件**：`CourseSlider`×3（⛔ 不自写 `::-webkit-slider-thumb`）、`CourseArrow`、`Latex`、`ChartLabel`（$q_1$、$q_2$、$r$ 的标注）。
- **交互必要性自查（指南 §1 三问，结论：保留滑块）**：① **需要数值**——本页要撞的错误正是"$r$ 减半 ⇒ $F$ 只当 2 倍"（漏平方），只有**倍数**能暴露它，定性图不行；② **必须亲手调**——"4 倍不是 2 倍"的陡度口述学生记不住，拖一下读数从 0.9 N 跳到 3.6 N、箭头同步变长才建立手感（指南 §2-A + §2-B）；③ **示意图 + 点击分步只能给结论、给不了手感**——"$r$、$2r$、$r/2$ 三张静态图 + 三个读数"能讲完结论，但丢掉连续耦合与 $\dfrac{F(r/2)}{F(r)}=4$ 的当场对照。**§5 一句话自证**：只有学生亲手把 $r$ 减半、看着读数从 0.9 N 跳到 3.6 N（正好 4 倍），"平方反比"才从公式变成直觉。**3 个滑块的例外**：$q_1$、$q_2$、$r$ 是同一条式子的三个自变量（不是三个并列知识点），合并成"两球电荷量"就只剩 $F \propto q^2$，丢掉"只改一个电荷量是 2 倍"这个对照——lead 已批准保留 3 个，并把这条例外写进指南 §4。
