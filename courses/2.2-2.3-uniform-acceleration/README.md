| 组件                | 功能                                                                                                                                       |

| `VtAreaRiemann.vue` | 分割求和：$n=5\to20\to100\to$ 非常非常多，小矩形面积和与真实位移（39.0 m）实时对比，展示"分得越细越接近"                                   |

## 授课提醒

- **第 11 页的几何讲法**：完整矩形 48 m **减去**大三角形——轴上方那块把上半梯形**剪掉**（32 m），轴下方那块还要**倒扣**（4 m），总位移 12.0 m，最后用 $\bar v t$ 核对。不要退回"轴上方加、轴下方减"这类没有几何依据的说法。
- **第 11 页右侧那行结论（"完整矩形 − 大三角形"）随示意图一起出现**（第 2 次点击），学生思考时屏幕上不提前给答案。
- **第 14 页标题是推导完成后才出现的**：先只给问题，第 5 次点击标题「匀变速直线运动中速度、加速度和位移的关系」才出现；翻页时不要提前念标题。
- **第 17 页右侧是规范书写示范**：只写"原始公式 + 结果"，**不写代入算式**（代入过程一旦漏量纲就会被判错）；算术过程留在草稿纸。
- **第 13 页的时间中点速度**是由公式得到的推论，教材 §2.2/§2.3 未列为正文结论。
- **第 21–22 页逐差法**是附录（教材正文未涉及，其结论出现在"复习与提高"习题中），时间不够留到第二课时；教材 §2.1 走的是 $v$-$t$ 图像求斜率。
- 三个例题全部取自教材原题（§2.2 例题 1(1)、§2.3 例题 1(1)、§2.3 例题 2），作业为 §2.3「练习与应用」第 2、4、6 题。

## 本课特有的工程约定

- **第 14 页的标题位**用 `.title-slot`：问题与标题绝对定位叠在同一个槽里，切换时零位移。
- **坐标图统一走 SVG 16px 体系**：数学量用 `font-family="KaTeX_Math" font-style="italic"`、单位用 `font-family="KaTeX_Main"`；`v₀` 用 `<tspan dy="3">0</tspan>` 下标，不用 Unicode `₀`。
- **分类树副注带专属修饰类**（`mt-note-curve` 等）：既便于按分支单独调样式，也让 E2E 的"稳定标识"能区分不同节点里的同名符号（它只回溯 3 层祖先，不加修饰类会把两个 `a` 互相错配、报出假位移）。
- **纸带图**用 `.tape-figure`（`svg` 收窄到 26rem），避免标题与图互相顶。
