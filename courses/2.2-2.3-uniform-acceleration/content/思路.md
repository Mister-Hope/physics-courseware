# 匀变速直线运动的速度、位移与时间的关系 — 授课思路

> 课题：**匀变速直线运动的速度与时间的关系（§2.2）＋匀变速直线运动的位移与时间的关系（§2.3）**
> 教材：人教版《物理》必修第一册 第二章「匀变速直线运动的研究」 · 约 40 分钟 · 一课时一课件
>
> 一句话主线：**上节实验课量出一条 v-t 直线，这节课把这条直线变成公式**——先建立运动的分类框架，
> 再发现「v-t 图像下方的面积就是位移」，由面积推出 $x=v_0t+\frac12at^2$，由加速度定义推出 $v=v_0+at$，
> 两者消去 $t$ 得到 $v^2-v_0^2=2ax$，最后落在一套**高考规范的解题书写**上，并以逐差法收尾。
>
> **本课件只做第一课时。** 紧随其后的第二课时是**习题课 / 应用扩展课**（多过程问题、追及相遇、图像综合），按教师要求不并入。
>

## 一、教师教案要点（保留原始判断）

### 1. 引入

- 上节实验课已得到一条匀变速运动的 $v$-$t$ 图像，由实验数据验证小车做**匀加速直线运动**。
- 师问：对**一般的匀变速运动**，$a$、$v$、$x$ 与 $t$ 之间的定量关系究竟是什么？
- 第二问：提到"运动"，我们该如何**系统分类**？

### 2. 运动的树状分类（板书图）

```text
                  ┌─ 曲线运动 (a 与 v 不共线)
运动 ─────────────┤
                  └─ 直线运动 (a 与 v 共线)
                        ├─ 匀速直线运动 (a = 0)
                        ├─ 匀变速直线运动 (a = 恒定常数, 且 a ≠ 0)
                        │     ├─ 匀加速直线运动 (a 与 v 同向/同号)
                        │     └─ 匀减速直线运动 (a 与 v 反向/异号)
                        └─ 非匀变速直线运动 (a 非恒量, 随时间改变)
```

三条判据（教案第 2 页结论）：**共线→直线**；**$a=\text{常量}(a\ne0)$→匀变速**；**$a$ 与 $v$ 同号→加速、异号→减速**。

### 3. 四幅手绘图像（课件复刻为矢量图）

| 图   | 内容                                                                                    | 用途                      |
| ---- | --------------------------------------------------------------------------------------- | ------------------------- |
| 图 1 | 一个坐标系里三条典型 $v$-$t$ 线：水平线（匀速）、斜直线（匀加速）、上凹曲线（$a$ 增大） | 识图                      |
| 图 2 | 匀速：图线与 $t$ 轴围成的**矩形** → $x=vt$                                              | 面积=位移的起点           |
| 图 3 | 匀加速：梯形拆成**矩形 $v_0t$** + **三角形 $\frac12at^2$**                              | 推出 $x=v_0t+\frac12at^2$ |
| 图 4 | 匀减速梯形；图线**穿过 $t$ 轴**后轴上下面积取**代数和**                                 | 方向与正负                |

### 4. 公式推导体系（教案原样）

- $a=\dfrac{\Delta v}{\Delta t}$，令 $\Delta t=t$ → $v_t=v_0+at$（变形 $v_0=v_t-at$）
- 时间中点速度：$v_{\frac t2}=v_0+\frac12at=v_t-\frac12at=\dfrac{v_0+v_t}{2}=\bar v$
- 匀速 $x=vt$；匀变速 $x=v_0t+\frac12at^2$（备用形式 $x=v_tt-\frac12at^2$）
- $x=\bar v\,t=\dfrac{v_0+v_t}{2}\cdot\dfrac{v_t-v_0}{a}=\dfrac{v_t^2-v_0^2}{2a}$ → $v_t^2-v_0^2=2ax$

### 5. 规范解题（卷面红线）

四步法：**「解 + 必要的文字描述 + 原始物理公式 + 代入数据与结果」**。

> 教师原话：**"强调算数、代权（计算草稿）都不能在答题中，移动到草稿纸上。"**
> 卷面只保留字母公式、列出的物理量数值与最终结果，通分/竖式等算术过程留在草稿纸。

### 6. 逐差法（纸带求加速度）——**教师明确要求纳入本课时**

- 偶数段：$a=\dfrac{(x_{n+1}+\dots+x_{2n})-(x_1+\dots+x_n)}{n^2T^2}$
- 奇数段：**舍去第一段**（点迹最密、相对误差最大）后按偶数段处理。

## 三、教学目标

1. **建框架**：能用 $a$ 与 $v$ 的关系把运动分类，知道"匀变速"的判据是 $a$ 恒定。
2. **懂面积**：理解 $v$-$t$ 图像与 $t$ 轴围成的面积表示位移，体会"分得越细越接近"的分割求和思想（**本课难点**）。
3. **推公式**：独立推出并记牢 $v=v_0+at$、$x=v_0t+\frac12at^2$、$v^2-v_0^2=2ax$ 及各自"不含谁"。
4. **会书写**：按高考规范四步法写出完整解答；**会处理"减速到停"的边界**。
5. **会处理纸带**：用逐差法求加速度，奇数段会舍去第一段。
