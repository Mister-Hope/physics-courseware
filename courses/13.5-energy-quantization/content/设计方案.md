# 13.5《能量量子化》课件设计方案

## 一、基本信息

| 项       | 内容                                                                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 课题     | 能量量子化                                                                                                                                         |
| 教材位置 | 人教版必修第三册 第十三章《电磁感应与电磁波初步》第 5 节（本章最后一节）                                                                           |
| 课时     | 40 分钟（1 课时）                                                                                                                                  |
| 页数     | 19 页（含封面）                                                                                                                                    |
| 主线     | 温度 → 热辐射 → 黑体辐射的强度分布 → 经典理论失效 → 能量子 ε = hν → 能量量子化（分立） → 光子 → 原子能级与跃迁 → 分立光谱 → 射电望远镜「聆听」宇宙 |

**教学目标（≤3 条）**

1. 能说出热辐射与温度的关系，知道黑体与黑体辐射；能定性读出「温度升高 → 短波成分越来越强」，并用它解释铁块颜色由暗红变到黄白。
2. 知道普朗克的能量子假设，知道 ε = hν 与普朗克常量的数值；理解微观粒子的能量是量子化的（不连续、分立），知道「光子」概念。
3. 知道原子能级与能级跃迁：放出的光子能量等于前后两个能级之差，发射光谱只有分立的亮线；了解射电望远镜（FAST）为什么能「聆听」宇宙。

**与前后课时衔接**

- 前接 13.4《电磁波的发现及应用》：电磁波谱、电磁波的能量 → 本课把电磁波具体化为「物体因温度而发出的热辐射」，并从能量角度提出量子化。
- 前接 12.4《能量守恒定律与能源》：宏观世界的能量可以连续变化；本课给出微观世界的另一幅图景——能量取分立值。
- 后接选择性必修第三册《原子结构与原子核》：氢原子能级、光电效应、波粒二象性，本课的「能量子 / 光子 / 能级」是它们的直接前提。
- 本章收尾：教材本节末段把量子力学与现代科技（核能、计算机与智能手机、激光）联系起来；科学漫步以 FAST 收束整章。

**总体取舍**

- 本课**只有 1 个滑块**（P9：频率 → 能量子），其余一律用「点击分步」或「定性示意图」：黑体谱、能级图、光谱条都是定性页，坐标轴一律**不标刻度数字**；能级图、谱线、跃迁箭头属于「讲出来才有」的分析标注，全部点击后才出现。
- 4 处回扣，把概念串成一条链：P5 曲线回扣 P2 引课（铁块颜色）；P14 谱线回扣 P13 能级差；P15 的 2.725 K 宇宙微波背景辐射回扣 P5 黑体辐射；P19 练习回扣 P3–P5 热辐射规律。
- 本课**无受力分析**（不涉及力箭头），因此「力只用 F + 角标」一条自然满足；全课不出现微积分符号。

## 三、逐页设计

**全课统一的实现约定**

- 每页 frontmatter 写 `clicks: N`，与总览表一致；组件里拿 `$clicks` 或由页面传 `:step`。
- 页面级分步一律用 `v-click`（Slidev 用 opacity 隐藏、保留占位，**不顶跑**已有元素）；图组件内部的分步用 `visibility` 占位（固定尺寸 SVG 内也可用 `v-if`，不影响文档流）。
- 所有图包 `<div class="figure">`（零背景、零边框）；SVG 内不能写 `<Latex>`，量与单位用 `KaTeX_Math`（斜体）/ `KaTeX_Main`（单位）字体；图内文字按 16px 体系写、`font-size` 不带单位。
- 上屏的物理量与单位一律用 `<Latex tex="…" />`（HTML 块内不写 `$…$`）。
- 组件里的数值全部由真实公式 `computed` 算出（普朗克公式、ε = hν、λ = c/ν、1/ΔE），不写死。
- `exercise-split` 的具名 slot 写 `<template v-slot:stem>` / `<template v-slot:fig>`（不能写 `#stem`）；`#fig` 里图组件根 `<svg>` 必须有 `width` / `height` 固有尺寸，否则图栏塌成 0。

### 第 1 页 · 封面

- **标题**：不写 `#`（`course-cover` 读 headmatter 的 `title`：能量量子化）。
- **布局**：`course-cover`；frontmatter `chapter-no: "13.5"`、`chapter: "第十三章 电磁感应与电磁波初步"`、`subtitle: "从热辐射到能量子：能量是一份一份的"`。
- **上屏内容**：`<CoverDecorationSvg />`（右下角装饰：一条黑体辐射曲线 + 一组能级横线 + 一次向下的跃迁 + 一道光子波浪线，纯图形无文字）。
- **点击节奏**：0 击，常显。
- **交互组件**：无（静态装饰）。
- **教学意图**：装饰本身就是本课两条主线（黑体辐射曲线、能级跃迁）的预告，不占版面、不写小字。
- **物理依据**：教材 13.5 两节正文（热辐射 / 能量子 / 能级）。
- **用时**：0.5 分钟。

### 第 2 页 · 引课（整页不写标题）

- **标题**：不写；原话写进 frontmatter `title: "铁块为什么由暗红变到黄白"`（用于目录）。
- **布局**：`base-flex`；`clicks: 2`。
- **上屏内容**：
  - 常显：`.ask`「把铁块投进火炉：刚开始只是发热，并不发光；温度升高后，铁块慢慢变红、开始发光，依次呈现暗红、赤红、橘红，直至黄白色。为什么会有这样的变化？」
  - 第 1 击：`<IronColorSwatches />`（五段：不发光（发热）→ 暗红 → 赤红 → 橘红 → 黄白；上方一条「温度升高」箭头）。
  - 第 2 击：`<div class="info-hint">`「发热与发光是两个阶段：温度不够高时，热辐射里几乎没有可见光。」
- **点击节奏**：
  - 初始：只有问题，学生对着问题想「颜色为什么变」。
  - 第 1 击之后：看到教材现象本身——四段颜色与一条温度升高的方向，问题变得具体（「凭什么颜色会这样排？」）。
  - 第 2 击之后：得到第一个事实——发热与发光是热辐射的两个阶段，为 P3 的「室温时主要是不可见的长波」铺路。
- **交互组件**：`<IronColorSwatches />` 用页面 `v-click="1"` 整图出现（组件内不再分步：颜色序列是要一眼看全的现象，不是过程动画）。
- **教学意图**：用教材「问题」的原情境制造认知冲突——「颜色变化」需要一个关于辐射的解释。
- **物理依据**：教材 13.5「问题」原文 + 图 13.5-1（暗红、赤红、橘红、黄白色）。
- **用时**：2 分钟。

### 第 3 页 · 热辐射

- **标题**：写 `# 热辐射`（主题名，不给答案）。
- **布局**：`base-flex`；`clicks: 2`。
- **上屏内容**：
  - 常显：`.ask`「一切物体都在向外辐射电磁波，为什么我们平时看不见？」
  - 第 1 击：`<DefinitionBox term="热辐射" tone="gold">`「我们周围的一切物体都在辐射电磁波，这种辐射与物体的温度有关，叫作热辐射。物体在室温时，热辐射的主要成分是波长较长的电磁波，不能引起人的视觉。」
  - 第 2 击：`<div class="tip-hint">`「温度升高时，热辐射中波长较短的成分越来越强。铁块温度足够高时才有可见光，于是我们看到它发光。」
- **点击节奏**：
  - 初始：问题（「看不见」的疑问）。
  - 第 1 击之后：得到热辐射的定义，以及「室温时主要成分是长波、不可见」——问题的答案落地。
  - 第 2 击之后：拿到本课第一个核心规律「温度升高 → 短波成分越来越强」，为 P5 的曲线和 P2 的颜色作解释。
- **交互组件**：无。
- **教学意图**：把「辐射」与「看得见」分开，纠正「不发光的物体不辐射」这一前概念。
- **物理依据**：教材 13.5「热辐射」第 1 段。
- **用时**：2.5 分钟。

### 第 4 页 · 黑体

- **标题**：写 `# 黑体`。
- **布局**：`base-flex`；`clicks: 3`。
- **上屏内容**：
  - 常显：`.ask`「一切物体都在辐射，也都在反射外界的电磁波——研究热辐射时，为什么要挑黑体？」
  - 第 1 击：`<div>`「物体表面还会吸收和反射外界射来的电磁波。常温下我们看到的不发光物体的颜色，就是反射光所致。」
  - 第 2 击：`<DefinitionBox term="黑体" tone="blue">`「如果某种物体能够完全吸收入射的各种波长的电磁波而不发生反射，这种物体就叫作黑体。黑体虽然不反射电磁波，但是却可以向外辐射电磁波。」
  - 第 3 击：`<div class="tip-hint">`「黑体辐射电磁波的强度按波长的分布只与它的温度有关——所以研究热辐射的规律时，人们特别注意对黑体辐射的研究。」
- **点击节奏**：
  - 初始：问题（为什么挑黑体）。
  - 第 1 击之后：明白「反射光」会混进来，直接看物体颜色并不干净。
  - 第 2 击之后：得到黑体的定义（且强调「不反射 ≠ 不辐射」，这是易错点）。
  - 第 3 击之后：问题回答——黑体辐射只由温度决定，是研究热辐射规律的理想对象。
- **交互组件**：无。
- **教学意图**：从「反射光的干扰」过渡到「只与温度有关」的理想模型，说明引入黑体的必要性。
- **物理依据**：教材 13.5「热辐射」第 2 段。
- **用时**：2 分钟。

### 第 5 页 · 黑体辐射的强度分布

- **标题**：写 `# 黑体辐射的强度分布`（主题名）。
- **布局**：`base-flex`；`clicks: 4`。
- **上屏内容**：
  - 常显：`.ask`「黑体辐射的强度怎样按波长分布？温度改变时，这条分布曲线怎样变？」
  - 第 1–3 击：`<BlackbodySpectrum :step="$clicks" />`（整图包在 `v-click="1"` 里，随第 1 击出现；横轴 λ（单位 nm）、纵轴「辐射强度（相对）」，**刻度数字全关**；图底常显一条按波长上真实颜色的可见光—紫外—红外色带；三条曲线对应温度 <Latex tex="T_1<T_2<T_3" />，每出一条曲线同时画出它到横轴的峰值虚线）。
  - 第 4 击：`<div class="tip-hint">`「温度升高（<Latex tex="T_1<T_2<T_3" />），各波长的辐射强度都增大，峰值向短波一侧移动——短波成分越来越强。同样的道理，铁块温度越高，发出的光里短波成分越多，颜色就由暗红变到黄白。」
- **点击节奏**：
  - 初始：只有问题与空白图位（`v-click` 占位，后面元素不跳）。
  - 第 1 击之后：看到最低温那条曲线（峰值偏长波一侧）——只凭文字想不出「分布」长什么样。
  - 第 2 击之后：较高温曲线叠上来（整条抬高、峰值左移），两条曲线可比较。
  - 第 3 击之后：最高温曲线，三条一起看，规律成立。
  - 第 4 击之后：结论与**回扣引课**（铁块颜色）。
- **交互组件**：`BlackbodySpectrum`，页面传 `:step="$clicks"`（组件内曲线、峰值虚线、温度标注用 `showAt` 分步，隐藏用 `visibility` 占位）。
- **物理依据**：教材「热辐射」第 1 段「大量实验结果表明，辐射强度按波长的分布情况随物体的温度而有所不同」＋ 能量子段「黑体辐射的强度按波长分布」；三条曲线只作图像观察，不把某条曲线说成「铁块在某个温度下的真实曲线」（教材只写「短波成分越来越强」，本课**不引入维恩位移定律公式**、也不标具体温度值）。
- **定性页要求**：本页是教材没有配图的图像化（保留与否见第六节问题 1，实现前待老师拍板）；若保留，只做「曲线整体抬高 + 峰值向短波一侧移动」的定性差异：坐标轴不标任何刻度数字；温度用符号 <Latex tex="T_1" />、<Latex tex="T_2" />、<Latex tex="T_3" /> 标注，不写具体开尔文值（教材没有温度数据，铁块也到不了几千开）。
- **用时**：3 分钟。

### 第 6 页 · 经典理论遇到的困难（整页不写标题）

- **标题**：不写（这是纯提问/思考页）；frontmatter `title: "经典理论遇到的困难"`。
- **布局**：`focus-question`（整页一个大问题，学生停留思考）；`clicks: 2`（`#hint`、`#answer` 由布局自带 `v-click`）。
- **上屏内容**：
  - 常显（默认 slot）：「用经典的电磁理论，能解释黑体辐射的实验规律吗？」
  - 第 1 击（`#hint`）：「经典理论的思路：物体中的带电微粒不停振动，产生变化的电磁场，从而发出电磁辐射。」
  - 第 2 击（`#answer`）：「按这套经典理论算出的结果，与实验规律严重不符——微观世界的某些规律，在我们宏观世界看来可能非常奇怪。」
- **点击节奏**：
  - 初始：整页只有大问题，留出讨论时间（约 30 秒）。
  - 第 1 击之后：回忆起「带电微粒振动 → 电磁辐射」这条经典解释链，知道经典理论并非没有说法。
  - 第 2 击之后：冲突揭晓——说法有了，结果不符；同时给出教材的态度句，为普朗克的假设做心理准备。
- **交互组件**：无（用布局的思考页形态，不塞图）。
- **教学意图**：制造认知冲突，让「能量子假设」是必经之路而不是天上掉下来的公式。
- **物理依据**：教材「热辐射」第 3 段（「用经典的电磁理论解释黑体辐射的实验规律时遇到了严重的困难」）＋「能量子」第 1 段（「微观世界的某些规律在我们宏观世界看来可能非常奇怪」）。
- **用时**：1.5 分钟。

### 第 7 页 · 能量子

- **标题**：写 `# 能量子`（主题名）。
- **布局**：`base-flex`；`clicks: 3`。

1. **跃迁箭头终点不在能级线上（物理/图示硬伤）**：能级画在 y = 296、206、152、118，而激发箭头画到 y = 156（落在 n = 3 与 n = 2 之间）、向下箭头画到 y = 292（落在 n = 1 线下方 4 个单位）——学生看到的是「跃迁不到能级上」，与「跃迁到某一能级」直接冲突。
2. **入射电子的画法自相矛盾**：一个「电子」圆点 + 一条斜箭头 + 一条从底部竖直向上的箭头，图上没有原子主体，读者无法判断哪个是入射电子、哪个是被激发的原子——教材说的是「原子受到高速运动的电子的撞击而跃迁到较高能量状态」，图中却像「电子自己升到高能级」。
3. **缺「光子能量 = 能级差」的呈现**：光子只有一条波浪线和「光子」二字，没有与 <Latex tex="h\nu" />、能级差挂钩的标注，P14 的谱线图也就失去了依据。

重做要求：箭头起点/终点**精确落在能级线**（与能级线共用同一份 y 坐标数组）；激发用「向上箭头 + 文字标注（被高速电子撞击）」表达，不画电子卡通；两次向下跃迁各放一个光子；能级间距「越高越密」（定性，不标数值）；不引入 E_n 公式与 eV 数值；分步用 `visibility` 占位。
