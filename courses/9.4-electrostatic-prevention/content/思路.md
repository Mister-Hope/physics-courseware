## 1. 课时定位（40 分钟）

### 1.1 教材知识点顺序（照教材，不重排）

1. 问题：加油站加油前为什么要触摸静电释放器（299–301）
2. 静电平衡：感应电荷 → 感应电场 $E'$ → 内部合场强 $E_{\text{内}}=0$（303–307）
3. 尖端放电：电荷只在外表面 → 尖端电荷密度大 → 空气电离 → 异种电荷中和 → 尖端放电；避雷针、高压设备光滑表面、电晕（309–315）
4. 静电屏蔽：空腔导体内表面无电荷、壳壁 $E=0$、腔内 $E=0$；金属网也能屏蔽；高压线屏蔽线（317–329）
5. 静电的危害：手术台、煤矿的静电火花（331）
6. 科学漫步：雷火炼殿（333–343）
7. 静电吸附：静电除尘、静电喷漆、静电复印（345–355）

### 1.2 时间分配（到环节）

### 1.3 与前一节 / 后一节的衔接

- **学生已经学过**（9.1–9.3，教材口径）：金属中有自由电子、静电感应、电荷守恒、元电荷；库仑定律；电场、电场强度 $E=\dfrac{F}{q}$、点电荷场强 $E=k\dfrac{Q}{r^2}$、电场强度的叠加、电场线、匀强电场。
- **本节要用**：静电感应解释导体两侧的感应电荷；用矢量叠加解释导体内部合场强为零；用电场线描述"电场线不进入导体内部"；用 $F=qE$ 解释带电微粒向电极运动。
- **本节不引入**：电势、电势差、电容（第十章内容）；静电平衡只用场强叠加解释，不用电势论证，避免超前。
- **下一节衔接**：10.1 电势能和电势、10.3 电势差与电场强度；本节建立的"导体内部 $E=0$"和"带电微粒受静电力"是后续电容器、带电粒子在电场中运动的基础。

### 1.4 本课时学生最典型的错误理解（P16 专门撞）

1. "静电平衡时导体内部没有电荷"——教材说"没有**净**电荷"；自由电子和正离子仍在，只是净电荷为零，电荷只分布在外表面（311）。
2. "尖端电荷总数更多"——教材说的是**电荷密度**（单位面积的电荷量）更大，周围场强更大（311）。
3. "静电屏蔽必须用密封金属壳"——金属网也能屏蔽（329）。
4. "静电平衡时导体内部场强为 0，所以导体表面场强也为 0"——内部为 0，表面附近不为 0，尖端附近更强（307、311、313）。
5. "避雷针是把雷引到地下"——教材的口径是：雷雨云接近时金属棒静电感应出异种电荷，通过**尖端放电**把电荷释放到大气中、中和空气中的电荷，从而避免雷击（315）。
6. "静电屏蔽是金属把电场线挡住了"——更准确的说法是：导体表面感应电荷重新分布，使导体壳壁和空腔内的合场强为 0（321）。

### 3.1 单个组件细化

#### 3.1.1 `ConductorEquilibriumDemo`（P4）

- 屏幕上长什么样：左栏占满；上排是外电场（水平向右的等间距 `CourseArrow`），中间是矩形导体 $ABCD$（深色玻璃质感、圆角），下排是一条滑块（外电场 $E_0$）与三格读数。$AB$ 侧画 $-$、$CD$ 侧画 $+$，导体内部画一条向左的 $E'$ 箭头。
- 交互：初始 $E_0=60\ \text{N/C}$，导体内没有电荷；第 1 击后出现感应电荷、$E'$ 和读数，并自动播放"感应电荷从 0 积累到 100%"的过程动画（约 $1.5\ \text{s}$），动画中 $E'$ 从 0 长到 $E_0$、$E_{\text{内}}$ 从 $E_0$ 降到 0；拖动 $E_0$ 时外电场线密度、感应电荷数量、$E'$ 长度同步变化；第 2 击出现"$E_{\text{内}}=0$"平衡标记。
- 物理公式：$\vec E_{\text{内}}=\vec E_0+\vec E'$；因 $E'$ 与 $E_0$ 反向，$E_{\text{内}}=E_0-E'$；$E'=\eta E_0$（$\eta$ 是"感应电荷积累程度"的内部过程量，$0\le\eta\le1$，由动画驱动、**不设滑块、不参与结论口径**）；平衡条件 $\eta=1\Rightarrow E'=E_0\Rightarrow E_{\text{内}}=0$。
- 参数范围与边界值：$E_0=20\ \text{N/C}$ 时感应电荷少、$E'$ 短；$E_0=100\ \text{N/C}$ 时感应电荷多、$E'$ 长；动画起点 $\eta=0$ 时 $E'=0$、$E_{\text{内}}=E_0$，动画终点 $\eta=1$ 时 $E_{\text{内}}=0$。
- 分步 prop：`step`（0/1/2），页面写 `:step="$clicks"`；`step=1` 触发一次性过程动画，`step=2` 显示平衡标记；所有标注用 `visible` 切换，不用 `v-if` 顶跑。
- 不上屏的提示：不写"拖动滑块试试"；只保留 $E_0$ 一条滑块，屏幕上不出现 $\eta$ 的数值或"积累程度"字样。

#### 3.1.2 `TipDischargeDemo`（P6）

- 屏幕上长什么样：左栏占满；一个带正电的尖端导体（针尖朝上），周围画空气分子（中性小球）；放电时分子分裂为 $+$、$-$ 小球，电子向尖端运动、正离子远离；下方两条滑块与读数。
- 交互：拖动 $r$、$U$ 改变 $E_{\text{尖}}$；当 $E_{\text{尖}}\ge E_b$ 时状态变为"放电中"，动画播放；低于阈值时状态"未电离"、动画停止，只保留文字说明；教师把参数调回放电区即可继续。第 1/2/3 击分别显示电离、更多带电粒子、异种粒子中和尖端电荷。
- 物理公式：$E_{\text{尖}}=\dfrac{U}{r}$（把尖端近似为半径 $r$ 的球面，同一导体等势；**这是演示模型、不是通用结论**；$U$ 取尖端相对环境/大地的电位差，代码注释里必须写清这个参考点）；电离条件 $E_{\text{尖}}\ge E_b$，取 $E_b\approx3\times10^6\ \text{V/m}$（空气击穿场强的常用近似）。
- 参数范围与边界值：$r=5\ \text{mm}$、$U=5\ \text{kV}$ 时 $E_{\text{尖}}=1\times10^6\ \text{V/m}<E_b$，不放电；$r=0.5\ \text{mm}$、$U=50\ \text{kV}$ 时 $E_{\text{尖}}=1\times10^8\ \text{V/m}\gg E_b$，强烈放电。
- 分步 prop：`step`（0/1/2/3），页面写 `:step="$clicks"`。
- 不上屏的提示：屏幕上只出现读数与"未电离 / 放电中"状态，**不出现 $E_{\text{尖}}=\dfrac{U}{r}$ 的公式与推导**；组件注释里写明"演示模型、$U$ 为相对环境/大地的电位差、非通用结论"；是否允许这个定量化见 §7 问题 2。

#### 3.1.3 `ShieldingDemo`（P10）

- 屏幕上长什么样：左栏占满；左边带正电金属球（画 $+$），右边验电器（金属球、金属杆、两片箔片）；两者之间画距离 $r$；`mode=1` 时验电器外出现金属网，`mode=2` 时出现封闭金属壳；下方 $Q$、$r$ 两条滑块与读数。
- 交互：拖动 $Q$、$r$ 改变无屏蔽时的场强；页面第 1/2/3 击切换 `mode` 0/1/2；箔片张开角度按 $E$ 的大小作**定性映射**（无公式，饱和处理），屏蔽时夹角为 0；读数从 $E=k\dfrac{Q}{r^2}$ 变为 $0$。
- 物理公式：无屏蔽时带电球在验电器处产生的场强 $E=k\dfrac{Q}{r^2}$，$k=9.0\times10^9\ \text{N}\cdot\text{m}^2/\text{C}^2$（把带电球近似为点电荷）；屏蔽时 $E_{\text{内}}=0$（静电平衡，321/323）。
- 参数范围与边界值：$Q=3\times10^{-8}\ \text{C}$、$r=10\ \text{cm}$ 时 $E=2.7\times10^4\ \text{N/C}$；$r=5\ \text{cm}$ 时 $E=1.08\times10^5\ \text{N/C}$；$r=20\ \text{cm}$ 时 $E=6.75\times10^3\ \text{N/C}$；$Q$ 增大时箔片张开角度定性增大，屏蔽后始终为 0。
- 分步 prop：`mode`（0/1/2），页面写 `:mode="$clicks <= 1 ? 0 : $clicks - 1"`；不再额外加 `step`，文字解释由页面 `.info-hint` / `.tip-hint` 承担。
- 不上屏的提示：不写"拖动滑块试试"；屏幕上不出现箔片张角数值；组件注释里写明"张角为**定性映射**、无公式"；金属网不画"接地"（教材演示未要求接地，329 的高压线屏蔽线才接地）。

#### 3.1.4 `ElectrostaticPrecipitatorDemo`（P14）

- 屏幕上长什么样：左栏占满；右侧竖直板状收集器 $A$（标 $+$），左侧线状电离器 $B$（标 $-$）；中间画电场线（靠 $B$ 密、靠 $A$ 疏）和粉尘颗粒；底部漏斗；下方电源开关、电压滑块与读数。
- 交互：断电时粉尘充满、烟雾弥漫；接通后 $B$ 附近空气电离，电子向 $A$ 运动，粉尘变负电并向 $A$ 运动、吸附，最后落入漏斗；拖动电压 $U$ 改变场强和粉尘漂移速度。
- 物理公式：粉尘受力 $F=qE$，加速度 $a=\dfrac{F}{m}$；同一装置 $E\propto U$；因 $q<0$，$F$ 与 $E$ 反向，指向正极 $A$。教材只给"距 $B$ 越近，电场强度越大"（351），组件内部按此定性分布画场线，不显示编造的 $E$ 数值。
- 参数范围与边界值：$U=20\ \text{kV}$ 时场强弱、漂移慢；$U=100\ \text{kV}$ 时场强强、漂移快；断电时 $E=0$，粉尘不被收集。
- 分步 prop：`step`（0/1/2/3），页面写 `:step="$clicks"`；电源开关也可由教师单独操作。
- 不上屏的提示：不写"拖动滑块试试"；不显示 $E$ 的具体数值（教材没有给出该装置的场强分布），只显示 $U$ 与"电场强弱"的相对条。

## 5. 物理正确性自检

| 关键结论 / 表述（上屏原文） | 教材出处 | 易错点 / 说明 |
| --------------------------- | -------- | ------------- |
| "把一个不带电的金属导体放到电场强度为 $E_0$ 的电场中，由于静电感应，$AB$ 侧感应出负电荷，$CD$ 侧感应出正电荷。" | 305 | 感应电荷是自由电子定向移动的结果；不要写成"正电荷被吸引过来"。 |
| "感应电荷在导体内部产生与 $E_0$ 方向相反的电场 $E'$。" | 307 | $E'$ 是感应电荷产生的，不是外电场本身。 |
| "直到导体内部各点的电场强度 $E=0$ 为止，自由电子不再发生定向移动，导体达到静电平衡。" | 307 | 平衡是电子继续移动、直到合场强为零的结果；不要因果倒置。 |
| "处于静电平衡状态的导体，其内部的电场强度处处为 $0$。" | 307 | P16 第 4 条（**正确**说法）；只说"内部"，表面附近不为 $0$（311 尖端周围场强更大）。 |
| "静电平衡时，导体内部没有净电荷，电荷只分布在导体的外表面。" | 311 | "没有净电荷"不等于"没有电荷"；金属内部仍有自由电子和正离子（31）。 |
| "在导体外表面，越尖锐的位置，电荷的密度（单位面积的电荷量）越大，周围的电场强度越大。" | 311 | 不是"尖端电荷总数更多"；P16 专门撞这一条。 |
| "强电场使空气分子中的正负电荷分离，这个现象叫空气的电离。" | 313 | 电离是空气分子分离，不是"尖端吸引空气中的电荷"。 |
| "与尖端电荷符号相反的粒子，由于被吸引而奔向尖端，与尖端电荷中和，相当于导体从尖端失去电荷。" | 313 | 尖端电荷符号不同，奔向尖端的粒子符号也不同；不要固定说"电子跑向尖端"。 |
| "避雷针：尖锐金属棒 + 粗导线 + 埋地金属板，与大地良好接触；雷雨云接近时静电感应，尖端放电释放电荷、中和空气中的电荷，避免雷击。" | 315 | 不要写成"避雷针把雷引到地下"；教材口径是尖端放电中和。 |
| "尖端放电会造成高压设备电能损失，所以高压设备中导体表面应尽量光滑；夜间高压线周围的绿色光晕是电晕。" | 315 | 电晕是微弱的放电现象，不是普通的"发光"。 |
| "空腔导体：静电平衡时内表面没有电荷，导体壳壁 $W$ 内 $E=0$，空腔内 $E=0$；无论外部电场怎样，导体内部都没有电场。" | 321 | 推理链是"内表面无电荷 → 壳壁 $E=0$ → 腔内 $E=0$"，不要跳步。 |
| "金属壳（或金属网）内部的电场强度保持为 $0$，外电场对壳内仪器没有影响，叫静电屏蔽。" | 323、329 | 金属网也能屏蔽；教材没有要求"必须接地"才能屏蔽外电场。 |
| "三条输电线上方还有两条导线，它们与大地相连，形成一个稀疏的金属'网'，把高压线屏蔽起来，使其免遭雷击。" | 329 | 这里是屏蔽线，不是避雷针；屏蔽线接地。 |
| "医院手术台上，静电火花可能引起麻醉剂爆炸；煤矿里，静电火花会引起瓦斯爆炸。" | 331 | 静电火花是引发爆炸的原因，不是"静电本身爆炸"。 |
| "金殿是优良导体；云层与金殿顶部之间形成巨大电压，使空气电离，产生电弧（闪电）；电弧使周围空气剧烈膨胀而爆炸，看似火球。" | 339 | "火球"是电弧与空气膨胀的视觉效果，不是燃烧。 |
| "金殿顶部很少有带尖的结构，不易放电，所以能使电压升得比较高，保证'炼殿'之需。" | 341 | 少尖 → 不易尖端放电 → 电压更高；与避雷针"有尖 → 易放电"形成对照。 |
| "静电吸附：带电粒子受到静电力作用，向着电极运动，最后被吸附在电极上。" | 347 | 利用的是静电力，不是分子力或重力。 |
| "静电除尘：$A$ 板接正极，$B$ 线接负极；距 $B$ 越近场强越大；$B$ 附近空气电离；电子向 $A$ 运动使粉尘带负电；粉尘吸附到 $A$，重力作用下落入漏斗。" | 351 | 粉尘最终到正极 $A$；正离子被吸到负极 $B$。 |
| "静电喷漆：接负高压的涂料雾化器喷出的油漆微粒带负电，向作为正极的工件运动并沉积。" | 353 | 漆滴带负电，工件是正极。 |
| "静电复印：OPC 鼓没有光照时是绝缘体，受到光照时变成导体。" | 355 | 教材正文只给 OPC 特性；图 9.4-9 的五步流程未展开，见 §7 问题 4。 |
| "加油站触摸静电释放器" | 299–301（问题）+ 315/329（接地）+ 331（静电火花危害） | 教材只提问、未给答案；本方案按"人体带电 → 触摸接地释放器 → 电荷转移 → 避免火花"综合讲，口径见 §7 问题 1。 |
| "点火器钉尖 / 验电器金属球" | 78（习题 4）+ 311/313/315 | 点火器用尖端放电产生电火花；验电器用球面避免尖端放电使电荷流失。 |
