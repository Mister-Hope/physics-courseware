## 交互式组件

| 组件                    | 功能                                                                                                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ElevatorScaleSim`      | 电梯 + 电子秤模拟：上升/下降三段运动（加速→匀速→减速，时长与图像同源），点击画面暂停/继续；`standalone`（独占一页放大）、`hide-panel`（隐藏楼层/状态面板） |
| `ElevatorFtGraph`       | 示数–时间图像（0–28 s）：静止参考线常显，点击依次出上升、下降曲线与超重/失重色块、极值标注                                                                 |
| `ElevatorVtGraph`       | $v\text{-}t$ 图像：上升/下降梯形（圆角过渡），虚线切出加速/匀速/减速三段                                                                                   |
| `ElevatorStateTable`    | 六种运动状态表：`reading` 模式先出现象、再出运动状态；`accel` 模式逐个出加速度方向                                                                         |
| `SquatRiseFtGraph`      | 下蹲–站起 $F\text{-}t$ 实测曲线，4 步揭示（mg 线、分段线、超失重区间、阶段名与加速度方向）                                                                 |
| `BeakerBallRise`        | 木球上浮动画：球加速上浮、水流箭头循环下流、秤读数同步下降（点击播放一次）                                                                                 |
| `ScaleReadout`          | 七段数码管读数（切角火柴棍、未点亮段留淡影），两门秤共用                                                                                                   |
| `PersonWeightSvg`       | 人站在体重秤上：$mg$、$F_N$、可选的 $F_N'$ 与运动/加速度箭头，支持电梯框与读数                                                                             |
| `SpringScaleHangingSvg` | 弹簧测力计悬挂重物（$F_T=mg$、读数）                                                                                                                       |
| `WaterBottleSvg`        | 侧壁开孔的水瓶：静止喷水 / 自由下落不喷水                                                                                                                  |
| `VideoSlot`             | 16:9 视频槽（本课为 H.264 转码后的电梯实拍）                                                                                                               |
| `CurlyBraceSvg`         | 过程树的花括号                                                                                                                                             |
| `CoverDecorationSvg`    | 封面装饰                                                                                                                                                   |

## 授课提醒

- 第 6 / 8 / 9 / 10 页的模拟靠**点击电梯画面**暂停，可停在最大/最小示数上讲解；
- 第 17 页的动画点图播放一次，示数会随小球上浮先降后回升；
- 示数只显示数字、不标单位（视频里并未给出单位）。
