# 超重和失重 — 授课思路

> 本文按老师的口述思路整理（课件定稿后同步更新）：先用弹簧测力计和体重秤讲清「秤称的是什么」（视重），
> 再用电梯实测视频与可暂停的模拟还原示数的变化，由示数–时间图像给出超重、失重的定义，
> 然后按「运动状态 → 示数与重力 → 加速度方向 → 牛顿第二定律」逐层推进，
> 最后到完全失重、水的实验与三个例题，收在课堂小结与思考题上。

## 课题与教学定位

**课 题**：超重和失重（§4.6）

**教学重点**：

1. 秤的读数（视重）是它受到的拉力或压力，不等于重力；超重、失重都是视重相对重力的变化
2. 用牛顿第二定律把视重与加速度方向联系起来，得到「只看加速度方向」的判据
3. 完全失重（$a = g$ 向下）的物理含义

**难 点**：区分「重力」与「视重」；摆脱「上升就超重、下降就失重」的直觉，改为用加速度方向判断

**教 具**：弹簧测力计、钩码、体重秤；电梯实测视频（1 楼到 4 楼）、电子秤模拟；水瓶、木球与烧杯

---

## 一、引课：如何测重力（视重）

- 重力不能直接测量。弹簧测力计测的是它受到的**拉力**：物体静止时二力平衡，$F_T = mg$，读数才反映重力。
- 再用体重秤：人站在秤上，秤的读数是人对秤的**压力** $F_N'$；静止时 $F_N = mg$，$F_N' = F_N$。
- 这两个读数都叫**视重**。视重不是重力——只有静止或做匀速直线运动时才等于重力。

## 二、两个问题（承上启下）

1. 我们测出的这个力，什么条件下才等于重力？
2. 如果这个条件不满足，可能出现哪些情况？

（公开课版只抛问题、口头带出答案；自读版把答案写在屏幕上：加速度为零时相等；不相等时大于重力叫超重、小于叫失重。）

## 三、电梯实测：先看现象

- 播放电梯实测视频（商场电梯，1 楼到 4 楼，跨三层）：秤上放一只盒子，读数 11.36 起步。
- 上升过程：读数最大到 12.58、最小到 10.08；下降过程：先到 10.20、再到 12.54。
- 示数在变，而盒子所受的重力没有变——变的是视重。

## 四、可暂停的电子秤模拟（把视频里看不清的地方重复给学生看）

- 点「上升」或「下降」，轿厢运动、两侧楼板滚动，秤上读数按实测数值同步变化；
- **点一下电梯画面就暂停**，可以停在最大/最小示数处讲解，再点一下继续；
- 电梯按时长比例走完「加速 → 匀速 → 减速」，匀速段占一半以上（与 v–t 图像一致）。

## 五、由示数–时间图像给出定义

- 上升、下降各画一条示数随时间的曲线，与「静止时的示数」比较：
  - 示数**大于**重力 → **超重**；示数**小于**重力 → **失重**（定义内容与教材一致）。
- 强调：重力 $mg$ 始终不变，变的只是视重。

## 六、上升、下降各三个阶段 + v–t 图像

- 电梯上升、下降都经历**加速 → 匀速 → 减速**三个阶段（用过程树把六个阶段列出来）。
- 右侧配 $v$–$t$ 图像：斜率就是加速度，起停处的圆角表示加速度连续变化（不突变），
  虚线切出三段，正好对应六个阶段。

## 七、把「示数」和「运动状态」对起来

- 表格先只给「示数与重力相比」这一列（大于 / 等于 / 小于 / 小于 / 等于 / 大于），
  逐行点出现象（超重 / — / 失重 / 失重 / — / 超重），再点出对应的运动状态（加速上升 …… 减速下降）；
- 让学生自己把「示数变化」与「电梯在做什么」一一对应。

## 八、加速度的方向

- 六个状态逐个点出加速度方向：上升时 ↑、0、↓，下降时 ↓、0、↑。
- 共同点：超重时加速度向上，失重时加速度向下——**只跟加速度方向有关，与运动方向无关**。

## 九、为什么（牛顿第二定律）

- 竖直方向有加速度，合力就不为零：$F_{\text{合}} = ma \ne 0$，支持力不再与重力平衡。
- 加速度向上（取向上为正）：$F_N - mg = ma$ ⇒ $F_N = m(g+a) > mg$，超重。
- 加速度向下（取向下为正）：$mg - F_N = ma$ ⇒ $F_N = m(g-a) < mg$，失重。
- （公开课版这一页只有问题，推导由老师口头讲＋板书；自读版把两条推导留在屏幕上。）

## 十、判据的应用：人蹲下、站起

- 体重计的 $F$–$t$ 实测曲线：先下蹲——加速下降（失重）→ 减速下降（超重）；
  再站起——加速上升（超重）→ 减速上升（失重）；静止后示数回到重力。
- 用第九步的判据逐段判断，再用曲线核对。

## 十一、完全失重

- 张老师站在电梯里，电梯以 $a = g$ 向下加速下落：取向下为正，$mg - F_N = mg$ ⇒ $F_N = 0$，秤的读数为 0，脚对地板也没有压力。
- 完全失重：加速度向下且 $a = g$ 时，视重为 0。

## 十二、水的实验

- 瓶侧壁扎孔，静止时水从孔中喷出；让瓶子自由下落，水不再流出——
  瓶和水都以 $a = g$ 下落，水不再挤压瓶壁，也就不会流出。

## 十三、例题

1. **超重的代价**：火箭发射加速度 $3.5g$，平时重 10 N 的脏器需要 45 N 的支持力。
2. **蹦极**：绳拉直前完全失重；拉直后速度仍增大时失重；速度减小时超重。
3. **木球上浮**：剪断细绳后木球加速上浮、水被挤着向下流，系统重心加速下降 ⇒ 示数先突然变小、再逐渐回到原值。
   先让学生只看木球得出「示数变大」的错解，再打叉、讲清为什么错，最后点出答案；老师口述两种情形（球还在加速就到顶 / 已经匀速才到顶）。

## 十四、小结与思考题

- 小结：视重 → 超重 → 失重 → 完全失重；重力 $mg$ 始终不变。
- 思考题：如果物体的加速度大于 $g$ 会怎样？（支持力不可能为负——人会离开地板、被顶棚压住。）
