## 一、老师口述原文（逐字保留）

首先从位移引入，回顾教材1.2里面的位移。
然后呢，我们找一个讲台上的毛巾，或者说找一把尺子，强调矢量不仅有大小，还有方向。然后，我们可以举一个大宝剑的例子，比如说呢，你拿剑呢，是只能拿着剑柄的啊，箭头要冲人，你不可能握着剑尖儿然后用剑柄去冲人。所以说呢，位移并不是描述位置，而是描述了物体位置的变化量，然后再引入两个平行且大小相等的位移是完全相同的，

这个时候呢，就再引入数学向上的概念，然后呢，理解一下，物理上的矢量和标量，其实对应在数学上是向量和数，然后点出核心区别，这里面就要做一页PPT了，就是矢量、标量和向量，和数对应的一个PPT。然后区别就是矢量和标量是具有实际意义的物理量，具有单位，而数学上的向量和数是抽象的。

接下来呢，让大家理解了向量矢量，它都是没有实际的起始点，那么呢，我们就把地平面内所有向量的起点改为1点。那么建立一个平面直角坐标系，那么地面上发生的所有位移，换句话就可以变成呢，用平面上每个点的坐标来表示。每个点的坐标呢，就对应着从坐标系原点到这个点坐标产生的那条唯一的向量。

接下来就是我们要做几个演示去让同学们理解向量的加法规律。首先，回顾位移的加法表示，引导学生位移呢，是需要把后一个位移的起点和前一个位移的终点重合。那么我们就先建立一个坐标系，然后画出A点和B点，设坐标是X 1 Y 1 X 2 Y2, 然后把B的起点从原点平移到A的终点，这样就能产生一个平行四边形。这个是要点击做一个动画的。然后画出来之后呢，我们就知道中点的位，这个时候B的中点的位置啊，应该叫B撇的中点的位置，就是这个A+B, 然后就能知道它的位移很很方便能算出来是X1+X2，Y1+Y2。所以说呢，我们就能得到了加法的表达式类似的。然后提问同学减法的运算怎么算？先给出一个问题，然后，同学应该能自然想到负A就是把A的坐标反过来是负X1，负Y1这样类似的就能得出来减法的规律，比如说是X1-X2，Y1-Y2。然后呢，我们再来观察就能够得到向量是满足交换律和结合律的，也就是说在加法和减法里面我们可以使用交换律和结合律。

然后呢，带领同学们思考用点来描述向量的时候进行了何种的科学简化。那这个呢，实际上我们把一个向量抽象成43这样的点对的时候，实际上我们告诉他了X轴应该是4个单位长度，Y轴是应该3个单位长度。我们可以理解为X轴上的四个单位长度的向量依次相加，然后再加上Y上的3，单位为3的这样一个不长度为3个标准单位的一个向量，比如说X上的长度为4的向量和Y上的3的向量加加出来的向量，就是我们最终的向量，这是唯一的。所以说呢，我们这个时候再引入正交分解，也就是说呢，我们为了方面去计算向量，我们实际上在数学去加减坐标的时候，实际上就把这个向量重新沿着X轴和沿着Y轴，把它分解成了两个互相投影为零的这样两个子向量。然后分别在一条直线上去应用向量的加减法规律得到新的坐标，然后再把它拼回原向量，让学生理解这么一个事儿。然后这里面呢，我们也正常就正好引入了这个单位向量的意义，。以及正交分解这样一个非常重要的东西。同时再复习一下，向量是遵守平行四边形法则和三角形法则的，当然也有多边形法则，也就是说向量的下一个的头沿连着前一个的多边形变形法则。

然后就引入了一个例题，就一个正六边形A，顺时针ABCDEO这个O点是有E的，然后我们让它算什么呢，如果这个正六边形边长是1米，那么OAOBOCODOE，嘉禾的心的位移的大小和方向是哪里？然后我们就可以有几种方式都带大家练一下。板书要展示，就是我们的课件要展示。第一个是通过平行四边形法则把OB挪到CE上去，然后把OD挪到AC上去，这样的话就能快速地得出来是6m的结论。第二个就是常规思路，用正向分解。

## 二、结构化整理

### 教学目标

1. **认对象**：从位移出发认识矢量（大小 + 方向），理清矢量/标量与向量/数的对应与区别。
2. **学运算**：掌握矢量的加法（平行四边形法则 / 三角形法则）与减法（减法化为"加上相反矢量"），知道坐标表示下"对应坐标相加、相减"。
3. **懂方法**：理解"用坐标表示矢量"这一步科学简化，引入**单位向量**与**正交分解**：沿两坐标轴分解 → 分别作一维加减 → 再合成。
4. **建条件**：理解多个矢量（首尾相接）之和为 0 的条件——链末端回到起点、构成闭合多边形。

### 例题细节（已核算，请老师确认）

**题**：正六边形的顶点依次为 $A,B,C,D,E,O$（顺时针，$O$ 是第六个顶点），边长 $1\,\text{m}$，求
$\overrightarrow{OA}+\overrightarrow{OB}+\overrightarrow{OC}+\overrightarrow{OD}+\overrightarrow{OE}$ 的大小和方向。

> 口述原文是"顺时针 ABCDEO，这个 O 点是有 E 的"，理解为**顶点依次 A、B、C、D、E、O**（$O$ 是正六边形的一个顶点，不是中心）。若按"$O$ 为中心"算，这五个（六个）矢量两两抵消、合位移为 0，得不到 6 m。

**解法一（平行四边形 / 三角形法则拼合）**

- $\overrightarrow{OB}=\overrightarrow{EC}$（把 $\overrightarrow{OB}$ 平移到 $E$ 点起，终点正好落在 $C$）→ $\overrightarrow{OE}+\overrightarrow{OB}=\overrightarrow{OC}$
- $\overrightarrow{OD}=\overrightarrow{AC}$（把 $\overrightarrow{OD}$ 平移到 $A$ 点起，终点正好落在 $C$）→ $\overrightarrow{OA}+\overrightarrow{OD}=\overrightarrow{OC}$
- 于是总和 $=(\overrightarrow{OA}+\overrightarrow{OD})+(\overrightarrow{OB}+\overrightarrow{OE})+\overrightarrow{OC}=3\overrightarrow{OC}$
- $O$ 与 $C$ 是相对顶点（直径），$|\overrightarrow{OC}|=2\,\text{m}$ → **合位移 $6\,\text{m}$，方向沿 $\overrightarrow{OC}$（由 $O$ 指向 $C$）**

**解法二（正交分解，常规思路）**

以 $O$ 为原点、$\overrightarrow{OC}$ 方向为 $x$ 轴正方向（正六边形中心在 $(1,0)$，外接圆半径 $=1\,\text{m}$）：

| 矢量                  | 坐标 / m                    |
| --------------------- | --------------------------- |
| $\overrightarrow{OA}$ | $(0.5,\;\frac{\sqrt3}{2})$  |
| $\overrightarrow{OB}$ | $(1.5,\;\frac{\sqrt3}{2})$  |
| $\overrightarrow{OC}$ | $(2,\;0)$                   |
| $\overrightarrow{OD}$ | $(1.5,\;-\frac{\sqrt3}{2})$ |
| $\overrightarrow{OE}$ | $(0.5,\;-\frac{\sqrt3}{2})$ |
| **合矢量**            | $(6,\;0)$                   |

y 方向两两抵消 → 合位移 $6\,\text{m}$，方向沿 $x$ 轴正方向（即 $\overrightarrow{OC}$）。
