# 矢量与向量 — 公开课交互式课件

> 原创：张伯望（东北育才学校） ｜ 人教版必修第一册 · 第一章「数学扩展」 ｜ 在线地址：**[https://courseware.mister-hope.com/1.x-vectors/](https://courseware.mister-hope.com/1.x-vectors/)**

一节课的主线：**从位移出发，把"方向"装进算式里**——认识矢量/标量与向量/数的区别 → 矢量可以自由平移 → 起点搬到原点、建坐标系 → 加减法与运算律 → 正交分解与单位向量 → 多个矢量之和为 0 的条件 → 正六边形例题。

## 授课提醒

- **实物环节**：讲台上有直尺 / 宝剑就真的比划——横放斜放长度一样但指向不同；握剑只能握剑柄（现在安排在第 3 页）。
- **例题的顶点命名**：正六边形 `OABCDE`（顺时针），**O 是顶点、不是中心**（`O` 与 `C` 是相对顶点、`|OC| = 2 m`），所以合位移是 6 m 沿 `OC`；若按"O 为中心"讲，答案会变成 0。
- **本课不提"向量 ÷ 向量"**（教师明确要求）：学生数学基础弱，一提就会联想叉乘、除法；第 5 页只留「矢量、向量有自己特殊的运算法则」。
- **先问后答**：几乎每页都是"提问 → 点击出图 / 出结论"，初始态只显示标题 + 提问是有意为之（不是留白 bug）。
- 页码以定稿版为准（迭代期间页序可能调整）。
