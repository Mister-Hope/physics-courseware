> 这是一个‘速度决定力、力又反过来改变速度’的死循环。在高中阶段我们没有微积分工具，怎么去解开这个死结？今天我们用一种极其巧妙的力学思想——**配速法**。”

## 幻灯片 3：【核心攻坚】任意时刻的“力与速度记账法”（破解“转偏失效论”）

### 1. 课件视觉画面设计

- **核心动图演示（核心教学逻辑）**：
  - **左侧：速度三角形（任意时刻 $t$）**
    画出此时此刻小球斜向右下方的实际速度 $\vec{v}_{\text{实}}$。
    在画面上将其拆为两笔“账”：一条水平向右恒定的矢量 $\vec{v}*0$，一条倾斜的矢量 $\vec{v}*{\text{转}}$（构成矢量三角形：$\vec{v}_{\text{实}} = \vec{v}_0 + \vec{v}_{\text{转}}$）。
  - **右侧：力的三角形（几何整体旋转 $90^\circ$ 动效）**
    将左侧的速度三角形，整体顺时针旋转 $90^\circ$ 并放大 $qB$ 倍，生成对应的洛伦兹力三角形：
    真实的洛伦兹力 $\vec{F}_B = \vec{f}_0 + \vec{f}_{\text{转}}$。
    - $\vec{f}_0$：由 $\vec{v}_0$ 产生，**永远严格竖直向上**，大小恒为 $qv_0B$。
    - $\vec{f}_{\text{转}}$：由 $\vec{v}_{\text{转}}$ 产生，**永远垂直于 $\vec{v}\_{\text{转}}$**，大小恒为 $qv_{\text{转}}B$。
  - **中心碰撞动效**：将重力箭头 $mg$ 移到 $\vec{f}_0$ 处，设 $Bqv_0 = mg$，两箭头对冲变灰（彻底抵消）。

### 2. 课件版面文字清单

- **数学拆解自由度**：在任意时刻，真实速度均可唯一分解为：$\vec{v}_{\text{实}}(t) = \vec{v}_0\text{（恒定向右）} + \vec{v}_{\text{转}}(t)$。
- **洛伦兹力的刚性旋转性**：速度矢量旋转 $90^\circ$ 对应力矢量，故真实洛伦兹力恒等分解为：$\vec{F}_B = \vec{f}_0 + \vec{f}_{\text{转}}$。
- **全天候对冲**：
  令 $qv_0B = mg \implies v_0 = \frac{mg}{qB}$（恒定向右）。
  $\vec{F}_{\text{总}} = (mg\downarrow + \vec{f}*0\uparrow) + \vec{f}*{\text{转}} = 0 + \vec{f}_{\text{转}} = \vec{f}_{\text{转}}$。
- **结论**：无论小球转到何种角度，重力每分每秒都被 $\vec{f}_0$ 抵消；剩余分运动受力时刻垂直于速度，必为**匀速圆周运动**！

### 3. 配套讲课台词与教案（针对学生困惑的核心攻坚）

> **教师讲述（重中之重）**：
> “现在，很多同学心里会有一个极大的困惑：
> _‘老师，开始时两个速度向左向右共线，后面一旦转起来，圆周速度方向就斜了，两速度根本不共线了！真实受力也斜了，那个向右的假想速度产生的力，怎么还能刚好抵消竖直向下的重力？’_
>
> 请大家紧盯黑板上的这两个平行四边形！
> 实际小球只有一个，它的真实速度 $\vec{v}_{\text{实}}$ 在空中乱转。但是，数学上，我无论在任何一微秒，都可以把这个实际速度强行记账记成两项：一个恒定向右的 $\vec{v}_0$，加上剩下的速度 $\vec{v}_{\text{转}}$。
> 因为洛伦兹力永远垂直于速度，**速度平行四边形旋转 $90^\circ$，就是力的平行四边形！**
> 只要你拆出来的 $\vec{v}_0$ 永远水平向右，它分担出来的洛伦兹力 $\vec{f}_0$ 就**必定永生永世竖直向上**！
> 只要我们取 $v_0 = \frac{mg}{qB}$，那么无论小球运动到哪里、转成了什么样子，在每一微秒，**重力都会被分力 $\vec{f}\_0$ 精准、干净地冲抵掉！**
>
> 全场重力消失了，剩下的唯一真实合力就是 $\vec{f}_{\text{转}}$。而 $\vec{f}_{\text{转}}$ 永远垂直于 $\vec{v}_{\text{转}}$，大小永远不变——它不是标准的匀速圆周运动，还能是什么？！”

## 幻灯片 4：【运动合成与原题求解】静止释放的摆线全貌

### 1. 课件视觉画面设计

- **画面展示**：
  - **初态匹配（$t=0$）**：真实速度为 $0$。借了一个向右的 $v_0 = \frac{mg}{qB}$，必须还一个小球一个向左的初速度 $\vec{v}_{\text{转}0} = -v_0$。
  - **动态轨迹生成（滚轮滚动线/摆线）**：
    展示一个半径为 $R$ 的圆轮，轮心以速度 $v_0$ 沿水平虚线向右平移，轮子同时以角速度 $\omega$ 顺时针转动。
    轮缘原本在顶点的标记点，随着转动和向前平移，在空中画出一道完美的周期性**摆线（Cycloid）**。
- **关键极值标注图**：
  - 标注最高点（尖点）：$v=0, a=g\downarrow$。
  - 标注最低点：$v_{\max} = 2v_0 = \frac{2mg}{qB}$，下落最大高度 $h_{\max} = 2R$。

### 2. 课件版面文字清单（核心公式推导）

1. **分运动 1（匀速直线）**：$v_0 = \frac{mg}{qB}$，方向水平向右。
2. **分运动 2（匀速圆周）**：初速度大小为 $v_0$，方向向左；顺时针转动。
   - 半径：$R = \frac{m v_0}{qB} = \frac{m^2g}{q^2B^2}$
   - 周期：$T = \frac{2\pi m}{qB}$
3. **原题结论导出**：
   - 下落最大深度（峰谷差）：$h_{\max} = 2R = \frac{2m^2g}{q^2B^2}$
   - 最低点最大速度（两速度同向叠加）：$v_{\max} = v_0 + v_0 = 2v_0 = \frac{2mg}{qB}$
   - **能量验证**：由动能定理，$\Delta E_k = \frac{1}{2}m v_{\max}^2 = \frac{1}{2}m (2v_0)^2 = 2mv_0^2$；重力做功 $W_G = mgh_{\max} = mg(2R) = 2mg\frac{mv_0}{qB} = 2mv_0^2$。完全自洽！

### 3. 配套讲课台词与教案

> **教师讲述**：
> “把两个分运动合成起来：小球一边以 $v_0$ 匀速向右漂移，一边绕着中心转圈。这在几何上叫作‘摆线’，就像自行车车轮滚过地面时，车轮边缘那颗气门芯在空中划出的轨迹！
> 我们可以一眼看出极值：
> 在最低点，匀速分速度向右，圆周分速度也转到了向右，两者同向，速度达到最大，正好是 $2v_0$；
> 下落的最大高度，正好就是圆周运动的直径 $2R$！无需列任何复杂的动能定理或微分方程，几何图形一画，答案瞬间秒杀。”

## 幻灯片 6：【能力拓展】当小球具有任意初速度 $\vec{v}_{\text{初}}$ 时的通用法则

### 1. 课件视觉画面设计

- **核心图解**：
  - 左图：展示初速度 $\vec{v}_{\text{初}}$ 任意倾斜（大小不为零、方向任意角 $\theta$）。
  - 矢量减法图：
    $$\vec{v}_{\text{圆0}} = \vec{v}_{\text{初}} - \vec{v}_{\text{平}}$$
    用高一矢量三角形直观展示：从平衡分速度 $\vec{v}_{\text{平}}$ 的箭头末端，指向真实初速度 $\vec{v}_{\text{初}}$ 的箭头末端。
- **右侧展示：三种不同的轨迹演变形态（动画演示）**：
  1. **临界摆线（尖点摆线）**：当 $|\vec{v}_{\text{圆0}}| = v_{\text{平}}$（即静止释放或初态合速度为0）。
  2. **短摆线/波浪线（无尖点、平滑起伏）**：当 $|\vec{v}_{\text{圆0}}| < v_{\text{平}}$（向右的漂移速度压过了转动速度，轨迹全程向前）。
  3. **长摆线/结环摆线（有打圈闭合回路）**：当 $|\vec{v}_{\text{圆0}}| > v_{\text{平}}$（转动速度大于漂移速度，在最高处向左逆行打圈）。

### 2. 课件版面文字清单（通用解题三步法）

无论带电粒子初始速度 $\vec{v}_{\text{初}}$ 方向如何、大小如何，统统一套标准流程：

- **第 ① 步：锁定恒定平衡速度 $\vec{v}\_{\text{平}}$（只看恒力与磁场）**
  - 只要重力 $mg$ 竖直向下，为抵消重力，平衡速度**必须且永远是**：
    $$v_{\text{平}} = \frac{mg}{qB} \quad (\text{方向水平向右})$$
- **第 ② 步：矢量减法确定圆周运动初状态 $\vec{v}\_{\text{圆0}}$**
  - 由运动合成关系 $\vec{v}_{\text{初}} = \vec{v}_{\text{平}} + \vec{v}_{\text{圆0}}$，得到：
    $$\vec{v}_{\text{圆0}} = \vec{v}_{\text{初}} - \vec{v}_{\text{平}}$$
  - 通过平行四边形定则求出其大小 $v_{\text{圆0}}$ 和初始偏角。
- **第 ③ 步：全盘输出运动学参数**
  - 匀速直线速度：$v_{\text{平}} = \frac{mg}{qB}$（决定整体水平漂移）。
  - 圆周运动半径：$R = \frac{m v_{\text{圆0}}}{qB}$（仅由相对速度的模长决定！）。
  - 运动周期：$T = \frac{2\pi m}{qB}$（恒定不变）。
  - 下落的最大落差：$h_{\max} = y_{\text{最高}} - y_{\text{最低}}$，由圆周运动的垂直跨度给出。

### 3. 配套讲课台词与教案

> **教师讲述**：
> “掌握了本质，我们就能降维打击所有变式！如果考题变难，小球不是静止释放，而是一开始就有一个斜向上的初速度 $\vec{v}_{\text{初}}$，我们还怕不怕？
> 记住通解法则三步走：
>
> **第一步，‘天塌下来有它顶着’：**
> 重力是不会变的吧？向里的磁场是不变的吧？那么负责抵消重力的平衡速度，**就雷打不动永远是水平向右的 $\frac{mg}{qB}$**！这叫底盘速度，谁来都改不了。
>
> **第二步，‘扣除底盘算相对速度’：**
> 题目给了真实的初速度 $\vec{v}_{\text{初}}$，我们只要扣掉向右的 $\vec{v}_{\text{平}}$，剩下的矢量差就是圆周运动的初速度：$\vec{v}_{\text{圆0}} = \vec{v}_{\text{初}} - \vec{v}_{\text{平}}$。
>
> **第三步，‘看大小定轨迹’：**
>
> - 如果算出来的圆周初速度正好等于向右的漂移速度，就是我们刚才讲的尖点摆线；
> - 如果初速度顺着漂移方向给，扣掉后剩下的圆周速度很小，小球就像一列高速向右行驶的列车里慢慢晃悠，轨迹变成平缓的波浪形；
> - 如果逆着漂移方向给了一个很大的速度，圆周速度大于漂移速度，小球就会在空中一边翻跟斗、一边向右走，画出结环的优美螺线！
>
> 任凭风浪起，万变不离其宗。这就是‘配速法’带给我们化繁为简的物理之美！”
