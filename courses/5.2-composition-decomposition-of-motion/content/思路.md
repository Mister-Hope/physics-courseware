# 运动的合成与分解 — 授课思路

> 本文是老师授课思路的原文整理（含本轮明确调整：用**抓娃娃机**替代教材的蜡块实验；不做平抛超前内容；小船渡河讲完整）。
> 只放思路本身，不写迭代记录与待确认清单。

## 教案表头（老师手写教案）

- 课题：运动的合成与分解
- 教学目标：
  1. 能建立合理的平面直角坐标系，并用函数方式描述曲线运动（原稿字迹：曲线运动 / 直线运动）；
  2. 能对简单平面运动进行合成与分解；
  3. 能掌握"把复杂的运动分解为简单的运动"的思想。
- 教学重点：① 对常规运动的分解；② 对应用中的运动能做到合成与分解。
- 难点：船过河问题。
- 教学方法：讲授法。教具：板书。

## 一、引入：复杂运动可以拆成几个简单运动

- 无人机航拍、挖掘机、龙门吊——它们的动作都很"灵活"。
- 挖掘机：电机 → 臂 → 挖斗，每个电机只管一个关节。
- 龙门吊：3 个互相垂直方向的电机 → 3 个互相垂直方向的运动。
- 无人机：不直接控制 4 个风扇，靠算法抽象成 3 个方向的运动 + 水平旋转。
- 收束：复杂运动 = 几个简单运动的叠加；平面运动拆成 2 个互相垂直方向，空间运动拆成 3 个方向。
- 正交分解的落点：分别求出每个方向上的 a、v、x，运动就描述清楚了。
- 思想：**替代法**——用分运动"替代"原来的运动状态；分运动 ⇌ 合运动（合成 / 分解）。

## 二、新课：用抓娃娃机把一个平面运动拆开

- 情境：抓娃娃机的爪上方有两个电机，一个控制爪的 x 坐标（横梁左右移动），一个控制爪的 y 坐标（吊索收放、升降）。
- 先问："爪为什么能斜着走到娃娃上方？是谁在指挥它？"
- 演示一：只开 1 号电机 → 爪只沿水平方向匀速移动；只开 2 号电机 → 爪只沿竖直方向匀速移动。→ 这是两个**分运动**。
- 演示二：两个电机同时开 → 爪斜着运动，轨迹是一条直线。→ 这是**合运动**；斜线不是第三个电机给的，而是两个分运动共同的效果。
- 建立坐标系：以爪的起点为原点，x 轴水平向右、y 轴竖直向上。
  - 位置随时间变化：$x = v_x t$、$y = v_y t$；
  - 消去 $t$ 得 $y = \frac{v_y}{v_x}x$——轨迹是过原点的直线。
- 合速度：$v = \sqrt{v_x^2 + v_y^2}$，方向 $\tan\theta = \frac{v_y}{v_x}$（速度是矢量，按平行四边形定则合成，与 3.4 力的合成一致）。
- 概念落地：分运动 / 合运动、运动的合成 / 运动的分解，遵从矢量运算法则。
- 推广：描述运动的三个量都按矢量合成——合速度 $v = \sqrt{v_x^2 + v_y^2}$、合加速度 $a = \sqrt{a_x^2 + a_y^2}$、合位移 $s = \sqrt{x^2 + y^2}$（位移用 $s$ 或 $r$ 表示，避免出现 $x_x$ 这种下标）。
- 变式：1 号电机匀加速、2 号电机匀速 → 轨迹变成曲线（$x = \frac{1}{2}at^2$、$y = v_y t$）。
  - 落点：**分运动都是简单的直线运动，合运动却可以是曲线运动**——这就是研究曲线运动的办法。

## 三、参考系变换与速度合成公理（要讲透，不是渡河专用）

- 先给生活情境：传送带上往前走——传送带上的人看你走多快、地面上的人看你走多快？（两个答案，速度是相对的）
- 用两栏动画对照同一件事：地面参考系（带在走）／传送带参考系（带不动、地面在退）。
- **公理**：$v_{A对C} = v_{A对B} + v_{B对C}$。
  - 读法：$v_{A对B}$ 就是"在 B 的参考系里看 A 的速度"；
  - 在 C 系里看 B 的运动，叠加在 B 系里看 A 的运动，就是 C 系里看 A 的运动；
  - 这是**普遍规律**（不是渡河专用），矢量相加，与合成/分解同一套法则。
- 渡河里的具体形式：$v_{船对岸} = v_{船对水} + v_{水对岸}$——船的实际速度等于船对水的速度与水对岸的速度的矢量和。

## 四、难点：小船渡河（讲完整）

- 教材问题：人始终保持头朝正前方游向对岸，会在正前方到达，还是偏向上游 / 下游？→ 偏向下游。
- 渡河时间由哪个分速度决定、靠岸点偏到哪里，都要用分运动算。
- 目标一（渡河时间最短）：船头垂直河岸。
  - $t_{min} = \frac{d}{v_{船}}$，与水流速度无关；
  - 漂移距离 $x = v_{水}t$，靠岸点偏向下游。
- 目标二（渡河位移最短）：让合速度垂直河岸，船头偏向上游。
  - 船头与河岸（上游方向）的夹角 $\theta$ 满足 $\cos\theta = \frac{v_{水}}{v_{船}}$；
  - $t = \frac{d}{\sqrt{v_{船}^2 - v_{水}^2}}$，位移等于河宽 $d$。
  - 前提是 $v_{船} > v_{水}$；若 $v_{水} > v_{船}$，到不了正对岸，最短位移 $s = d\cdot\frac{v_{水}}{v_{船}}$（此时合速度与船头垂直）。

## 五、关联速度（重点扩展，要讲全）

- 核心一句话：**沿约束方向的速度分量相等**——绳不可伸长、杆不能伸缩、接触面不嵌入也不分离。
- 为什么：绳两端沿绳方向的分量必须相等，否则绳被拉长或压缩；垂直绳的分量不传递，只让绳绕端点转动。
- 三步法：① 找合速度（物体真实的运动方向）② 沿约束方向分解 ③ 写"分量相等"列式。
- 三个模型，由易到难：
  1. **绳**：人在高岸收绳拉船 → $v_{船}\cos\theta = v_0$，$v_{船} = \frac{v_0}{\cos\theta}$（船比绳快，越靠岸越快）。
  2. **杆／绳—环**：两根互相垂直的杆上各套一个环、用等长绳相连 → $v_A\cos\theta = v_B\sin\theta$，$v_B = v_A\cot\theta$。
  3. **接触面**：光滑墙角处斜劈被下落的球挤开 → $v_0\cos\theta = v_{劈}\sin\theta$，$v_{劈} = v_0\cot\theta$（沿接触面法线方向分量相等）。
- 练习：斜靠在墙上的杆（$u = v\cot\theta$）、收绳拉船取 $\theta = 60^\circ$、$v_0 = 0.5\ \text{m/s}$ 求船速。

## 六、课堂小结

- 一个平面运动可以拆成两个互相垂直方向上的分运动（正交分解）。
- 分运动与合运动之间由矢量运算法则联系：合成、分解都遵守平行四边形定则。
- 速度合成公理：$v_{A对C} = v_{A对B} + v_{B对C}$，普遍适用。
- 渡河两类问题：要快（船头垂直河岸）还是要正（船头偏向上游）。
- 关联速度：绳／杆／接触面，沿约束方向的分量相等，三步法列式。
