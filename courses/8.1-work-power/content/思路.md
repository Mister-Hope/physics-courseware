> 教师口述原文整理（语音转写中的同音错误按上下文纠正：牛·米、`1 + cos α = 2cos²(α/2)`）。

## 课时划分

- **第一课时：只讲功。** 功的定义 → 表达式 → 说明 → 地面参考系辨析 → 合力与分力做功 → 一组做正功/做负功/不做功的辨析 → 判断做功看哪里 → 一对相互作用力做功 → 滑轮例题。
- **第二课时：先复习功，再讲功率的定义与 `P = Fv`，然后是一节"功和功率"的专题课**，主要讲机车启动一类的问题。
- 这两块内容一节课根本讲不完，所以第一课时就只到功为止。

## 一、功的定义与表达式（三件事必须上屏）

1. **功的定义：力在位移上的累积。**
   （书上原话要对应一下——教材 8.1 的定义句是"力对物体所做的功，等于力的大小、位移的大小、力与位移夹角的余弦这三者的乘积"。）
2. **功的表达式**：`W = Fx cosα`。这时还没有学点乘，`α` 是 `F` 和位移 `x` 的夹角。
3. **`x` 是哪个位移**：`x` 通常情况下是**以地面参考系衡量**的。
   后面有专门一页辨析，这里**直接写在 PPT 上**、不作解释，让学生先集中记笔记，后续再理解。

## 二、关于功的说明

- 功是**标量**，它有正负。
- 单位是**焦耳**：`1 J = 1 N·m = 1 kg·m²/s²`。
- 由公式强调三种情况：
  - `α = π/2` 时 `W = 0`；
  - `0 ≤ α < π/2` 时 `W > 0`，做正功；
  - `π/2 < α ≤ π` 时 `W < 0`，做负功，**也叫物体克服外力所做的功**。
- **比较功的大小：比较绝对值。** 功的正负代表**能量传递的方向**——`W > 0` 时施力物体给受力物体提供能量，`W < 0` 时受力物体给施力物体提供能量。也就是说，`-5 J` 的功比 `3 J` 的功要大。标量正负的意义就在这里点明。

## 三、地面参考系辨析（单开两页，这是个难点）

**第一页（匀速）**：一个 50 kg 的人站在公交车里，用 100 N 的力向前推公交车的栏杆；公交车以 4 m/s 向前运动。问：前 2 s 内，**手对公交车**做了多少功？**人对公交车**做了多少功？

- 手对公交车做的功"有数"，人对公交车做的功是**零**。
- 从主观感受上讲，我们确实觉得自己是不做功的。为什么人手又做功了？看起来矛盾的原因，是我们平常判断自己做功，是在**我们自己的参考系**下。
- 以常规的地面参考系看：手受到栏杆向左的 100 N 的力，同时脚受到公交车地板向右的 100 N 的力，正好抵消——所以人对公交车的合作用力为零。

**第二页（匀加速）**：把公交车的运动改成**从静止开始以 4 m/s² 的加速度做匀加速**，一样的分析，并且**深入一点**：

- 用第四章的牛顿第二定律可以看出，**摩擦力和手的推力是不相等的**：人也要跟着一起加速，所以脚受到的摩擦力比重力、比手的推力都大（`F_f = F + ma`）。
- 这时候**做功就有差值**了：手对车做的功还是那么多，但脚对车做的功更大，合起来人对车做的功是个负值——反过来说，**人的能量在凭空上升**。
- 简单点一下原因：**因为人的速度在增大，运动起来的能量变大了**（动能）。后续会专门讲，这里正好提一下，**不深入**。

## 四、合力做功与分力做功

- 一个物体所受**合力做的功，等于分力做功的代数和**。
- 这里也可以对力进行合成分解；但**因为功是标量，这里不能用平行四边形法则**。

## 五、一组辨析：做正功、做负功，还是不做功

1. **加速跑**的时候，地面摩擦力对人做的功？——**不做功**。
2. **蹲下后站起来**时，地面支持力做的功？——**不做功**。
3. **椭圆形操场，缓慢拉动行李箱走一圈**，手对行李箱做的功？——**正功**。（这里不需要辨析，但需要画个小草图。）
4. **压缩弹簧**时弹簧做的功？——呈现答案的时候，画一个 `F-x` 图像：点击后右侧出现一堆小条（`Δx` 足够小时，`F` 可以认为是恒力），再点一下就变成一个三角形的面积；由此得出 `W = ½kL²`。
   这里正好做一个辨析：**手对弹簧做了一个正功，而弹簧的弹力做了一个负功，弹簧把能量存起来了**。

## 六、判断做功看哪里

- 作为问题设上去：一个人是否做功，看头、看心，还是看脚？
  答案是**根本不看任何特定部位**——看**力的作用点**：作用点在力的方向上有投影，那就是有功；没有投影，就是不做功。
- 辨析**平板支撑、扎马步为什么这么累**：尽管没有位移，但人为了完成这个动作，肌肉需要时刻紧绷；肌肉紧绷就要消耗糖原，实际上是**化学能转化为内能**。
- **秋千**可以构成一个粗略的单摆，这时绳的**拉力不做功**，因为拉力时刻与速度垂直。

## 七、功有多大（量级感）

- 强调人体是很省电的：**一度电可以供人跑十多公里**。
- 电学上一度电是 `1 kW·h`，也就是 `1 kW` 的功率工作 1 小时；每秒能产生 1 kJ 的功。
- 算一下一度电是多少焦的功，是相当大的；可以把一度电和一个人做比较——**它能把人举高多少**。

## 八、一对相互作用力做功

- **作用力和反作用力做的功没有关系**：作用力做正功、不做功或者做负功，反作用力都可能是这三种里的任意一种。
- 举例：
  - 一个做正功、一个做负功：**一对静摩擦力**（叠放物块一起加速）；
  - 都做正功：**两块磁铁 N 极靠拢，然后松手**；
  - 一个做正功、一个不做功：**摁住一块磁铁，看另一块磁铁动**；
  - 都做负功：**用夹子夹住一个东西、用手往两边拽**，它们之间的滑动摩擦力都做负功；
  - 一个做负功、一个不做功：**拉着桌子在地面上拖行**，桌面与地面之间那一对摩擦力。
- 这些辨析希望在**整页都是示意图**。

## 九、例题：滑轮拉物体

- 一个物体前面有一个滑轮；一根绳从墙面连过来，跨过定滑轮，然后再绕回来，有一个力 `F` 拉着。也就是说，这根绳被系在它**运动方向前面**的那面墙上，另一边用手拉着。
  问：在这种情况下，物体前进 `L` 做了多少功？
- 答案是 `F × 2L`。因为要看**力的作用点**的位移：物体进 `L`，绳头前进了 `2L`。
- 再问：和地面摩擦有没有关系？——**没有关系**。
- 进阶：如果手拉的方向与水平面成 `α` 角斜向上拉，物体还是走了 `L`，问做了多少功？**两种方式**：
  1. 先算两段绳的拉力的合力（物体和定滑轮之间那段绳不是水平的，而是倾斜的），算它的夹角实际上是 `α/2`；用合力的大小 `2F cos(α/2)` 再乘 `cos(α/2)`、再乘 `L`。
  2. 算**绳头的位移**：绳头的位移也是一条与水平面成 `α/2` 角的平行四边形的对角线，和 `F` 之间还有一个 `cos(α/2)` 的夹角。
- 两种方式用 `1 + cos α = 2cos²(α/2)` 正好得到两种不同形式的解，实际上是等价的。**这个题非常精彩。**

## 第二课时：功率与机车启动（口述整理）

### 一、先复习功的概念（两道题）

1. **钉钉子**：钉子受到的阻力与钉入的深度成正比；假设**每次锤击做的功相同**，问各次钉入的深度之比。
   - 结论：`1 : (√2 − 1) : (√3 − √2) : … : (√N − √(N−1))`；第 `n` 锤再钉进去 `(√n − √(n−1))·x₁`。
   - 讲法落到"每锤给的能量一样，但越往后阻力做的功越贵"。
2. **提塑料袋**：装满水的塑料袋静止放着，拽**侧边**往上提、或捏住**底部的角**往上拉，做的都是**正功**——一定会使重心升高、重力势能升高（袋子"自然"就是重心最低的摊平状态）；从能量角度讲，是我们使它的能量增大了。
   - **这一题定性讲即可，不画图。**

### 二、功率

- 复习初中：`P = W/t`；单位**瓦特**（`1 W = 1 J/s`、`1 kW = 1000 W`），瓦特简称"瓦"。
- 由 `W = Fx cosα` 推出 `P = Fv cosα`（第一课时只讲了 `F` 沿位移方向的特例 `P = Fv`，第二课时要说明这是力与位移成 `α` 角的一般情形）。
- 强调**瞬时功率与平均功率**；**力与速度垂直时不做功**（功率为零）；功率也是**标量、有正负**；恒力时平均功率＝力 × 平均速度。
- 教材里好的解析与思考过程**先保留**：`P = Fv` 中 `v` 是平均速度 ⇒ 平均功率，间隔非常小 ⇒ 瞬时功率；"思考与讨论"＋换挡旁注（功率一定时 `F` 与 `v` 成反比，效果有限，要提高额定功率）。

### 三、机车问题

- **真实车辆为什么有最高速度（纯定性）**：车往前走时阻力随速度增大——地面摩擦大体不变，**风阻**随速度明显增大，还有**传动系统的阻力**；而额定功率下能提供的牵引力 `F = P/v` 随速度减小；两者相等时车就不再加速，这就是真实车辆有最高速度的原因，再想快只能提高额定功率。**不写数值、不写次数。**
- **机车启动题（阻力严格恒定，题给条件 `f₀`）**：
  1. **恒定功率启动**：`P–t`、`F–v`、`F–(1/v)`、`a–t`、`v–t`、`a–(1/v)` **六个图像各用一页**给答案并解析。
  2. **恒定加速度启动**：问匀加速阶段能达到的最大速度——`v₁ = P₀/(f₀ + ma)`，**小于** 刚才算的 `v_max = P₀/f₀`。
  3. 再问：不能保持恒定加速度以后就保持最大功率，`v–t` 与 `F–(1/v)` 图像各是什么样。
- 全套只在"**阻力恒定**"这个题设下讲；真实情况（风阻、传动阻力）另起一页定性辨析，**两套模型不混用**。

### 四、第二课时页序

第二课时封面 → 钉钉子（问题页 / 答案页）→ 提塑料袋（问题页 / 答案页）→ 功率的定义与单位 → `P = Fv cosα` 推导 → 平均功率与瞬时功率 → 辨析（垂直不做功、标量有正负、单位）→ 换挡与思考讨论 → 教材例题 2 → **真实车辆最高速度（定性）** → 恒定功率启动六图（问题页 + 6 页答案）→ 恒定加速度启动 → 之后保持最大功率的 `v–t`、`F–(1/v)` → 课堂小结。
