## 课件结构（16 页）

| 页码 | 内容                                      | 类型                           |
| ---- | ----------------------------------------- | ------------------------------ |
| 1    | 封面                                      | 渐变标题 + 呼吸动画            |
| 2    | 时间 位移 · 引入                          | 先问后答 + 两条线索            |
| 3    | 时刻与时间间隔（7:40 / 8:20）             | 先问后答                       |
| 4    | 时间轴：时刻是点，时间间隔是线段          | **TimeAxis 组件**              |
| 5    | 用坐标描述位置（长安街）                  | LaTeX + 正负坐标               |
| 6    | 位置的变化：选哪条路？（导航 12 km）      | 导航示意图 SVG + 先问后答      |
| 7    | 位移定义 + 矢量 / 标量                    | 定义卡片 + 双栏对比            |
| 8    | 直线运动位移：算一算                      | **DisplacementLine 组件**      |
| 9    | 思考与讨论：$x_A=5$、$x_B=2$              | 先问后答 + 公式                |
| 10   | 起点不同，位移可以相同                    | 双数轴对比 + 结论竖线          |
| 11   | 位移—时间图像（$x$-$t$ 图像）             | SVG 示例图 + 说明              |
| 12   | 位移和时间的测量（频闪照相 / 打点计时器） | 双栏对比 + 先问后答            |
| 13   | 两种打点计时器                            | **对比表格**（考试实际考点）   |
| 14   | 纸带：时间和位置的同步记录                | 纸带 SVG + 由此画出 $x$-$t$ 图 |
| 15   | 课堂小结（时间 / 位移）                   | 两块回顾，2 次点击             |
| 16   | 课后练习（位移计算）                      | 计算 + 先问后答                |

> - 第 6 页的位移引入不照抄教材“北京 → 重庆”，改为高德地图导航情境：去 12 km 外的公园，两条骑行路线 15 km / 18 km——15 km、18 km 是**路程**，12 km 是起点到终点的**直线距离**（最短路径），由此引出“由初位置指向末位置的有向线段”。
> - 第 12～14 页把“测量”拆成三页：**12** 两种测量手段（频闪照相 / 打点计时器 → 等时间间隔取样）；**13** 电磁式 / 电火花式打点计时器对比表（8 V / 220 V、振针 + 复写纸 / 放电针 + 墨粉纸盘、摩擦阻力大小），考试实际考点；**14** 纸带本身就同时记录了**时间**（数点：每 0.02 s 一个点）与**位置**（量距：各点到起点的距离），把每个点的 $(t,\ x)$ 描出来就是 $x$-$t$ 图像——这是本课要强调的落点。
> - 原“科学漫步：全球卫星导航系统”一页已删除（纯教材内容，与本课时考点无关）。

## 交互式组件

| 组件               | 功能                                                        |
| ------------------ | ----------------------------------------------------------- |
| `TimeAxis`         | 时间轴：显示时刻（点）与时间间隔（线段）                    |
| `DisplacementLine` | 一维位移计算：拖动 $x_1$/$x_2$ 滑块，实时 $\Delta x$ 与方向 |
