# 速度变化快慢的描述——加速度 — 公开课交互式课件

> 原创：张伯望（东北育才学校） ｜ 人教版必修第一册 1.4 ｜ 在线地址：**[https://courseware.mister-hope.com/1.4-acceleration/](https://courseware.mister-hope.com/1.4-acceleration/)**

**一个课件 = 一个课（一课时 40 分钟，19 页）**：从"百公里加速"引入，用两条 $v$-$t$ 直线把"速度变化的快慢"变成可比较、可计算的量，再由**比值定义法**类比出加速度，随后依次解决**方向**（$\Delta v$ 作图）、**读图**（$v$-$t$ 斜率）、**辨析**（$a$ 与 $v$ 无关的两个反例），最后三页总结。

## 课件结构（19 页，一课时）

| 页码 | 内容                                                                                        | 类型                            |
| ---- | ------------------------------------------------------------------------------------------- | ------------------------------- |
| 1    | 封面：§1.4 · 第一章 运动的描述                                                              | v-t 直线 + 斜率三角装饰         |
| 2    | 引入：跑车与家用轿车的百公里加速表（2.7 s / 3.9 s / 11.3 s / 13.2 s / 15.5 s）+ 四问        | 数据表 + 问题清单（整页常显）   |
| 3    | 只看"速度"描述不了一辆车 → 这个指标反映的是**速度变化的快慢** → 引出加速度                  | 双栏 + 2 次点击                 |
| 4    | 两条 $v$-$t$ 直线（都过原点、都到 $100\ \text{km/h}$）：哪一条是跑车的？                    | **图常显** + 2 次点击           |
| 5    | 为什么是 A：相同 $\Delta v$、不同 $\Delta t$ → 每 1 s 速度增加 $10.3$ 与 $2.46\ \text{m/s}$ | 算式对照 + 2 次点击             |
| 6    | **加速度的定义**：由 $v=\frac{\Delta x}{\Delta t}$ 类比出 $a=\frac{\Delta v}{\Delta t}$     | 类比双框 + 3 次点击             |
| 7    | 单位 $\text{m/s}^2$ 的来历与读法 + 教材"一些运动物体的加速度"表                             | 双栏 + 2 次点击                 |
| 8    | 加速度的方向：**先学会画 $\Delta v$**（$v_1$ 尖端 → $v_2$ 尖端）；$a$ 与 $\Delta v$ 同向    | Δv 作图 + 3 次点击              |
| 9    | 两种情形：加速（$a$ 与 $v$ 同向）/ 减速（反向）                                             | 双图对照 + 3 次点击             |
| 10   | 从 $v$-$t$ 图像看加速度：同样的 $\Delta t$ 内 $\Delta v$ 大者更陡；斜率正负 → $a$ 的方向    | 双图 + 3 次点击                 |
| 11   | 一段 $v$-$t$ 图像能读出多少信息（5 段运动：$+5$、$+12$、匀速、$-8$、越过 $t$ 轴）           | **`VTMotion` 交互** + 4 次点击  |
| 12   | 从 $v$-$t$ 图像还能读出什么：斜率在变 → $a$ 在变；$k$ 与 $v$ 同号加速、异号减速             | 三张小图 + 归纳（整页常显）     |
| 13   | 辨析提问页：加速度大，速度一定大吗？（只提问，不给答案）                                    | 整页常显（等待学生举例）        |
| 14   | 反例一：高铁高速飞驰（$v\approx83\ \text{m/s}$，$a=0$；图内铁轨枕木滚动，像列车在飞驰）     | 高铁 SVG（含动效）+ 2 次点击    |
| 15   | 反例二：荡秋千（最高点 $v=0$ 而 $a\ne0$；初始停在最高点，点一下放开）                       | **`SwingDemo` 交互** + 3 次点击 |
| 16   | 六个说法对六个物理量（位移大→$x$ 大 … 速度变化快→$a$）；"变化大＝变化量，变化快＝变化率"    | 六格对照 + 1 次点击             |
| 17   | 课后总结 ①：加速度的定义式 / 单位 / 方向                                                    | 三框 + 关键句（整页常显）       |
| 18   | 课后总结 ②：$x$-$t$ 图像要点（位置、斜率方向与大小、交点；面积与形状无意义）                | 图 + 五条要点（整页常显）       |
| 19   | 课后总结 ③：$v$-$t$ 图像要点（速度、斜率、交点、面积、远离/靠近 $t$ 轴）                    | 图 + 五条要点（整页常显）       |

## 交互式组件

| 组件        | 功能                                                                                                                                                                                                              | 页面 |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| `VTMotion`  | 5 段运动的 $v$-$t$ 图像：**点组件本身**播放／暂停／重来，小球沿图线运动，实时给出一行读数 `t = … s`、`v = … m/s`、`a = … m/s²` 与运动状态；当前段高亮并画出该段的 $\Delta t$–$\Delta v$ 直角三角形（斜率＝$a$）。 | 11   |
| `SwingDemo` | 荡秋千：单摆模型（$L=2.5\ \text{m}$、$\theta_0=30^\circ$，velocity-Verlet 数值积分）。**初始停在最高点**（$v=0$、$a\ne0$），点一下放开、再点暂停；$a$ 箭头只在最高点附近出现（此时加速度恰好沿切线，严格正确）。  | 15   |

> 两条 $v$-$t$ 直线、$\Delta v$ 作图、斜率弧线、高铁、两张总结图都是 `slides.md` 里的静态 SVG，没有单独做组件。
> 高铁图里的枕木用 CSS 动画横向滚动（0.15 s 一格，无缝循环），并用 `clipPath` 把枕木范围裁成与上下铁轨一致。
