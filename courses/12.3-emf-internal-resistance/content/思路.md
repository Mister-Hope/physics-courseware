## 第一部分：常规伏安法——电流表外接法（相对电源外接）

> **电路特征**：开关接在电源负极一侧（断开开关时电压表示数归零）；电压表并联在外电路（电流表 + 变阻器）两端（测路端电压），电流表只串在外电路中。

### 1. 测量原理与基本方程

根据闭合电路欧姆定律，列出两组测量值方程：

$$\begin{cases} U_1 = E - I_1 r \\ U_2 = E - I_2 r \end{cases}$$

解得测量值：

$$E = \frac{U_1 I_2 - U_2 I_1}{I_2 - I_1}, \quad r = \frac{U_1 - U_2}{I_2 - I_1}$$

### 2. 系统误差分析（三种分析方法）

- **【分析方法 1】计算法（方程修正）**
  - **误差根源**：电压表的分流作用。电流表的读数 $I$ 不是流过电源的真实电流 $I_0$，真实电流为 $I_0 = I + \dfrac{U}{R_V}$，所以 $I < I_0$。
  - **修正方程**：
    $$\begin{cases} E_0 = U_1 + \left(I_1 + \dfrac{U_1}{R_V}\right)r_0 \\ E_0 = U_2 + \left(I_2 + \dfrac{U_2}{R_V}\right)r_0 \end{cases}$$
  - **解得真值并对比**：
    $$E_0 = \frac{U_1 I_2 - U_2 I_1}{I_2 - I_1 - \frac{U_1 - U_2}{R_V}} > E, \quad r_0 = \frac{\frac{U_1 - U_2}{I_2 - I_1}}{1 - \frac{U_1 - U_2}{(I_2 - I_1)R_V}} > r$$
  - **结论**：$E_{测} < E_{真}$，$r_{测} < r_{真}$（测量值均小于真实值）。
- **【分析方法 2】图像法（$U-I$ 图像分析）**
  - 直线①（测量线）：根据测量值 $(I, U)$ 拟合的直线。
  - 直线②（真实线）：考虑电压表分流修正后的直线。
  - **特征**：当 $U = 0$ 时，电压表分流为 $0$，此时测量电流等于真实短路电流（两条线交于横轴 $(I_0, 0)$）；随着 $U$ 增大，分流越大，测量线偏离真实线越远。
  - **结论**：由图线纵轴截距及斜率绝对值可直观看出：$E_{测} < E_0$，$r_{测} < r_0$。
- **【分析方法 3】等效法（戴维南等效）**
  - 把**电压表和电源等效为一个新电源**：
    - 等效电源电动势（开路电压即电压表两端电压）：$E_{等} = \dfrac{R_V}{r_0 + R_V} E_0 < E_0$
    - 等效电源内阻（$r_0$ 与 $R_V$ 并联）：$r_{等} = \dfrac{r_0 R_V}{r_0 + R_V} < r_0$
  - **减小误差条件**：要求 $R_V \gg r_0$（普通干电池内阻很小，一般满足该条件，故常采用此接法）。

## 第二部分：常规伏安法——电流表内接法（相对电源内接）

> **电路特征**：电流表串联在电源干路上（测干路电流），电压表并联在滑动变阻器两端。

### 1. 测量原理与基本方程

同理，测两组数据根据 $U = E - Ir$ 解得 $E$ 和 $r$。

### 2. 系统误差分析（三种分析方法）

- **【分析方法 1】计算法（方程修正）**
  - **误差根源**：电流表的分压作用。电压表读数 $U$ 不是电源路端电压 $U_0$（$U < U_0$）。设电流表内阻为 $R_A$。
  - **修正方程**：
    $$\begin{cases} E_0 = U_1 + I_1(r_0 + R_A) \\ E_0 = U_2 + I_2(r_0 + R_A) \end{cases}$$
  - **对比结论**：电动势测量值 $E_{测} = E_0$（等于真实值）；内阻测量值 $r_{测} = r_0 + R_A > r_0$（测量值大于真实值，包含了电流表内阻）。
- **【分析方法 2】图像法（$U-I$ 图像分析）**
  - 当干路电流 $I = 0$ 时，电流表分压为 $0$，测量电压等于真实路端电压，即两图线在纵轴交于同一点（$U$ 轴截距相同，$E_{测} = E_0$）。
  - 测量直线的斜率绝对值包含 $(r_0 + R_A)$，倾斜程度更大，故 $r_{测} > r_0$。
- **【分析方法 3】等效法（戴维南等效）**
  - 把**电流表和电源等效为一个新电源**：$E_{等} = E_0$，$r_{等} = r_0 + R_A$。
  - **适用性评价**：要减小该接法的误差，需满足 $r_0 \gg R_A$。但实验室中电池内阻通常很小，这一要求很难满足，因此一般不用此接法测小内阻电池。

## 第三部分：实验方法拓展一——"伏阻法"（电压表 + 电阻箱）

### 1. 测量原理

用电压表测路端电压 $U$，电阻箱提供外电阻 $R$。由闭合电路欧姆定律：

$$E = U + Ir = U + \frac{U}{R} r$$

若测得两组数据 $(U_1, R_1)$ 和 $(U_2, R_2)$，联立可求得：

$$E = \frac{U_1 U_2 (R_1 - R_2)}{U_2 R_1 - U_1 R_2}, \quad r = \frac{(U_1 - U_2)R_1 R_2}{U_2 R_1 - U_1 R_2}$$

### 2. $\dfrac{1}{U} - \dfrac{1}{R}$ 图像法处理

将原原理方程两边同除以 $E \cdot U$，变形为线性方程：

$$\frac{1}{U} = \frac{1}{E} + \frac{r}{E} \cdot \frac{1}{R}$$

- **纵轴截距 $a$**：$a = \dfrac{1}{E} \Rightarrow E = \dfrac{1}{a}$
- **直线斜率 $k$**：$k = \dfrac{r}{E} \Rightarrow r = \dfrac{k}{a} = kE$
- **横轴截距 $-b$**（外推至 $\dfrac{1}{U} = 0$）：$-b = -\dfrac{1}{r} \Rightarrow r = \dfrac{1}{b}$

### 3. 误差分析

- **等效对应关系**：用公式计算的干路电流 $\dfrac{U}{R}$ 只是流过电阻箱的电流，电压表并联在两端产生分流，本质上**等效于电流表外接法**。
- **结论**：$E_{测} < E_{真}$，$r_{测} < r_{真}$（测量值均小于真实值）。

## 第四部分：实验方法拓展二——"安阻法"（电流表 + 电阻箱）

### 1. 测量原理

用电流表测干路电流 $I$，电阻箱提供外电阻 $R$。由闭合电路欧姆定律：

$$E = I(R + r)$$

测得两组数据 $(I_1, R_1)$ 和 $(I_2, R_2)$，联立得：

$$E = \frac{I_1 I_2 (R_1 - R_2)}{I_2 - I_1}, \quad r = \frac{I_1 R_1 - I_2 R_2}{I_2 - I_1}$$

### 2. 图像法处理（两种线性化形式）

- **形式一：$\dfrac{1}{I} - R$ 图像**：$\dfrac{1}{I} = \dfrac{1}{E} R + \dfrac{r}{E}$
  - 斜率 $k = \dfrac{1}{E} \Rightarrow E = \dfrac{1}{k}$
  - 纵轴截距 $a = \dfrac{r}{E} \Rightarrow r = \dfrac{a}{k}$
  - 横轴截距 $-b$：令 $\dfrac{1}{I} = 0$，横轴截距为 $-r$（截距绝对值等于内阻 $r$）
- **形式二：$R - \dfrac{1}{I}$ 图像**：$R = E \cdot \dfrac{1}{I} - r$
  - 直线斜率 $k = E$（斜率即为电动势）
  - 纵轴截距 $-r$（截距的绝对值即为内阻）

### 3. 误差分析

- **等效对应关系**：$IR$ 算出的只是电阻箱两端的电压，电流表内阻产生分压，本质上**等效于电流表内接法**。
- **结论**：$E_{测} = E_{真}$，$r_{测} = r_0 + R_A > r_{真}$。

## 教材要点（人教版必修三 §12.3，供对齐顺序与表述）

- 实验思路：$E = U + Ir$，测两组 $U$、$I$ 解出 $E$、$r$；只有一个电流表（或只有一个电压表）时怎么办？
- 物理量的测量：只测两组误差较大，要用滑动变阻器多次测量。
- 数据分析：$U = -Ir + E$ 是直线；纵截距为断路时的路端电压（即 $E$）；由斜率绝对值 $r = \dfrac{\Delta U}{\Delta I}$ 求内阻；也可由短路电流 $r = \dfrac{E}{I_{短}}$ 求。
- 参考案例 1（干电池）：纵轴起点一般不从 0 开始；旧的干电池内阻大得多，容易测量。
- 参考案例 2（水果电池）：铜片、锌片相距约 1 cm 插入水果；内阻较大容易测量，但内阻会明显改变，测量要迅速。
- 教材练习与应用：第 1 题蓄电池 $U-I$ 图像；第 2 题实物连线与"电流表坏了改用电阻箱"；第 3 题橙汁电池（电流表内阻 $100\ \Omega$，量程 $0\sim300\ \mu\text{A}$）。
