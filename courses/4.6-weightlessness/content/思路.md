# 超重和失重 — 授课思路

> 本文为老师的口述思路整理稿，按老师确认的顺序展开。
> 主线沿用教材 §4.6：**下蹲问题 → 重力的测量 → 超重和失重 → 完全失重 → 应用**。
> 老师确定的重点要求：**必须在人与秤这里专门讲清"秤测的是什么"** ——
> 秤测的是它受到的压力（读数），这个读数叫**视重**；视重不等于物体受到的重力，
> 它的大小等于物体受到秤向上的支持力。**超重和失重是视重相对于重力的变化**，不是重力变了。
> 这是学生困惑的实质，讲透这一页，学生就能理解为什么会有超重、失重。

## 课题与教学定位

**课 题**：超重和失重（§4.6）

**教学重点**：

1. 秤的读数（视重）是压力，不等于重力；超重、失重是视重相对重力的变化
2. 用牛顿第二定律把视重与加速度方向联系起来，得到"只看加速度方向"的判据
3. 完全失重（$a = g$ 向下）的物理含义

**难 点**：区分"重力"与"视重"；摆脱"上升就超重、下降就失重"的直觉，改为用加速度方向判断

**教 具**：体重计 / 力传感器（下蹲的 F–t 图像，可用手机加速度传感器现场演示）

---

## 一、引课：体重计上的怪现象

- 人站在体重计上缓慢下蹲，示数**先变小、后变大、再变小**，静止后保持不变。
- 力传感器把全过程记录成 $F$–$t$ 图像，这是本节的主线索图。
- 追问：示数变小，是人变轻了吗？——不。人还是那个人，引力也没变，**变的只能是秤读到的那个力**。

## 二、重力的测量与"秤测的是什么"（本节枢纽）

- 教材两种测重力方法：① 测自由落体加速度 $g$ + 天平测质量 $m$，由 $G = mg$ 求；② 把物体**静止**放在测力计上，由平衡条件读数（最常用）。
- 关键区分（**单独一页讲透**）：
  - 秤受到的是人向下的**压力** $F_N'$，读数就是它；
  - 由牛顿第三定律 $F_N' = F_N$，$F_N$ 是秤对人的支持力；
  - 这个读数叫**视重**，是秤"感到"的力；重力是地球的吸引。两者来源不同，**只有静止（或匀速）时才相等**。
  - 落点：**超重、失重 = 视重相对于重力的变化**，重力 $mg$ 本身不变。

## 三、下蹲三阶段的定量分析

- 约定：竖直向下为正方向。
- 加速下降：$mg - F_N = ma \Rightarrow F_N = m(g-a) < mg$ → 视重小于重力，**失重**。
- 减速下降：$mg - F_N = -ma \Rightarrow F_N = m(g+a) > mg$ → 视重大于重力，**超重**。
- 静止：$F_N = mg$。
- 结论：视重变大还是变小，**只由加速度方向决定，与速度方向无关**。

## 四、电梯模型（交互）

- 电梯六种运动状态（加速上升 / 匀速上升 / 减速上升 / 加速下降 / 匀速下降 / 减速下降）点着看，示数实时变化。
- 学生自己归纳：加速度向上 → 超重；加速度向下 → 失重；匀速 → 视重等于重力。

## 五、完全失重与现象

- 向下加速且 $a = g$ 时 $F_N = m(g-a) = 0$ → **完全失重**（重力仍在，只是全部用来产生加速度）。
- 现象：扎孔的水瓶自由下落时水不流出；航天器内的物体飘浮、液滴呈球形、气泡不上浮。
- 超重的应用：火箭发射阶段加速度可达 $3.5g$，脏器承受的支持力是平时的 4.5 倍。

## 六、例题与练习

- 例题按教材例题（电梯匀加速上升求压力）编排；**例题后续可能替换**，先按占位处理、不做精细打磨。
- 练习：蹦极过程中各阶段的超重、失重判断（教材 §4.6 练习第 2 题）。
- 小结：视重的含义 → 判据 → 完全失重 → 重力不变。
