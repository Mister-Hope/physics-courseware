### 本课统一口径（不超纲、不误导）

- 13.3 只回答"**有没有**感应电流、**什么条件**才有"：**不讲感应电流方向**（右手定则、楞次定律），**不讲法拉第电磁感应定律**（`<Latex tex="\mathcal{E} = -\dfrac{\Delta\Phi}{\Delta t}" />`），都不出现；这些属选择性必修第二册。
- 不讲微积分符号；所有"变化"只作定性判断（增大 / 减小 / 不变），**不出现具体数值与刻度**。
- 上屏的物理量符号与单位一律 `<Latex tex="…" />`；电路符号（`Circuit*`）、磁场记号（`FieldDots` / `FieldMark`）一律用共享组件，不手画。
- 交互演示的按钮用 `@click`（鼠标点组件就动，**不绑 `$clicks`**）；页面节奏用显式 `v-click`；图内分步用组件 `:step="$clicks"`（固定 SVG 内用 `v-if`，不会顶跑版式）。
- 每页点击**只新增、不顶跑**；"有没有电流""原因""答案"这类试卷上没有的东西，一律点击后才出现。

## 三、逐页设计

### P1 封面

- **标题**：`course-cover` 取 headmatter 的 `title`（电磁感应现象及应用）；`chapter-no: 13.3`、`chapter: 第十三章 电磁感应与电磁波初步`、`subtitle: 从磁生电到电气化时代`。
- **布局**：`layout: course-cover`。
- **上屏内容**：章节行、课题名、副标题；右下角装饰 `<CoverDecorationSvg />`（条形磁铁插入螺线管、两端接电流表）。
- **点击节奏**：0 击常显。
- **交互组件与触发方式**：无（装饰图 `CoverDecorationSvg` 不参与交互）。
- **教学意图**：封面就点出本课两条主线（发现与条件、应用与时代），只点主题、不给答案。
- **依据**：教材本节标题与内容结构。

### P2 引课：磁能不能生电

- **标题**：**不写**（提问页）；frontmatter `title: 引课（磁能不能生电）` 只保目录。
- **布局**：`layout: focus-question`。
- **上屏内容**：
  - `#icon`：`<mdi-head-question-outline />`（大图标）
  - 默认 slot（大问题）：**电流能产生磁。反过来，磁能不能产生电？**
  - 第 1 击（`#hint`）：1820 年，奥斯特发现通电导线周围存在磁场——电与磁之间是有联系的。（只作一句回忆，图见 P3 简图，不重画 13.1 的实验）
  - 第 2 击（`#answer`）：法拉第由这种联系想到：磁也应该能产生电。1822 年，他在日记中写下"由磁产生电"。
- **点击节奏**：0 击只有大问题（停住，让学生先想）→ 1 击给奥斯特的事实 → 2 击给法拉第的猜想。
- **交互组件与触发方式**：无（`focus-question` 布局的 `#hint` / `#answer` 槽会自动各占 1 击）。
- **教学意图**：用对称性制造认知冲突，把"磁生电"作为一个待检验的猜想提出，而不是直接讲结论。
- **依据**：教材"问题"栏目 + "划时代的发现"第 1–2 段。

### P3 法拉第的十年

- **标题**：**不写**（叙述页）；frontmatter `title: 法拉第的十年探索`。
- **布局**：`base-flex` + `.split-wide`（左图右文）。
- **上屏内容**：
  - 左栏常显：`<OerstedSymmetrySvg />`——上半只作**简图**（一根导线 + 一枚小磁针的一瞥式示意，标"电 → 磁"，**不重画 13.1 的奥斯特实验装置**，避免与 13.1 撞图）；下半：条形磁体 + 闭合线圈 + 电流表 + "？"（磁 → 电？）。
  - 右栏（逐击）：
    - 第 1 击：法拉第试过很强的磁体、很强的电流——都没有在导线中产生电流。
    - 第 2 击：十年间，他的日记里反复出现这些词：未显示作用、毫无反应、不行。
    - 第 3 击：1822 年的设想，直到 1831 年才有了第一次成功。
- **点击节奏**：0 击只有图（对照的两种方向）→ 1 击"试过什么、为什么失败"→ 2 击日记原话 → 3 击过渡到铁环实验。
- **交互组件与触发方式**：无（静态对照图 `OerstedSymmetrySvg` 常显）。
- **教学意图**：让学生感到"磁生电"不是一蹴而就，为下一页"只在变化瞬间出现"的反常现象铺垫。
- **依据**：教材"划时代的发现"第 2 段 + STSE 第 2 段（日记中的"未显示作用""毫无反应""不行"）。

### P4 法拉第的铁环实验

- **标题**：**不写**（页面上是一个提问 + 一个演示）；frontmatter `title: 法拉第的铁环实验`。
- **布局**：`base-flex`。
- **上屏内容**：
  - 常显 `.ask`：把两个线圈绕在同一个铁环上：A 接电源，B 接电流表。给 A 通电或断电，B 中有电流吗？
  - 常显交互：`<FaradayRingDemo />`（铁环 + 线圈 A/B + 电源 + 开关 + 电流表指针；按钮「接通电源」「断开电源」）
  - 第 1 击：**接通瞬间**：电流表指针偏转——B 中出现了感应电流。
  - 第 2 击：**保持接通**：指针回到零——B 中没有电流。
  - 第 3 击：**断开瞬间**：指针反向偏转——B 中又有感应电流。
- **点击节奏**：0 击装置与问题（开关断开）→ 老师点"接通电源"，观察指针 → 1 击接通瞬间的结论 → 保持接通，观察指针回零 → 2 击稳定时的结论 → 老师点"断开电源"→ 3 击断开瞬间的结论。
- **交互组件与触发方式**：组件内按钮（`@click`，不绑 `$clicks`）；组件只显示"线圈 A：有/无电流"这一**输入**状态与指针现象，**不显示**"B 中有没有电流"的文字结论（结论留给页面 v-click）。
- **教学意图**：把教材里最难观察的"瞬间"放慢给学生看——只在通断电瞬间有电流。
- **依据**：教材"划时代的发现"第 3 段 + 图 13.3-1。

### P5 电磁感应与感应电流

- **标题**：**写**「电磁感应」（概念名，带信息）。
- **布局**：`base-flex`。
- **上屏内容**：
  - 常显 `.ask`：通电和断电这两个瞬间，有什么共同点？
  - 第 1 击：都是"变化"发生的瞬间：线圈 A 中的电流在变化。
  - 第 2 击：法拉第的领悟：磁生电是一种在变化、运动的过程中才能出现的效应。
  - 第 3 击 `<DefinitionBox term="电磁感应">`：由磁产生电的现象叫作**电磁感应**（electromagnetic induction），产生的电流叫作**感应电流**（induction current）。
- **点击节奏**：0 击只有问题 → 1 击现象的共同点 → 2 击法拉第的领悟 → 3 击定义落地。
- **交互组件与触发方式**：无（`DefinitionBox` 与文字均用页面 `v-click` 分步）。
- **教学意图**：从"为什么只在瞬间"抽象出"变化"这一关键词，为后面"磁通量变化"埋线。
- **依据**：教材第 4–5 段（"磁生电"是一种在变化、运动的过程中才能出现的效应；定名电磁感应、感应电流）。

### P6 划时代的意义

- **标题**：**不写**（引语页）；frontmatter `title: 划时代的意义`。
- **布局**：`layout: center`。
- **上屏内容**：
  - 常显（居中偏大，`.text-xl leading-normal`）：法拉第评价奥斯特的发现："它突然打开了科学中一个黑暗领域的大门，使其充满光明。"
  - 引语下方小字（`.mini-note`）：——法拉第
  - 第 1 击：电磁感应的发现使人们对电与磁内在联系的认识更加深入，宣告了电磁学作为一门统一学科的诞生。
  - 第 2 击：公正地说，法拉第与奥斯特应该共享这样的荣誉。
- **点击节奏**：0 击只有引语（读、停）→ 1 击意义 → 2 击"共享荣誉"。
- **交互组件与触发方式**：无（`center` 布局 + 页面 `v-click`）。
- **教学意图**：让发现的"划时代"落在"统一学科"与两位科学家的接力上，不做空泛抒情。
- **依据**：教材第 6 段。

### P7 三种运动，哪种有电流

- **标题**：**不写**（提问页）；frontmatter `title: 三种运动`。
- **布局**：`base-flex`。
- **上屏内容**：
  - 常显 `.ask`：闭合电路的一部分导体在磁场中运动。下面三种运动，哪些能产生感应电流？
  - 常显 `<CuttingCasesSvg :step="$clicks" />`——三小图（甲 静止 / 乙 沿磁感线上下运动 / 丙 切割磁感线左右运动），每幅只有：蹄形磁体（N/S）、导体棒 AB、灵敏电流计、运动方向箭头（甲为"静止"标注）；**第一眼不出现答案与指针状态**。
  - 第 1 击：甲：指针不偏转——没有感应电流。
  - 第 2 击：乙：指针不偏转——没有感应电流。
  - 第 3 击：丙：指针偏转——有感应电流。
  - 第 4 击（`.tip-hint`）：只有丙——切割磁感线时才产生感应电流。
- **点击节奏**：0 击干净的三幅装置图（学生先判断）→ 逐击给甲、乙、丙的指针状态与结论 → 最后一击收束。
- **交互组件与触发方式**：组件 `:step="$clicks"` 控制"指针状态 + 有/无电流"标注的显隐（固定 SVG 内 `v-if`）。
- **教学意图**：先让学生用初中知识判断，再用"指针不动"强化"运动 ≠ 电流产生"。
- **依据**：教材"问题"第 1 句 + "思考与讨论"第 1 段（静止、沿磁感线运动均无电流，只有切割才有）。

### P8 切割时变的是什么

- **标题**：**不写**（提问页）；frontmatter `title: 变化的物理量`。
- **布局**：`base-flex`。
- **上屏内容**：
  - 常显 `.ask`：AB 沿导轨滑动时同样在切割磁感线，但磁场没有变化——变化的是什么？
  - 常显交互：`<RailLoopDemo />`（U 形导轨 + 金属棒 AB + 电流表 + 垂直纸面向里的匀强磁场 `FieldDots`；按钮「向右滑动 AB」「向左滑动 AB」）
  - 第 1 击：滑动时，电路 ABCD 的面积 S 在变化。
  - 第 2 击：面积变，穿过电路的磁通量 `<Latex tex="\Phi = BS" />` 也跟着变。
  - 第 3 击（第二个 `.ask`）：感应电流的产生，是否与磁通量的变化有关？
- **点击节奏**：0 击装置与问题 → 老师点按钮让 AB 滑动（滑动中电流表指针偏转、停止后回零）→ 1 击"面积在变"→ 2 击"Φ 也在变"→ 3 击抛出下一环节要检验的问题。
- **交互组件与触发方式**：组件内两个按钮（`@click`，补间约 0.7 s）；滑动中显示"面积 ↓ / Φ ↓"与指针偏转，停止后指针回零。
- **教学意图**：把"切割"从动作层面推进到"磁通量变化"这一物理量层面；页面**不下结论**（结论留给实验）。
- **依据**：教材"思考与讨论"第 1–3 段 + 图 13.3-2 + 13.2 的 `<Latex tex="\Phi = BS" />`。

### P9 实验：探究感应电流产生的条件

- **标题**：**写**「实验：探究感应电流产生的条件」（实验/操作名，带信息）。
- **布局**：`base-flex` + `.half-grid`（左装置、右表格）。
- **上屏内容**：
  - 常显 `.ask`（题干，**实现时压成一行**）：线圈 A 接电源，线圈 B 接电流表，A 套在 B 里。四种情况下，B 中有电流吗？（页 frontmatter 加 `zoom: 0.92`：装置 + 表格 + 结论同页，内容高度差约 35px）
  - 左栏常显交互：`<CoilInductionDemo />`（线圈 A、B 套在一起；电源 + 开关 + 滑动变阻器；电流表；按钮「闭合开关」「断开开关」「迅速移动滑片」）
  - 右栏常显：`.data-table` 四行两列，**"线圈 B 中是否有电流"一列先留空**：

    | 开关和变阻器的状态                   | 线圈 B 中是否有电流 |
    | :----------------------------------- | :------------------ |
    | 开关闭合瞬间                         |                     |
    | 开关断开瞬间                         |                     |
    | 开关闭合时，滑动变阻器不动           |                     |
    | 开关闭合时，迅速移动滑动变阻器的滑片 |                     |

    （答案格一开始留空；实现时用 `<span v-click="n">有 / 无</span>` 逐击填入，保留占位、不顶跑。）

  - 第 1 击：第 1 行填「有」；第 2 击：第 2 行「有」；第 3 击：第 3 行「无」；第 4 击：第 4 行「有」。
  - 第 5 击（`.tip-hint`）：有电流的三种情形，共同点是：穿过线圈 B 的磁通量发生了变化。

**边界情况**

- `FaradayRingDemo`：断开状态下再点"断开"无动作；快速连续通断时先清掉上一定时器/动画（保留原组件 `onBeforeUnmount` 清定时器的写法）；指针角钳位 ±28°，不越出表盘；动画中途切换以最后一次操作为准（从当前角度继续）。
- `RailLoopDemo`：AB 到最左/最右位置后对应按钮禁用，不会被拖出导轨；面积 S 始终大于 0（最左位置仍有初始面积），`<Latex tex="\Phi" />` 不会出现 0 以外的异常值；停止后指针平滑回零，不残留偏转；反向滑动时读数与指针方向随之反向（只体现"在变"，不标方向含义）。
- `CoilInductionDemo`：开关断开时"移动滑片"按钮禁用；滑片到两端时 `I_A` 仍为有限值（`<Latex tex="E/(R+r)" />`，`R` 有下限），不出现 `Infinity`；快速连点闭合/断开以最后一次为准；脉冲时长固定（约 0.6 s），不出现"Δt 太小 ⇒ 读数爆掉"。
- `FaradayDiskDemo`：转速有上限（指针角钳位 ±28°）；停止后指针回零；转动角取模 360°，长时间运行不累积误差；不显示电流方向含义。

### 4.3 交互必要性自证（每组件一句话）

- `FaradayRingDemo`：**必须是交互，而不是示意图**——因为"有电流"只发生在通断电那一瞬间，静态图无法表达"瞬间 vs 稳定"的时间差别；这是本课最关键的观察。
- `RailLoopDemo`：**必须是交互**——因为"面积在变、磁通量在变"是一个**过程**，滑动的动画直接让"变化"可见；不用滑块，因为这不是"参数变化 → 结果随之变化"的函数关系，而是一个动作（按 `.agents/notes/interactive-necessity.md`：过程/动作 → 点击分步动画，不硬塞滑块）。
- `CoilInductionDemo`：**必须是交互**——因为四种情形的区别就在"操作"上（闭合、断开、不动、迅速移动滑片），学生要看到"操作 → 指针反应 → 回零"的完整过程；静态表格说不清"瞬间"。
- `FaradayDiskDemo`：**必须是交互**——因为"摇动 → 转动 → 指针摆动"本身是动作过程；只看形态（转与不转、指针偏与不偏）用定性动画即可，不需要读数。

### 4.4 共享组件与共享布局的使用清单

- 电路符号：`CircuitBattery`、`CircuitSwitch`、`CircuitRheostat`、`CircuitMeter`（**不手画电源/开关/变阻器/电表**；导线止于元件两端，节点只画在确实相连处）。
- 磁场记号：`FieldDots`（平铺 × / ·，**不手画叉点阵**）；`FieldMark` 仅在图里没有平铺阵列、需要单个方向标注时使用（本课 P8/P17/P18 有阵列，不再加角落图例）。
- 矢量箭头：`CourseArrow`（磁场方向、运动方向、电流方向；尖端落在目标点）。
- 公式与定义：`Latex`（HTML 块内 `<Latex tex="…" />`）、`DefinitionBox`（P5、P11 的定义）。
- 布局：`course-cover`（P1）、`base-flex`（全课默认）、`focus-question`（P2）、`center`（P6）、`exercise-split`（P17、P18）。
- 版式原子：`.ask`（提问）、`.tip-hint` / `.warn-hint`（结论与要点）、`.three-col`、`.split-wide`、`.half-grid`、`.data-table`、`.step-list`、`.mini-note`；**不用 `.card` 装定义或结论**。
- 尺寸建议（viewBox 用户单位，供实现时控版面）：`FaradayRingDemo` 约 640×300（全宽）；`RailLoopDemo` / `FaradayDiskDemo` / `CoilFluxSvg` 约 520×300；`CoilInductionDemo` 约 440×330（半栏）；`CuttingCasesSvg` 约 900×250、`RectFrameMotionsSvg` / `FrameThroughFieldSvg` 约 900×230（整宽三幅）。图内字号按 16px 体系给足，SVG 内不写空行。
