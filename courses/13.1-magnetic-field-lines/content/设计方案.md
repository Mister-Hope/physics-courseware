**教学目标（3 条）**

1. 知道磁体和电流周围都存在磁场；通过奥斯特实验认识电流的磁效应，知道磁体与磁体、磁体与通电导体、通电导体与通电导体之间的相互作用都通过磁场发生。
2. 会用磁感线描述磁场：磁感线上每一点的切线方向表示该点磁场方向，疏密表示磁场强弱；知道磁感线是闭合曲线、磁感线不相交；能画出条形磁体、两个条形磁铁靠近时（同名磁极 / 异名磁极）的磁感线分布。
3. 知道磁感应强度是矢量、空间某点的磁场是各磁体在该点产生的磁场的矢量和；会用安培定则判断直线电流、环形电流与通电螺线管产生的磁场方向。

**教学重点**：磁感线的方向与疏密、磁感线的闭合与不相交、常见磁场的磁感线分布、安培定则（两种形式）。
**教学难点**：① 两个磁铁靠近时「中间穿过的线」与「外侧绕回的线」都只是闭合曲线的一段，磁感线并没有断开（学生最易错处）；② 磁场的矢量叠加与「同名更疏 / 异名更密」的对应；③ 空间上区分导线方向 / 磁感线所在平面 / 环形电流轴线。

**与前后课时的衔接**

- **向前**：9.3《电场 电场强度》已建立「场」的概念与「电场线」的描述方法（有方向的曲线、切线表示方向、疏密表示强弱、电场线不相交），本课按同一套描述方法迁移到磁场；不同的是磁感线是**闭合**曲线。必修一已学**矢量与矢量合成**（平行四边形定则），本课的「磁场叠加」直接用它。初中已学磁极、磁化、通电螺线管的磁场方向（教材 13.1 明确「在初中，我们已经学会了判断通电螺线管的磁场方向」），本课补「为什么」。
- **向后（闭合性在后续哪一节用，明确答复）**：本课讲完磁感线闭合后，后续有三处直接用，且都不再重新讲：① **13.2《磁感应强度 磁通量》**——用「穿过某个面积的磁感线条数」比较磁通量，前提就是磁感线连续、闭合，条数才有意义；② **13.3《电磁感应现象及应用》**——线框进出磁场、磁体插入拔出时，靠磁感线的穿入 / 穿出来看磁通量变化；③ **选择性必修第二册第二章《电磁感应》（楞次定律、法拉第电磁感应定律，本仓尚未建课）**——判断感应电流方向时反复用「磁通量增加 / 减少、磁感线穿入 / 穿出」。选择性必修第二册第一章（安培力与洛伦兹力）基本不依赖闭合性。**磁感应强度的矢量性**同理：13.2 才给出大小定义 $B=F/Il$ 与单位 $\text{T}$，本课只讲「方向、矢量、可叠加」；叠加在 13.3 与选必二中继续使用。

## 三、逐页设计

> 约定：每页 frontmatter 都要写 `clicks: N`；页内「点击 k」指这一页的第 k 次点击。**所有组件内部的分步用固定 viewBox 的 `v-if`（不顶跑版面），页面层的文字一律用 `v-click`（保留占位、不位移）**。图中符号在 SVG 内用 `KaTeX_Math`（斜体量）＋`KaTeX_Main`（正体 / 单位），HTML 内用 `<Latex tex="…" />`。本课出现的物理量符号：电流 `<Latex tex="I" />`、磁感应强度 `<Latex tex="\vec{B}" />`（矢量，只讲方向与叠加，量值与单位留 13.2）。

### P1 · 封面

- **标题**：写（封面课题名，由 `title:` 取）。
- **布局**：`course-cover`；frontmatter 写 `chapter-no: "13.1"`、`chapter: "第十三章 电磁感应与电磁波初步"`、`subtitle: "从奥斯特实验到安培定则"`，页面内容只放 `<CoverDecorationSvg />`（默认插槽）。
- **上屏内容**：封面由布局生成（章节行 → 课题名「磁场 磁感线」→ 副标题 → 授课教师行）；装饰图为条形磁体 + **闭合**磁感线 + 小磁针。
- **点击节奏**：0 击。
- **教学意图**：进入课题，第一眼看到「磁体周围的曲线是闭合的」。
- **物理依据**：教材 13.1 图 13.1-5 的磁感线意象。

### P2 · 引课（无标题）

- **标题**：不写（整页是一个问题；原话写进 frontmatter `title: 电和磁有联系吗`）。
- **布局**：`focus-question`，`clicks: 2`；`#icon` 放一枚大图标（`<mdi-magnet class="icon-2xl" />`，图标名写入前在 `@iconify-json/mdi/icons.json` 的 `icons`/`aliases` 中验证）。
- **上屏内容**
  - 默认 slot（整页大字）：「同名磁极相斥、异名磁极相吸——与电荷之间的相互作用具有相同的特征。电和磁有联系吗？」
  - `#hint`（点击 1）：「凡是使用电的地方，几乎都有磁现象相伴随：电动机、电磁炉、耳机、扬声器。」
  - `#answer`（点击 2）：「19 世纪初，库仑、英国物理学家杨和法国物理学家安培都认为电与磁是互不相关的两回事；奥斯特相信两者之间存在某种联系。」
- **点击节奏**
  - 初始：只有一个问题，学生自由说「生活里哪些电器有磁」。
  - 第 1 击：出现生活实例（把「电的地方都有磁」摆出来）。
  - 第 2 击：出现 19 世纪初的判断分歧，把悬念收到奥斯特身上（下一页立刻验证）。
- **交互**：无。
- **教学意图**：用「磁极与电荷的相似性」制造认知冲突，落到「奥斯特要去找联系」。
- **物理依据**：教材 13.1「问题」段 ＋「电和磁的联系」第 1、2 段。

### P3 · 奥斯特实验（无标题）

- **标题**：不写（演示 + 提问页；frontmatter `title: 奥斯特实验`）。
- **布局**：`base-flex`，`.page-grow` 内用 `.mf-split`（左栏文字、右栏图）；`clicks: 3`。
- **上屏内容**
  - 右栏：`<OerstedDemo :step="$clicks" />`（改造后，见第四节）。
  - 左栏 `.ask`：「导线沿南北方向架在小磁针上方。给导线通电，磁针会怎样？」
  - `.tip-hint`（点击 1）：「磁针偏转——通电导线周围存在磁场。」
  - `.info-hint`（点击 2）：「把电流反向，磁针向相反方向偏转：磁场的方向由电流的方向决定。」
  - `.info-hint`（点击 3）：「1820 年，奥斯特在一次讲课中偶然发现；同年 7 月发表论文，首次揭示了电与磁的联系。」
- **点击节奏**
  - 初始：开关断开，小磁针静止指南北；问题在左栏，学生先预测。
  - 第 1 击：磁场箭头出现在磁针处（配合老师按下「电流向北」按钮，磁针向西偏转）→ 学生看到「偏转」与「磁场」的对应。
  - 第 2 击：老师按「电流向南」，磁针反向偏转；这一击的文字把「反向」点成结论。
  - 第 3 击：补历史事实（首次揭示电与磁的联系）。

**交互必要性自证（每个组件一句话：为什么它必须是交互 / 分步，而不是一张静态图）**

- `OerstedDemo`：因为「通电 / 断电、电流反向」这两个**动作**要老师在讲台上当场做出来，学生先预测再看到磁针偏转与反向，才能把「磁针动」与「电流」连成因果；静态图只能给结论，失去「猜—验」的过程。
- `BarMagnetBoardSvg`：因为「撒铁屑 → 轻敲 → 排成曲线」是**一个过程**，学生要看的是「敲一下之后发生了什么」；它只对两种离散状态成立，用滑块没有意义。
- `BarMagnetFieldSvg`（小磁针形态）：因为学生要看到「同一枚磁针换到三个位置，指向就不同」——这是**逐点取出方向**的动作，不是连续调参。
- `BarMagnetFieldSvg`（磁感线形态）：因为「曲线 → 加方向 → 加切线 → 定义 → 疏密」是五个连续的认知台阶，分步才能让每一层停住想；滑块会把「方向」和「疏密」混成一锅。
- `ClosedFieldLinesSvg`：因为「磁体内部有没有线」「线会不会相交」是学生最会想错的两件事，先抛问题、再逐条给答案；这是两个离散判断，不是参数变化。
- `TwoBarMagnetsSvg`：因为「穿过两磁铁的线是不是断了」这个迷思必须靠**整空间的图**来破——先看中间穿过的线、再点出外侧绕回的线，两步之间要停住；磁体内部另画淡虚线的 S→N 段，让每条回路在图上自证闭合；没有连续参数。
- `SuperpositionSvg`：因为矢量叠加要**逐个点看两个分矢量怎么相加**，分步出箭头才看得清；点的位置不是教学对象，固定一个点即可，不上滑块。
- `StraightWireFieldSvg`：因为「电流反向 → 各点磁场全部反向」这一事实要靠按钮**亲手翻一次**才对得上 P11 第 3 条的结论；电流方向只有两档，离散切换即可。
- `AmpereGripRule`：因为判据要靠学生**跟着比划右手**才记得住；电流只有两档，手与磁感线必须同步反向，交互比分步静态图更能立住「握」的关系。
- `RingCurrentFieldSvg` / `SolenoidFieldSvg`：因为「电流反向 → 轴线磁场反向 / N S 互换」是本节第二次、第三次用同一个判据，学生要自己按一次反向、确认结论能迁移；两档离散，不用滑块。
- `MolecularCurrentSvg` / `MagnetizationSvg`：只讲**形态变化**（取向杂乱 / 一致 / 又杂乱），没有任何数值，用点击分步讲过程即可。
- `ThreeInteractionsSvg` / `StraightWireCompassQ` / `RingCompassQ` / `CoverDecorationSvg`：不是交互演示——前三个是分步出标注（含「分析类标注点击后才出」的硬要求），最后一个是纯装饰。

**边界情况（0 / 极值 / 反向）**

- `OerstedDemo`：断开 → $\theta=0$（磁针恢复指南北）；电流反向 → $\theta$ 取反、磁场箭头反向（两侧对称）；$\theta=\arctan(\cdot)<90^{\circ}$ 恒成立，不会画出「转过 90°」；$I$ 固定为 4 A，不存在除零。
- `BarMagnetBoardSvg`：磁极附近 $|\vec r-\vec r_i|\to0$ 时给 $r^3$ 一个下限，绝不出现 `Infinity / NaN`；铁屑不落进磁体内部；随机抖动用固定种子（每次渲染一致，不闪）。
- `BarMagnetFieldSvg`：磁感线积分出界即停，终止判据用「进入磁体边界」而不是靠步数凑；切线严格取曲线上一点的场方向（不自造角度）；疏密只标「密 / 疏」，**不标任何数值**。
- `ClosedFieldLinesSvg`：内部磁感线只作**示意**（不追求模型精度），但要与外部线在极面处接上、不留断头；「不相交」只画反例示意，不能画出一条真的相交的磁感线。
- `TwoBarMagnetsSvg`：同名格两 N 极中点处 $\vec B=0$（由对称性），生成磁感线时避开该点附近，避免线在那里突然反向；每条线必须终止于某个 S 极附近，出界即停、不出断头线；**磁体内部的淡虚线 S→N 段必须在极面处与外部线端点重合**（差一点就又会露出「断开」观感）；同名 / 异名两格的磁体尺寸、间距一致，便于对比。
- `SuperpositionSvg`：同名格合矢量接近零，**不能画零长度箭头**——标「$\vec B\approx 0$」或用极短的箭头 + 文字说明，避免出现 `NaN`。
- `StraightWireFieldSvg`：只两档反向；同心圆半径不超出画布；高亮出的平面限定在导线中部（不画出导线两端）。
- `AmpereGripRule`：反向 = 整幅旋转 180°，**绝不镜像**（镜像会变成左手的判据，是物理错误）；四指与磁感线箭头必须同向。
- `RingCurrentFieldSvg` / `SolenoidFieldSvg`：反向 → 轴线磁场 ⊙ ↔ ⊗、N/S 互换；磁感线穿环后必须回到外部，不出现断头线。
- 练习图组件：只有一个答案，不存在「连续调参」；点击前题目图上不出现磁感线圆、⊙、任何分析标注。

**共享图元使用（不手画）**：矢量箭头一律 `CourseArrow`（不手写 `<marker>`）；磁场方向记号用 `FieldMark`（⊙/⊗）；矢量标签（$\vec{B}_1$、$\vec{B}_2$、$\vec{B}$）用 `ChartLabel`；定义用 `DefinitionBox`；气泡用 `tip-hint` / `info-hint`；公式用 `Latex`；两栏用 `.mf-split` / `.mf-split-text` / `.half-grid`。**本课不涉及坐标轴、弹簧测力计、天体、电路元件**（`CoordAxes` / `SpringScale` / `Celestial*` / `Circuit*` 不用）。

**两处必须自绘、需要理由**：① **右手**——`GripHand` 是「侧视捏住拉环 / 细绳」的握持形态，安培定则要的是「握住一根导线、四指环绕」，没有共享组件可用，因此自绘；但必须画成**线稿**（用 `var(--c-accent)` 系列 token，不写死肤色），并保证是右手。② **磁体、铁屑、螺线管、分子电流小环**——共享组件里没有磁体图元，自绘并统一「N 极红、S 极蓝」的配色（用 `var(--c-danger)` / `var(--c-accent-2)`）。

| `FieldDirectionNeedle` | **重做，由 `BarMagnetFieldSvg` 的小磁针形态取代** | 概念错：小磁针画在左边一个大箭头旁边、而不是放在「被测的那一点」上；用四个按钮把同一个点的磁场连续切换成东南西北，物理上这个点的磁场方向是**唯一**的，四档切换会让学生以为「磁场方向可以随便设」。正确形态：一个条形磁体 + 若干**位置固定**的小磁针，逐点点击让磁针转到该点场方向（P5）。 |
| `MagnetWireForceSvg` | **本课不复用** | 值得澄清：教材 13.1 确实有「把直导线悬挂在蹄形磁体两极间，通以电流，导线就会移动（图 13.1-2）」，这一**现象**属于 13.1。但该组件画的是受力 $F$ 与移动方向，属于「通电导线在磁场中的受力」——13.1 没有给受力方向的判据，$F=IlB$ 在 13.2、方向判据（左手定则）在选择性必修二，**超出本课**；而且组件里 $F$ 的方向只在「导线垂直于纸面」的画法下成立，学生在这一节还没有判断依据。另外文件头注释「$I$ 向外（$-\text{z}$）⇒ $F$ 向上」本身自相矛盾（$-\hat z\times\hat x=-\hat y$，只有 $I=+\hat z$ 才得 $+y$），并且把 `FieldMark`（B 方向记号）拿来当导线截面符号用。本课只在 P4 的三相互作用图里保留「蹄形磁体 + 通电导线」这一**现象**，不画 $F$。 |

### 5.3 发现的问题（逐条）

1. **`BarMagnetBoardSvg` 的 N/S 与场模型相反（硬错误）**：场代码把 N 极放在 $x=CX+A$（右端）、S 极放在 $x=CX-A$（左端），而图里右端画成蓝色「S」、左端画成红色「N」——所以算出来的磁感线是**从画着 S 的一端出发、流进画着 N 的一端**，与磁体标注反了 180°。修法：要么把红/N 与蓝/S 对调，要么把两个磁极坐标对调（推荐对调颜色与字母，保持场代码不动）。
2. **`CoverDecorationSvg` 的小磁针指向错**：小磁针位于条形磁体左侧（S 端外侧），该处磁场指向磁体（向右），针的 N 极应指向右；现在 N 极朝上。
3. **`CoverDecorationSvg` 的磁感线不成线**：四段曲线都从磁体右端附近出发、止于磁体上表面，另有两条悬空的水平短线；磁感线应当从 N 极面出发、绕到 S 极面连续进入，并且带箭头。本课要讲「磁感线闭合」，封面这条线不闭合就是**物理矛盾**，必须重画。
4. **`MagnetWireForceSvg` 的公式注释自相矛盾**（见 5.2）＋ 挪用 `FieldMark` 当电流截面符号。
5. **`FieldDirectionNeedle` 的概念错误**（见 5.2）＋ 磁针与被测点不在同一处。
6. **上屏废话 / 越纲注释**：`OerstedDemo` 底部 `note`（「电流越大，偏转越大」——13.2 的内容）、`BarMagnetBoardSvg` 底部「玻璃板上撒铁屑 · 轻敲后沿磁场方向排列」（对图的赘述）。这些必须删；结论文字回到页面用 `.tip-hint` 写。
7. **色值未走 token（style-audit 的 error 级）**：组件里大量写死色值——`#cbd5e1`、`#94a3b8`、`#f87171` / `rgba(248,113,113,0.85)`、`#60a5fa` / `rgba(96,165,250,0.85)`、肤色 `#f2c9a2` / `#eebd94` / `#8c5a40`、`rgb(255 255 255 / 5%)`。重做时一律换 `var(--c-*)`；手部改线稿，不再需要肤色 token。
8. **按钮样式重复**：`AmpereGripRule` / `StraightWireFieldSvg` / `FieldDirectionNeedle` / `OerstedDemo` 各写了一套 `.mf-btn`（其中一套叫 `.mf-btn-on`、另一套叫 `.mf-btn.on`）。改造时统一到本课 `style.css` 的**一个** `.mf-btn` 类，组件里不再重复定义。
9. **步进来源两套**：组件用 `Math.max(stepProp, $clicks)` 同时吃 props 与页面点击数，容易出现「翻页与组件内部状态不同步」。统一改成页面传 `:step="$clicks"`，组件只认 props。
10. **页面层分步不要用 `v-if`**：组件内部固定 viewBox 的 `v-if` 没问题（跳出 DOM 布局的才要改），但页面层的结论文字必须用 `v-click` 保留占位。
11. **课程样式**：`style.css` 只覆盖了 `--page-gap` / `--stack-gap` 与两个两栏变体，合规；`.mf-split` / `.mf-split-text` 的 `--cols` 比例与本方案的分页一致，直接沿用。
12. **`content/思路.md` 与 `README.md` 都是空模板**：`README.md` 的页目表 / 组件表属定稿后的闸门，本轮不动；老师的授课思路本轮已由老师直接口述（见第一节「老师口径」），方案按口述改，`思路.md` 待老师确认后再整理。
