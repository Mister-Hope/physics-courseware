# Apple Watch (45mm) + 磁吸充电头 3D 装配体模块 (`watchAssembly.ts`)

> 对应 `08-AppleWatch3D模型子任务.md` 与 `09-第3轮修改方案-P2-P3与模型.md`（第 3 轮修改版）。

---

## 1. 架构分工（08 §5 裁定）

- **`watchAssembly.ts`**：纯 3D 部件装配体与材质/状态控制 API（不控制相机、不读 Slidev 点击步）。
- **`watchModel.ts`**：相机轨迹、P2（`mode = "intro"`，C0–C6 共 6 击）与 P3（`mode = "chain"`，C0–C4 一镜到底连续 3D 供电链）、灯笼磁通笼、蓝色电子流以及本地 Web Audio 充电音效合成。
- **`WatchIntro3D.vue` / `PowerChainStepSvg.vue`**：只把 Slidev 的 `:step="$clicks"` 传给 `WatchIntroModel`，并渲染精简的提示卡 HUD（透明背景，无缝嵌入 PPT 整页，自动避让左上标题与右上校徽）。

---

## 2. 坐标系与尺度约定（`1 单位 = 10 mm`）

- **右手系**：`+Y` 向上（12 点钟方向）、`-Y` 向下（6 点钟方向）、`+X` 向右（数码表冠与侧键侧）、`-X` 向左（扬声器细缝与**充电盘白线向左引出方向**）。
- **朝向**：
  - **表盘正面朝 `+Z`**（2.5D 大曲面蓝宝石屏幕法线朝 `+Z`，与中框弧线连接，无台阶感）。
  - **表背朝 `-Z`**（非金属微磨砂精密陶瓷背盖 + 深色蓝宝石心率传感器圆台朝 `-Z`）。
  - **磁吸充电头（`chargerRoot`）充电白面朝 `+Z`**，银色金属底壳朝 `-Z`，**白色线缆从左侧（`-X`）护套自然向左引出**，不挡表盘。

## 3. 第 3 轮模型升级要点（对应 `09` §4 / §5 / §6.1）

1. **独立数码表冠（Digital Crown）**：独立组件 Mesh，采用 **56 齿真实 3D 齿轮滚花几何**（`createGearCrownShape`）+ bump 纹理 + 红圈细节，侧面能清晰看到齿轮凹凸感。
2. **大曲面 2.5D 蓝宝石屏幕**：加大屏幕占比（外廓 `3.78 × 4.48`），采用 10 段大曲率圆弧倒角直接过渡到 `3.80 × 4.50` 金属中框，彻底消除正面明显的“棱/台阶”；屏幕本体**永远不透明**。
3. **侧边按钮（Side Button）**：右侧偏下长条按钮加宽，36 段圆弧细分 + 4 段精致圆角倒角，消除边缘毛刺。
4. **表带旋转 90° 正确展开**：采用侧视弧线轮廓沿 `X` 轴水平挤出（宽幅 `2.38` 完全贴合表耳滑轨，不再扭转成窄边朝前），与表壳通过弧形表耳（Lug）无缝连接，无悬空、无穿模。
5. **非金属陶瓷/蓝宝石表背 + 内部深色电路板（PCB）**：
   - 背盖主体改为微磨砂深色精密陶瓷/蓝宝石（`metalness: 0.02~0.03` 非金属），避免整块亮金属板产生涡流屏蔽磁场；金属只保留在中框与外侧窄圈。
   - 背盖透明/剖开后：首先看到**黄铜/金属光泽受电线圈（RX Coil）**，其后方是一块**深色柔性电路板（Flex PCB）+ Apple S9 主控芯片 + 电源管理 IC + 金色 FPC 排线与微型贴片电容**（代表手表的负载，而非整块金属板）。
6. **黄铜线圈与蓝色电子流**：两个线圈平时呈现饱满的黄铜金属光泽；充电动效（C4–C6）出现时变为**半透明黄铜管**，内部 64 颗蓝色电子沿螺旋连续运动（速度控制在 **1 圈约 1.5 秒**，流向清晰、不闪烁）。
7. **表耳与线圈固定结构（直接采用 C 版最优方案，已移除 A/B 冗余分支）**：
   - 采用真实 Apple Watch 一体式弧形金属表耳（Lug）+ 线圈外沿 4 个微型暗色非金属卡爪，既保证表带与表壳滑轨连接严丝合缝，又不抢内部黄铜线圈与深色 PCB 的视觉焦点。
   - **正弦交变电流与交变磁场严格对应**：送电线圈电子角位移 $\varphi_1(t) \propto -\cos(\omega t)$（正半周顺时针、负半周逆时针往返振荡），激发的磁通量 $\Phi(t) \propto i_1(t) \propto \sin(\omega t)$ 与电流完全同相（随电流顺/逆时针同步增减并翻转磁感线箭头方向），受电线圈感应电流 $i_2(t) \propto -\mathrm{d}\Phi/\mathrm{d}t \propto -\cos(\omega t)$ 同样顺/逆时针正弦往返振荡。
