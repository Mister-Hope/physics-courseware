## 五、原始报告的可信度标记

| 标记       | 含义                                 | 用法                  |
| ---------- | ------------------------------------ | --------------------- |
| 【确定】   | 官方文件/教材/省级课例原文，已核链接 | 可说“根据……”          |
| 【较可靠】 | 正规期刊/高校/省级教研，二手互证     | 可说“有研究/有课例……” |
| 【经验值】 | 教研经验/自媒体/校本做法，无文件依据 | 说“我们的做法/经验上” |
| 【待核】   | 只查到二手转述/链接失效/日期存疑     | 不说，或说“待确认”    |
