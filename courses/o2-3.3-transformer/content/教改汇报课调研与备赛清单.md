## 0. 30 秒结论

1. 【确定】哈三中「教改汇报课」**不是**普通的新教师汇报课，而是学校办了 40 年的年度教改品牌活动（1985 年起，2025 年第 40 届正好四十周年）。规格是「多校联合 + 专家议课 + 同课异构」：第 40 届有 8 省 15 校、35 节展示课，省市教研员现场评议。所以评委不是来看你「讲得顺不顺」，是来看你「**改了什么、为什么改、有没有效果**」。
2. 【确定】第 41 届的公开报道、邀请函、评价表，截至 2026-11-19 **检索不到**。第 39、40 届都在 12 月中下旬举办，推断第 41 届也在 2026 年 12 月。主题「数智赋能背景下营造良性课堂生态策略探索」来自学校通知/你提供的信息，公开资料里没有——所以下面凡涉及「41 届会怎么评」的内容，没有来源的我都标了【推断】。
3. 【推断】这个主题是第 40 届「融合 AI」的延续和升级：从「用不用 AI」进到「AI 用得对不对、课堂关系健不健康」。评委大概率同时看两件事：**技术有没有真解决教学难点**，以及**课堂里的人和关系有没有变好**。
4. 【确定】公开的课堂评价量规（多地、多版本）反复出现同一组词：目标可测、学生主体、探究/动手 ≥10 分钟、教学评一致、证据优先（禁止凭「感觉」打分）、技术适配。这跟你 IT 行业的 code review / 测试报告是一个逻辑：**说做了什么不算，拿得出证据才算**。
5. 【推断】对《变压器》第一课时，最大的加分项不是 AI 多炫，而是：真实实验 + 真实数据 + 学生真的用数据推出规律 + 技术只在「看不见的磁通/损耗」上出现两次。最大的扣分项是：教师一人演示到底、AI 动画替代实验、借班冷场、超时。

## 1. 「教改课 / 教改汇报课」到底是什么

### 1.1 先分清两个容易混的东西

**（1）一般学校说的「汇报课」**：多由青年教师、新教师在被帮带期内开设，用来展示学习成果和成长，学校据此评估新教师的课堂教学水平、帮他站稳讲台。常见说法是「第一年到校教师必须上一节公开课，定名汇报课」；备课组集体磨课、师父指导、课后评课是标配流程。【确定】

- 依据：职称材料类文章对公开课/示范课/汇报课的区分（[链接](http://mp.weixin.qq.com/s?__biz=MzY4MTE0NjcwMw==&mid=2247483743&idx=1&sn=f56ad8afda11e883afe3273c5999d5ee)）；怀远三中「第一年到校教师必上一节公开课，定名汇报课」（[链接](https://www.ahhy.gov.cn/zfxxgk/public/25051/50878316.html)）；滁州实验中学「三堂课」：汇报课夯实「放心课堂」、研讨课创设「魅力课堂」、示范课构建「高效课堂」，汇报课前集体磨课、师父指导，课后教研组评课（[链接](https://www.chuzhou.gov.cn/public/152523227/1112322992.html)）。
- 淄博齐盛高中 2026 年 11 月的青年教师汇报课报道里有一句话很关键：「汇报课不是『表演课』，而是一轮复习真实战场的切片」，流程是「上课—听课—复盘—改进」闭环（[链接](http://www.zbnews.net/content/2026-11/18/content_3207044.html)）。

**（2）哈三中的「教改汇报课」**：名字里带「教改」，是学校层面的**年度教学改革成果展示活动**，不是「新教师汇报成长」。它从 1985 年开始办，2025 年是第 40 届、四十周年；官方叙述是「从『育分』到『育人』的破冰突围，从『素质教育』向『立德树人』的纵深推进，从『传统积淀』到『科技融合』的破界探索」。【确定】

- 依据：第 40 届官方报道（[链接](http://mp.weixin.qq.com/s?__biz=MjM5OTM1NDU0MQ==&mid=2652718864&idx=2&sn=54aaf07267293b3032aedb6149a527cd)）。
- 【推断】所以在这类活动里，「教龄 1.5 年」不是主要看点，**「你这节课代表哪种改法」才是**。青年教师上这种课，通常会被期待「理念新、技术敢用」，但也要接受「经验不足、生态掌控弱」的质疑——这正是主题里「课堂生态」四个字要防的。

### 1.2 与普通公开课、观摩课、赛课的区别

| 课型                     | 谁上                                | 给谁看                      | 核心目的                       | 评价重心                         | 常见风险                     |
| ------------------------ | ----------------------------------- | --------------------------- | ------------------------------ | -------------------------------- | ---------------------------- |
| 汇报课（通用）           | 青年教师/新教师                     | 教研组、师父、学校          | 展示成长、站稳讲台             | 基本功、规范、进步幅度           | 被当成「表演」               |
| **教改汇报课（哈三中）** | 各校骨干/优秀教师，常含外校同课异构 | 多校同行 + 省市教研员、专家 | **展示学校教改成果、交流理念** | **改了什么、为什么改、效果证据** | 只有「新花样」，没有「改法」 |
| 公开课                   | 任何教师                            | 同行/家长/领导              | 开放课堂、交流                 | 课堂本身是否成立                 | 目标不清、拖堂               |
| 观摩课                   | 骨干/名师                           | 来学习的人                  | 提供可模仿的范例               | 示范性、可学性                   | 学不来（脱离常态）           |
| 赛课                     | 参赛教师                            | 评委                        | 评比、区分                     | 量化打分、横向比较               | 迎合评委、过度打磨           |

【推断】一句话记：**公开课看「这节课好不好」，观摩课看「我能不能学」，赛课看「你排第几」，教改汇报课看「你改的那一刀切在哪、切出了什么」**。

### 1.3 评审通常看什么（8 个观察点 + 评委怎么看出来）

| #   | 评审看什么                                   | 评委在现场怎么看出来                                                            | 常见失分                             |
| --- | -------------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------ |
| 1   | 教学理念是否落地（课标、素养、以学生为中心） | 目标是否可测；活动是否服务目标；有没有「为活动而活动」                          | 目标写成套话，活动和目标对不上       |
| 2   | 学生主体是否真实                             | 学生说了多少、做了什么、错了教师怎么接；提问覆盖多少人                          | 教师一问一答包办，只有前排/熟脸参与  |
| 3   | 课堂生态是否良性                             | 借班有没有破冰；学生敢不敢说「我不会」；同桌/小组有没有真互助；有没有留思考时间 | 冷场、赶进度、只叫举手的             |
| 4   | 证据/数据                                    | 有没有前测后测、任务单、出口条、课堂观察数据；结论是不是「基于证据」            | 全程「我感觉学生掌握了」             |
| 5   | 数智/信息技术                                | 技术是否只出现在真难点；去掉技术课会不会变差；有没有留下数据                    | 动画/数字人/AI 抢戏，卡顿超时        |
| 6   | 教学评一体化                                 | 目标—活动—评价是否对齐；有没有当堂评价任务和即时反馈                            | 评价只有课后作业，课上无反馈         |
| 7   | 学科特质（物理）                             | 实验是否真做、数据是否真采、模型是否真建；误差怎么处理                          | 播放实验视频代替动手；数据「太完美」 |
| 8   | 反思/说课/材料                               | 能不能说清设计依据、改法、不足与改进                                            | 说课背稿、只讲流程不讲理由           |

【确定】这些观察点在公开量规里能对上：

- 《高中物理优质课评价标准》5 项 100 分：教学目标与内容设计 25（目标精准 10 / 内容逻辑 10 / 资源适配 5）、教学过程与方法 30（探究性 12 / 互动有效 10 / 时间把控 8）、学生学习状态 20（参与度 8…）；细则要求「至少 1 个完整探究环节」「学生动手或讨论 ≥10 分钟」「导入 3–5 分钟 / 探究 15–20 分钟 / 总结 3–5 分钟」「90% 学生跟上」「小组有操作员/记录员/汇报员」「无冷场 >3 分钟」（[链接](http://mp.weixin.qq.com/s?__biz=MzE5ODUwNDMxNQ==&mid=2247483762&idx=1&sn=2719eb34b995bb6531a68832f054095f)）。
- 某地高中化学课堂评价细则（2026）明确「证据优先」：**所有评分必须对应具体行为或学生表现，禁止「感觉」**；并要求「学生立场、学科特质、发展导向（至少 2 条具体改进建议）」（[链接](https://m.book118.com/html/2026/1011/7111150145011160.shtm)）。物理同理。
- 中国教育报对「学教评一体化」的报道：逆向教学设计（目标→评价任务→学习进程）、课堂观察量表、智慧课堂即时反馈/学情数据图谱（[链接](https://paper.jyb.cn/zgjyb/h5/html5/2026-01/19/content_144750_19230893.htm)）。
- 物理学科还有 RTOP 25 条观察要点（[湖南中学物理 2025(03)](https://wap.cnki.net/touch/web/Journal/Article/HNWL202503016.html)），核心就是：学生有没有真探究、教师有没有真听。

## 3. 拆解主题：「数智赋能背景下营造良性课堂生态策略探索」

### 3.1 「数智赋能」是什么

**字面**：数字化 + 智能化。用数据、算法、智能工具，给教学「加能力」。
**政策原文**（可直接引用，显得有依据）：

- 教育部等九部门《关于加快推进教育数字化的意见》（教办〔2025〕3 号）：「坚持数字赋能，推动教育理念、教学模式和教育治理整体性变革」「坚持以人为本，着力培养学生高阶思维、思考判断能力、实践能力」（[原文](https://www.gov.cn/zhengce/zhengceku/202504/content_7019045.htm)）。
- 国务院《关于深入实施「人工智能+」行动的意见》（国发〔2025〕11 号）：「把人工智能融入教育教学全要素、全过程……推动育人从知识传授为重向能力提升为本转变，加快实现大规模因材施教」（[答问稿](https://www.sz.gov.cn/hdjl/ywzsk/jyj/fwxx/jyxxh/content/post_12349138.html)）。
- 教育部等五部门《「人工智能+教育」行动计划》（2026-04-28）：构建覆盖课前、课中、课后全环节的智能应用；全面提升教师数字素养（[报道](http://fx.xwapp.moe.gov.cn/article/202604/69d8815f7940f4043dcf0750.html)）。
- 人民日报 2026-11-19：习近平总书记在全国教育大会指出「探索数字赋能大规模因材施教、创新性教学的有效途径……注重运用人工智能助力教育变革」；专家提出评价要从「凭经验打分」转向「基于证据诊断」（[原文](http://politics.people.com.cn/n1/2026/1119/c461001-40836631.html)）。

**翻译成人话**（【推断】，但和上面的政策一致）：数智赋能不是「课上放个 AI」，而是三层——

1. **呈现层**：把看不见的东西变可见（变压器里的磁通变化、漏磁、涡流）。
2. **数据层**：用前测、当堂任务单、后测、课堂观察数据，让「学生会不会」从感觉变成证据。
3. **决策层**：AI 帮你设计分层任务、诊断学情、生成变式；课堂上只做「助手」（提示、追问、记录），不替学生思考。

**判断真假数智的三个问题**（【推断】，建议说课时主动回答）：

- 去掉这个技术，这节课会变差吗？差在哪？
- 它留下了什么数据/证据？
- 它改变了你的哪个教学决策？

### 3.2 「良性课堂生态」是什么

**理论来源**：课堂是一个特殊的微观生态系统，要素是学生、教师、课程、资源和环境；健康的生态是开放的、动态的、平衡的、可持续的；生态课堂讲四观——生态本位观、信息流动观、能量交换观、可持续发展观；要「求真」（开放课程、多元资源、动态课堂）、「求善」（尊重生命、思考权、表达权）、「求美」（[顾新民《让课堂生态走向「真」「善」美》](https://fzzx.rdedu.net/UploadFiles/jyky/2019/7/201907160917544318.pdf)）。

**落到一节课，「良性」就是四对关系健康**（【推断】，但和文献里的「失衡」清单对得上）：

| 关系       | 良性长什么样                           | 失衡长什么样                     | 现场证据                     |
| ---------- | -------------------------------------- | -------------------------------- | ---------------------------- |
| 师生关系   | 安全、尊重、平等对话、允许说「我不会」 | 教师强势、只叫举手的、答错被忽略 | 借班破冰；错误被接住的片段   |
| 生生关系   | 同桌/小组真互助、有分工                | 各做各的、少数人包办             | 互查、分工卡、组内发言       |
| 学生与内容 | 难度匹配、有挑战但不挫败、负担合理     | 信息量过载、只讲难题、内容失衡   | 分层任务单；90% 学生跟得上   |
| 学生与技术 | 技术是工具，用完就退场                 | 技术抢戏、卡顿、制造新干扰       | 技术只出现 2 次、每次 ≤90 秒 |

**文献里的「失衡清单」**（可直接引用）：江苏师范大学 2012 年硕士论文《高中课堂生态问题研究》把课堂生态失衡归纳为：班级规模过大、片面追求知识信息量、多媒体技术应用失衡、人际关系失衡、师生互动失衡、教学内容失衡（[知网条目](https://cdmd.cnki.com.cn/Article/CDMD-10320-1013007697.htm)）。范淑静《构建良性的高中课堂生态》强调课堂生态是「平衡→失衡→平衡」的动态过程，可从教室布置、人际关系、教学内容入手（[知网条目](https://www.cnki.com.cn/Article/CJFDTotal-JLJY201207005.htm)）。
→ 【推断】注意「多媒体技术应用失衡」这一条：**技术用过头，本身就是生态失衡**。这正好是主题里「数智」和「生态」的张力，说课时点出来会很加分。

**借班场景的专门提醒**（这条对你最重要）：杨彦春在《中学历史教学参考》2024 年第 6 期写异地借班：「影响课堂教学效果的因素不仅是教师教学水平的高低，一定程度上也取决于异地借班授课的教师能否构建和谐融洽的师生关系，营造良性的课堂生态。」文中引李惠军的话：「师生间的陌生，是异地借班授课最大的心理隔膜，也是教师因材施教最难拿捏分寸的教学障碍。」（[维普条目](https://vip.hnadl.cn/article/detail.aspx?id=7111615306)）
→ 【推断】你这次就是异地借班。**「良性课堂生态」在你这里，第一关不是理念，是 40 分钟里让 40 个陌生学生敢开口**。

### 3.3 主题连起来怎么读（一句话）

【推断】**用数据和智能工具，让课堂里的四对关系更健康，并且拿得出证据。**

- 「数智」是手段，不是目的；
- 「良性生态」是目的，不是布景；
- 「策略探索」是要求你**说出可复制的做法**，不是只说「我用了 AI」。

### 3.4 评审可能期待的证据（分三档）

| 档位       | 证据                                                                                    | 评委反应       | 建议          |
| ---------- | --------------------------------------------------------------------------------------- | -------------- | ------------- |
| **强证据** | 前测/后测数据、学生任务单原稿、出口条原文、课堂观察量表、AI 课堂反馈报告、30 秒学生访谈 | 「这个是真的」 | 至少准备 2 样 |
| 中证据     | 教学设计里的评价任务、分层任务、板书上的学生答案、学生上台的照片/视频                   | 「有设计」     | 每环节都有    |
| 弱证据     | PPT 精美、教师口才好、「学生很活跃」、排练过的问答                                      | 「听听就好」   | 不要当主证据  |

【确定】「证据优先」不是我的发明：某地课堂评价细则明确「所有评分必须对应具体行为或学生表现，禁止『感觉』」；中国教育报报道的「学教评一体化」也强调课堂观察量表和即时反馈数据。哈三中第 40 届已经在 3 个学科用希沃课堂智能反馈系统做观察与评价分析——说明学校认这套【确定】。

### 3.5 七个常见误区（附「评委内心 OS」和破解）

| 误区                                              | 评委内心 OS                              | 怎么破                                                            |
| ------------------------------------------------- | ---------------------------------------- | ----------------------------------------------------------------- |
| 1. 为技术而技术（动画、数字人、AI 抢戏）          | 「这个动画换成一张图，课会差吗？」       | 每个技术点写一句「它解决哪个传统手段解决不了的问题」；答不上就删  |
| 2. 热闹但无学习（活动多、思维浅）                 | 「学生笑了，但学到了什么？」             | 每个活动配一个「学生必须输出的东西」（一句话、一个数、一张图）    |
| 3. AI 表演（AI 当演员，不是助手）                 | 「AI 在替学生思考，还是帮学生思考？」    | 让 AI 只做「提示、追问、记录、比对」，结论必须由学生说            |
| 4. 生态口号化（贴标签不落地）                     | 「你说的生态，具体到这节课是哪条关系？」 | 四对关系各准备 1 条证据，说不出来就不写                           |
| 5. 借班生态忽视（不预热、不了解学情、用原班默契） | 「这是借班，不是你的班」                 | 课前 10 分钟进班 + 前测 3 题 + 开场 30 秒回应学生答案             |
| 6. 数据/表现过度包装（完美数据、排练）            | 「太顺了，反而不可信」                   | 保留真实误差，把误差当教学资源（漏磁、涡流、表的内阻）            |
| 7. 被技术绑架（卡顿、超时、不会救场）             | 「投影坏了她还能上吗？」                 | 离线文件 + U 盘备份 + 打印图 + 一句「我们先看实验数据」的救场话术 |

【确定】这些批评不是空穴来风：中国教师报 2026 年 6 月《别让「表演型」公开课压垮教师》点名「动画、游戏、AI 软件等喧宾夺主，让教学沦为技术的附庸」，并批评「预制菜」「精准讨好评审体系的定制大餐」（[链接](https://www.sdetv.com.cn/edu/pc/teacher/8VR49VT2FV.html)）；《公开课莫成表演秀》把「表演化」拆成三重失真：课堂真实失真（固定提问、预设答案、筛选学生、排练互动）、教研价值失真、评价导向失真（[链接](https://yun.xgjy.cn/studio/index.php?r=studio/post/view&sid=300071&id=56477)）；张少飞《信息技术与教学融合的几点思考》说技术堆砌会造成「教师教得很『忙』，学生学得『乱』」，技术应是「赋能者」而非「负能者」，「雪中送炭」而非「锦上添花」（[链接](http://site.sxjybk.com/jsb/20251102/html/content_20251102004004.htm)）。

## 4. 对《变压器》第一课时的额外要求

### 4.1 这节课的五个硬约束

1. **40 分钟**：内容多（结构、互感、变压比、理想模型），必须做减法。【确定】
2. **借班 40 人**：不熟悉学情、没有默契、不能排练（也不该排练）。【确定】
3. **录播教室**：有摄像头/拾音/实物展台，但**操作要提前试**；录播意味着「说错的话会被留下」。【推断】
4. **演示实验为主**：可拆变压器、学生电源、多用电表。风险是「教师一个人演、学生看热闹」——公开量规要求「学生动手或讨论 ≥10 分钟」，纯演示容易不达标。【确定+推断】
5. **讲台有 220V 插座**：可以就地取材做「220V 不能直接接手机」的冲突，但**安全第一**，不要真的让学生碰市电。【推断】

【推断】内容取舍建议：第一课时聚焦「结构 → 互感 → 变压比 → 理想模型」，把「远距离输电/能量传输细节」留给第二课时；「多副线圈、动态负载」不作为第一课时重点，避免超时。

【推断】这个时间轴里「学生动手/讨论」大约 12–15 分钟（拆、读、算、互查、写），刚好压住公开量规「≥10 分钟」的线。如果学校要求分组实验，可把 10–20 min 改成「8 min 演示 + 10 min 4 人一组测电压」，但会挤掉可视化时间，需要二选一。

**按本课当前方向（教师演示 + 全班观察组/数据墙）的调整（建议版，待与课件设计合并）**

- 报告的时间轴是「教师演示 + 学生拆/读/算」的通用版；本课主方案若定为「教师演示 + 全班 6 个观察组/数据墙」，可这样落：
  - **3–10 min**：不拆 2–3 台，只在讲台拆 1 台，请 2 名学生上台指认原/副线圈与铁芯；其余学生看实物展台/大屏，避免排队。
  - **10–20 min**：6 个观察组各认领一行数据（n1/n2/U1/U2），2 名学生读数、1 名记录/算比；教师只操作、追问、板书数据，不替学生算。
  - **20–24 min**：先上「数据墙」（各组报数/贴条），再放 2 段 ≤90 秒 AI 可视化，解释「U2 为什么比理论值小」；顺序不能反。
  - **24–28 min**：直流对比 + 追问「为什么必须是变化的磁通」；**28–31** 分层任务；**31–34** 出口条；**34–37** 回扣开场；**37–40** 缓冲。
- 如果录播教室没有实物展台/摄像头可投表盘：用手机支架 + 大屏，或请前排学生看表、报数；**提前试**，不要到现场才发现看不清。
- 借班无法提前 24 小时接触学生时，报告里的「课前 24 小时前测」改为**课首 1 分钟手势投票/纸条前测**，数据仍可留；不要为了前测硬造数据。

### 4.3 五条要避免

1. **不要用 AI/动画替代真实实验。** 变压器课的说服力在「手上有物、表上有数」；可视化只在「看不见的磁通/损耗」上出现，而且要在学生产生困惑之后。【推断】
2. **不要让教师一人演示到底。** 至少 3 个学生动作：拆/指认、读数、算比值或说理由。否则「学生主体」和「探究 ≥10 分钟」两项都危险。【确定（量规）+推断】
3. **不要硬塞数字人、AI 评价员、花哨互动。** 评委对「AI 表演」很敏感；AI 只能是助手，结论必须由学生说。哈六中的提法「AI 做助手、学生做主体」可以直接借用。【确定（哈六中报道）+推断】
4. **不要忽视借班生态。** 不预热、不破冰、只叫前排/熟脸、把答案预设死——这三样在借班课上最容易暴露。也不要过度排练（借班本来也排练不了，但别把每个问题都写成「标准答案」）。【确定（杨彦春文）+推断】
5. **不要没有预案。** 实验失败、投影卡顿、超时，必须各有 B 方案：备用器材一套、预录实验视频、打印图、以及一句「我们先看数据，再解释」的救场话术。不要承诺「AI 实时评价」这种做不到的事。【推断】

### 4.4 三个说课/答辩可能被问的问题

**Q1（最可能）：「你这节课『改』了什么？和常规课的区别在哪？」**
回答骨架【推断】：

- 一句话主张：把「教师讲变压器」改成「学生用证据建构变压器模型」。
- 三个改动点：① 先猜后拆（结构自己发现）；② 用 3–4 组数据自己找规律（不是教师直接给公式）；③ 技术只在两个「看不见」的难点出现，且出现在学生有数据之后。
- 证据：前测典型错误 → 任务单完成情况 → 出口条「改变的想法」。
- 收尾：承认不足（比如分组实验时间不够），说下一步怎么改。

**Q2：「『数智』解决了什么传统手段解决不了的问题？去掉会怎样？」**
回答骨架【推断】：

- 只解决两个「看不见」：磁通变化、漏磁/涡流导致的 U₂ 偏小。
- 去掉的后果：学生只能被告知「U₂ 比理论小」，无法建立「理想模型 vs 实际器件」的差距感。
- 时机：技术出现在「学生已经测出数据、产生困惑」之后，不是开场炫技。
- 数据：前测/后测 + 课堂观察（或智能反馈报告），说明技术使用前后学生的解释质量变化。
- 主动说边界：这节课技术只占 4 分钟，其余靠实验和数据。

**Q3：「『良性课堂生态』怎么证明？借班 40 分钟你怎么建立关系？」**
回答骨架【推断】：

- 四对关系各一条证据：师生（30 秒回应前测 + 接住一个错误答案）；生生（同桌互查/小组分工）；学生与内容（三层任务单）；学生与技术（技术只出现 4 分钟，用完退场）。
- 借班做法：课前 10 分钟进班、发学习单、记住 2–3 个名字；开场用学生自己的问题；提问按「前排—中间—后排」轮转。
- 证据：出口条、任务单原稿、课堂观察记录（或 AI 课堂报告）。
- 可能的追问：「如果实验数据不理想怎么办？」——答：误差本身是教学资源（漏磁、涡流、表内阻），我会让学生解释偏差，而不是藏起来。

【确定】说课/答辩的一般规律：说 8–15 分钟 + 问 3–5 分钟；评委判断的是「设计能力、理论功底、临场反应」；常追问四类问题（[职称通](https://www.zhicheng123.cn/faq/shuoke-dabian.html)）。教资/公开课类常见追问还包括「为什么用这个视频/它带来什么教学帮助」「小组讨论有效性怎么保证、时间不够怎么办」「最大亮点是什么、怎么改进」（[题库](https://www.renrendoc.com/paper/540094476.html)）。

## 5. 如果准备时间很紧，最优先准备哪 3 件事

【推断】按「投入产出比 + 翻车风险」排序：

**第 1 件：把「教改主张」压成一句话 + 三条证据。**
教改汇报课的第一评审点是「你改了什么」。先写出一句话（例如「把教师讲结论改成学生用数据建模型」），再配三条证据（前测典型错误、任务单、出口条）。这句话要同时出现在：教学设计首页、说课第一页、板书标题、甚至课件封面。**没有这句话，后面所有准备都是散的。**

**第 2 件：把演示实验做到「一次成功、数据可读、有备份」。**
物理课的底盘是实验。提前 3 次全流程演练（含换匝数、换量程、读数时间）；备两套器材、预录一段实验视频、打印一张「理论值 vs 实测值」对照表。实验翻车，其他做得再好也救不回来。**这比多做一版动画重要 10 倍。**

**第 3 件：把「借班生态的前 10 分钟」和「证据链」做出来。**

- 前 10 分钟：课前进班 + 前测 3 题 + 开场 30 秒回应学生答案 + 记住 2–3 个名字。
- 证据链：前测 → 任务单 → 出口条 → 课后 3 题，合成 1 页。
  这两件事同时是「课堂生态」和「数智赋能」最容易拿分、也最容易被看穿的地方——真实做，成本不高；造假，评委一眼看穿。

【推断】可以往后放的：AI 课堂角色（评价员/设计顾问）——它属于加分项，不是必选项；如果时间紧，先保证「可视化 2 段 + 数据 3 张」，AI 角色可以只在说课里提一句「下一步探索」。

**如果要做 AI 角色，先过这一关**：它给的信息有没有改变你的一个教学决策（叫哪两组、补讲哪一点、换哪道题）？答不上来就不做；能答上来，再按「AI 做助手、学生做主体」设计，结论必须由学生说。哈六中的提法「AI 做助手，学生做主体」可以直接借用。

## 附录 D：本课专用证据链模板（示例，待与课件统一）

### D1 前测（3 题，课首 1 分钟手势/纸条；能提前接触学生则课前做）

1. 变压器能不能把恒定直流 6 V 变成 12 V？（能 / 不能 / 不确定）
2. 原线圈 400 匝、副线圈 200 匝，原线圈接 6 V 交流，副线圈电压最接近：3 V / 6 V / 12 V / 不确定。
3. 实际测得的副线圈电压，会比理论值偏大还是偏小？为什么？

> 答案：1 不能（恒定直流不产生持续变化的磁通，只在通断瞬间有感应）；2 3 V；3 偏小（漏磁、线圈电阻分压）。
> 目的：暴露「直流也能变压」「匝数比反了」「实际=理想」三类典型错误；上课用 30 秒回应 2–3 个真实答案。

### D2 数据墙（6 组，每组一行）

| 组号 | n1  | n2  | U1/V | U2/V（实测） | n2/n1 | U2/U1 | 与理论值偏差 | 一句话解释 |
| ---- | --- | --- | ---- | ------------ | ----- | ----- | ------------ | ---------- |
| 1    |     |     |      |              |       |       |              |            |
| 2    |     |     |      |              |       |       |              |            |
| 3    |     |     |      |              |       |       |              |            |
| 4    |     |     |      |              |       |       |              |            |
| 5    |     |     |      |              |       |       |              |            |
| 6    |     |     |      |              |       |       |              |            |

> 理论值 U2 = U1 × n2/n1；偏差来源：漏磁、线圈电阻、表计/读数；**不要修数据**，偏差是教学资源。

### D3 出口条（3 分钟）

- 今天我改变了哪个想法：______
- 我还想问的一个问题：______
- 用一句话解释：为什么实测 U2 比理论值小？______

### D4 后测（3 题，下一课时/课后）

1. 原线圈 800 匝、副线圈 200 匝，U1=12 V，理想情况下 U2=______。
2. 变压器能不能改变交流电的频率？为什么？
3. 实际变压器 U2 偏小的两个原因：******、******。

> 答案：1 3 V；2 不能（频率由电源决定）；3 漏磁、线圈电阻（铜损）——铁损更多影响效率。

### D5 说课「一句话 + 三条证据」

- **一句话主张**：把「教师讲变压器」改成「学生用课堂上测出的数据建构变压器模型」。
- **证据 1**：前测典型错误 → 出口条/后测的同题正确率变化。
- **证据 2**：6 组数据墙出现「U2 系统性偏小」，学生用漏磁/线圈压降解释。
- **证据 3**：任务单/发言中，学生从「背公式」到「用数据判断」的原话（拍照留档）。

### D6 借班破冰清单（前 10 分钟）

- 课前 10 分钟进班：发任务单、记住 2–3 个名字、问一句「你们平时物理课做实验吗？」
- 开场 30 秒：回应前测里 2–3 个真实答案（不点名批评）。
- 提问轮转：前排—中间—后排；至少给 2 个「等 30 秒」的问题。
- 安全：先接线、再检查、后通电；先最大量程、断电改线；错误不批评，说「我不会」不丢人。
