# 05 说课答辩与 1.5 年定位

> 目的：让你**不装老手、也不露怯**。评委允许年轻教师“节奏紧、生成少、追问浅”，不允许“讲错、拖堂、目标—评价脱节”。说课删形容词，改成“改动 + 证据 + 下一步”。
> 完整版在 `new-teacher` 原始报告（575 行，40 条分级来源；PDF 后半部分 / ZIP）。

---

## 一、90 秒说课稿（背下来，但别像背）

> “学生已经会用 U₁/U₂=n₁/n₂ 算题，但没看见公式背后的损耗。我把教师验证公式，改成学生用四组真实数据 + 一个气隙实验，自己走到理想模型的门口：先猜、再测、发现实测偏低、用漏磁/线圈电阻/铁芯发热解释、再建立理想模型。AI 只做看不见的 45 秒——漏磁和涡流；再加 20 秒答辩官，用本课数据追问。整节课 40 分钟，实验 9 分钟，人人有动作，出门条当堂收。”

- 说课只讲三件事：**我改了什么、为什么改、证据是什么**。
- 不念教学目标（PPT 上有）；不介绍教材（评委知道）；不堆形容词。

---

## 二、一句话主张 + 3 改法 + 3 证据

### 主张

> 把“教师验证公式”改成“学生用四组真实数据 + 一个气隙实验，自己走到理想变压器门口”。

### 3 改法

1. 教师演示、学生看 → 教师演示、全班四组读数、人人填表。
2. 误差口头提一句 → 气隙实验现场制造误差，学生解释三种损耗。
3. AI 当表演 → AI 只做看不见的 45 秒 + 20 秒答辩官。

### 3 证据

1. 任务单 4 行数据 + 气隙行；数据汇总表；读表员轮换。
2. 气隙 U₂ 从约 8 V 明显下降（预计 3–6 V）；学生说“漏磁/电阻/铁芯热”；板书右区。
3. 出门条正确率；AI 答辩官回答；当堂课首第 1 题原题再答。

---

## 三、8 个答辩问题（先写关键词，不背长句）

1. **改了什么？** 一句主张 + 3 改法。
2. **为什么这样改？** 学生公式会背不知来源；教师演示看不到内部；真实误差是资源。
3. **怎么证明有效？** 任务单 4 行 + 气隙；出门条；AI 答辩；课首第 1 题原题再答。
4. **AI 做了什么？** V1 漏磁/涡流 45 秒；V2 能量流 20 秒；AI 答辩官 20 秒；提前做好、课内播放、无现场生成。
5. **没有 AI 行不行？** 行；A 版保底；AI 是加分不是主链；去掉 AI 仍是完整实验探究课。
6. **时间不够怎么办？** 35 分钟版；砍序 V3→应用→V2→气隙→自检；数据/规律/出门条不砍。
7. **实验失败怎么办？** 双套器材 + 预录视频 + 读表员报数 + 板画；不编数据。
8. **和教材/课标什么关系？** 教材 §3.3 实验与 U₁/U₂=n₁/n₂ 是主线；3.4 只埋伏笔。

> 追问先一句话定课型：“这是一节**实验探究课**，不是概念课。”——评委的追问会跟着课型走。

## 四、1.5 年教师定位（最重要的一节）

### 1. 五个研究发现

1. **学术定位**：Berliner“新手→高级新手”（2–3 年）；官方对青年教师期待“基本功在前、创新在后”。风险不是“创新不足”，是“追创新丢基本功”。
2. **学科硬伤更致命**：北大物理学院王稼军（全国高校物理基础课青讲赛评委）原话：“一旦概念讲错，即使使用的教学方法、课堂设计再好，整个课堂教学也是失败的。”可援引“一票否决”的硬伤只有**拖堂**（王栋生《她为什么会拖堂》）；官方通知最常见硬条款是“按时上、下课”。
3. **三种反噬句式**：①“我觉得/我感觉”代替证据；②把常识包装成概念（真实情境、大单元、AI 赋能贴标签）；③把动作当目标（学生活动多=学生主体）。
4. **“可接受”有第一人称证据**：王希明（复旦附中、上海特级、正高）职初失败=内容过载+拖堂+急于展示+学情缺位；教研员对 1–2 年教师正常评价=“节奏偏紧、练习有点赶、拓展题没处理完”；《物理通报》评课文明确反对“抓住几个细节打倒整堂课，尤对年青教师”。
5. **借班最容易吃亏**：王红顺（评委身份听 60+ 节）十条“坑”的第 1 条就是“缺即兴导语、借班未破冰，前半节沉闷”；对应保底：前 3 分钟破冰 + 第一个活动低阶（绍兴柯桥“低开高走”）。

### 2. 允许 vs 不允许

| 允许（年轻教师正常） | 不允许（硬伤） |
| -------------------- | -------------- |
| 节奏偏紧             | 讲错概念       |
| 生成少               | 拖堂           |
| 追问浅               | 目标—评价脱节  |
| 例子不够花           | 编数据/假实验  |
| 偶尔紧张             | 安全事件/甩锅  |

### 3. 五条建议

1. **保底做成 A4 检查卡**：36 分钟设计 + 4 分钟缓冲；第 8/20/32 分钟三个检查点；写死“超时删哪块”；实验在录播教室原设备上试 3 遍（含断电/复电）。
2. **亮点只手选一个**，按六判据：可观察证据/低成本/40 分钟内闭合/直接对应课标/说课 90 秒讲清/失败不伤主流程。首选“**数据修正理想模型**”：400/800 实测 3.6/8.2 V 与理想值偏差 → 学生解释漏磁/线圈电阻 → 修正模型。这是《变压器》独有、评委必认的学科亮点，不依赖设备。
3. **数智只用 90 秒可视化**（磁场/磁通变化），不做互动、生成、扫码；说课引光明日报邵君（特级）“师—生—机三元协同，核心推理一律人机分离”。
4. **借班按 0 接触方案准备**（不承诺课前进班、不发学习单、不记名字）；前测/出门条/任务单降为可选，先用学校统一要求核实。
5. **说课删掉所有形容词**，改成“改动+证据+下一步”；追问先用一句话定课型（概念课/实验课）。

### 4. 三种反噬句式（说课时避开）

- ❌“我觉得/我感觉……” → ✅“数据显示/学生任务单上……”
- ❌“我用了真实情境/大单元/AI 赋能” → ✅“我改的是这一步，证据是这三条”
- ❌“学生活动很多，体现学生主体” → ✅“每个活动对应一个目标/证据”

## 五、评委心理（他们到底看什么）

1. **看“改了什么、为什么改、效果证据”**，不是“讲得顺不顺”。
2. **看学生有没有真动作**：举手、写、读、说、交；不是“教师表演”。
3. **看时间**：拖堂一票否决；40 分钟到点必须收。
4. **看 AI 是否服务难点**：去掉它课会不会变差？留下什么数据？改变哪个教学决策？
5. **看年轻教师的潜力**：基本功稳、有一个亮点、能说清证据；不要求“完美”。

### 最容易被问倒的三处

- AI 到底替代了哪一步人工？
- 数据是不是编的？
- 时间不够砍什么？

### 最加分的三个动作

- 气隙实验现场做；
- 学生自己说规律；
- 出门条当堂收。

### 最减分的三个动作

- 教师一人讲到底；
- AI 视频超过 90 秒；
- 拖堂。

## 六、说课/答辩练习（上台前 3 遍）

1. **第 1 遍**：90 秒录音，听有没有形容词/黑话；删。
2. **第 2 遍**：8 问随机抽 3 问，每题 30 秒答；录音。
3. **第 3 遍**：找同事/家人当评委，问“AI 替代了哪一步/数据是不是编的/时间不够砍什么”；答不出就改。
