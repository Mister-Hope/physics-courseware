# 04 术语表与借班（说人话，不用黑话）

> 目的：评委不会因为你不用“数据墙/出口条”扣分，但会因为你**用错层级又解释不出**扣分。这里给 26 个词的“人话版”，以及借班 0/5/10 三档的可执行方案。
> 完整 40 张术语卡在 `terms-feasibility` 原始报告（PDF 后半部分 / ZIP）。

---

## 一、先说五个被抬高的词（v1 的坑）

| 词       | 实际是什么                           | 本课怎么说                                               |
| -------- | ------------------------------------ | -------------------------------------------------------- |
| 出门条   | exit ticket 的意译；**不是官方术语** | “下课前 2 分钟写一张小条，看看谁没懂”                    |
| 量规     | 评价量表；教研常用，不是国家规定     | “4 条评价要点”/“观察表”                                  |
| 数据墙   | 自媒体/教研叫法；**官方没有**        | “实验数据汇总表”                                         |
| 教改主张 | 校本/评比话语；不是教材概念          | “我改的那一步：把教师验证公式改成学生用数据走到理想模型” |
| 证据链   | 教研常用；不是必须                   | “4 个证据：预测、数据、出门条、当堂再答”                 |

## 二、26 个术语的人话版

### A. 官方/课标词（可放心用）

| 词           | 人话                                                             |
| ------------ | ---------------------------------------------------------------- |
| 教学评一体化 | 目标、教学、评价对齐：目标说“会什么”，活动练“什么”，评价查“什么” |
| 情境         | 一个真实的、和学生有关的场景；不是贴个“生活导入”标签             |
| 核心素养     | 物理观念/科学思维/实验探究/科学态度与责任；说课点到即可，不堆    |
| 学业质量标准 | 课标对“学到什么程度”的描述；不是考试大纲                         |
| 大概念       | 能统摄一章的核心观念（如“场”）；本课不硬套                       |

### B. 教研常用词（可用，但别当文件）

| 词           | 人话                                                  |
| ------------ | ----------------------------------------------------- |
| 同课异构     | 同一课题，不同老师/不同设计                           |
| 说课         | 讲“教什么、怎么教、为什么这样教”，不是复述教案        |
| 观课议课     | 听课 + 基于证据的讨论；不是“我觉得挺好”               |
| 磨课         | 反复试上、修改                                        |
| 学习任务单   | 学生课上用的任务纸；本课叫“任务单”                    |
| 前测/后测    | 课前/课后摸底；**本课不做 24 小时前测、不做课后后测** |
| 量规         | 评价量表；本课用“4 条评价要点”                        |
| 课堂观察量表 | 听课人记录“学生动作/发言/时间”的表；不是打分表        |
| POE / PEOE   | 预测—观察—解释；PEOE 多一个“解释预测理由”             |
| 出门条       | exit ticket；本课保留但**不强制**                     |
| 数据汇总表   | 各组数据上黑板/大屏汇总；本课用这个，不用“数据墙”     |
| 数据闭环     | 数据→决策→再测；本课用“任务单→出门条→第二课时回访”    |

### C. 翻译/自媒体词（最好不用）

| 词                        | 问题                                     | 替代                     |
| ------------------------- | ---------------------------------------- | ------------------------ |
| 数智赋能                  | 教育部原文是“数字赋能”；“数智”是后来叫法 | “用 AI/数字工具做两件事” |
| 数据墙                    | 官方没有                                 | “实验数据汇总表”         |
| 出口条/出口通行证         | 翻译花样                                 | “出门条（exit ticket）”  |
| 数据驱动                  | 太大                                     | “看数据决定下一步”       |
| 底层逻辑/颗粒度/抓手/闭环 | IT 黑话                                  | 直接说动作               |

### D. 校本/自造词（对外说清“我们学校叫……”）

| 词                                             | 说明                               |
| ---------------------------------------------- | ---------------------------------- |
| 教改汇报课                                     | 哈三中年度教研活动名；不是通用概念 |
| 三育四维、三学六研                             | 校本话语；对外不展开               |
| 数智三层、生态四对关系、强/中/弱证据、教改一刀 | **自造，不要用**                   |
| 大单元/项目式/任务群/翻转课堂/跨学科           | 领域错位；本课是实验探究课，不套   |

## 三、借班 0/5/10 三档（默认 0 接触）

### 1. 0 接触（默认，最稳）

- 课首 2–3 分钟：三条公约（手势）→ 组号/角色 → “猜错不丢人” → 充电器问题（人人能答）。
- 任务单当堂发；实验全教师演示；不点名，用“第 3 组读表员”。
- 能做的：举手、写预测、读表员上台、填表、说规律、写出门条。
- 不能做：不假设能提前进班、不发学案、不做前测、不记名字。

### 2. 5 分钟（如果允许提前进班）

- 发任务单/角色卡；找 2 名志愿者预演“读数—报数”；问任课教师 3 问（学到哪、做过变压器没有、愿不愿意上台）。
- 不涉及具体教学内容；不承诺“提前讲”。

### 3. 10 分钟（如果允许更早）

- 完整预演 3 次（含断电/复电）；3 题手势前测（电压/匝数/直流）；记 3–5 个名字；两条规则；问题停车场。
- 仍不做 24 小时前测、不做课后后测。

### 4. 官方口径（别把 10 分钟当默认）

- 借班考核文件口径：学生提前 **5 分钟**进入，可适当课前交流但**不得涉及具体教学内容**。
- 所以“课前 10 分钟进班”不能当既定前提；必须问组织方。
- 三条铁律：不泄露教学内容；设计能 0 分钟兜底；数据绝不编造。
- 必问三句：学生提前几分钟到？允许接触/发单/做摸底吗？课后能否留小条？

---

## 四、证据链（4 个证据，够用）

1. **课首 1 分钟摸底**：3 个手势（电压/匝数/直流），只看起点，不算分。
2. **当堂任务单**：4 行数据 + 气隙行 + 一句规律 + 一个问题。
3. **出门条**：三行（规律/问题/自评），2 分钟写、1 分钟收。
4. **当堂最后 2 分钟课首第 1 题原题再答**：课首问“变压器能不能改变电压”，下课前用今天的数据再答一次，并写一个比值例子。

> 不做 24 小时前测、不做课后后测；如果学校要，另说。

---

## 五、不要说的词（说课/答辩）

- IT 黑话：赋能、抓手、闭环、落地、颗粒度、底层逻辑。
- 空口号：“以学生为中心”“核心素养落地”“AI 赋能全流程”“首创/创新点”“课后数据显著提升”“我的教学主张”。
- 缩写超过 2 个；自造概念不定义。
- 领域错位：任务群/大单元/项目式/翻转课堂/跨学科。
- 过度自谦/过度自信：“我还年轻，大家多指正”（可一次，不要反复）；“我首创了……”（绝对不说）。

---

## 六、PEOE 是什么（一句话）

- **P**redict 预测 → **E**xplain 解释预测理由 → **O**bserve 观察 → **E**xplain 解释观察结果。
- 第二个 E 不是“改主意”；本课简化成“先猜—再看—再说”，不贴标签也能做。

---

## 七、说课时怎么用（按层级）

| 场合     | 用什么词                                               | 不要用                       |
| -------- | ------------------------------------------------------ | ---------------------------- |
| 教学目标 | 物理观念/科学思维/实验探究/科学态度与责任；U₁/U₂=n₁/n₂ | “核心素养落地”“大概念统摄”   |
| 教学环节 | 情境、任务单、数据汇总表、出门条（解释一句）           | 数据墙、出口条、闭环         |
| 评价     | 4 条评价要点、4 个证据                                 | 量规、证据链（不解释就别用） |
| AI       | “AI 只做看不见的 45 秒 + 20 秒答辩官”                  | “AI 赋能全流程”“数智三层”    |
| 1.5 年   | “基本功在前、创新在后；我改了一步”                     | “首创/创新点/我的教学主张”   |
