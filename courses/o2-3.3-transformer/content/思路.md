# 变压器 — 授课思路

> 技术展示型常规课（第一课时，40 分钟，教师演示实验）。
> 核心思路：从 Apple Watch 磁吸充电引出互感 → 220 V 不能直充引出变压器 → 认识闭合铁芯与原/副线圈 → J2423 可拆变压器降压演示实验 → 点击驱动 3D 核心推导（原线圈用电端 $U_1=E_1+I_1r_1$、副线圈供电端 $U_2=E_2-I_2r_2$、无漏磁 $E_1/E_2=n_1/n_2$、理想化 $U_1/U_2=n_1/n_2$、功率守恒 $I_1/I_2=n_2/n_1$）→ 实际损耗（铜损、漏磁、涡流/铁损）与实测偏差回扣 → 结尾回看无线充电（耦合松散的变压器，不能当理想变压器）。

## 一、引入：从手表磁吸充电到互感（约 3–4 分钟）

- **情境与问题链**：
  1. 大家戴的智能手表平时怎么充电？（无线充电、磁吸）
  2. 没有金属插头，电是怎么隔空传过去的？（前面学过的**互感**）
  3. 3D 拆解演示（3 击）：
     - C1：手表“咔嗒”磁吸在充电盘上，屏幕亮起充电环（`磁吸 → 充电`）。
     - C2：表体变透明露出**表背线圈**，充电器剖开露出**充电器线圈**，两线圈同轴相对，中间是空气磁路。
     - C3：充电器线圈通交变电流，激发交变磁场穿过表背线圈，在手表线圈中感应出电流（`电怎么过去的？`）。
- **转折提问（P3）**：
  - 家里插座是 $220\ \text{V}$，能直接给手表充吗？不能。那充电头里先发生了什么？（先把电压降下来——引出**变压器**）

## 二、新课环节

### 环节 1：变压器的结构（P4，约 1–2 分钟，2 击）

- **初始**：剖视展示铁芯与左右两个线圈。
- **C1**：高亮左右两个线圈——接交流电源的叫**原线圈（初级）**，接负载的叫**副线圈（次级）**。
- **C2**：高亮**闭合铁芯**与内部闭合磁路——铁芯把磁通管住，使**磁通几乎全穿过两个线圈**。

### 环节 2：J2423 可拆变压器演示实验（P5，约 6–7 分钟，0 击）

- **器材与接线**：J2423 可拆变压器，原线圈 $n_1 = 1400$ 匝接 $U_1 = 12\ \text{V}$ 低压交流；副线圈取 $n_2 = 400$ 匝与 $100$ 匝（只做降压演示）。
- **安全规范**：$\le 12\ \text{V}$ 交流；先接线、再检查、后通电；多用电表先用最大量程挡；断电改线。
- **现象与追问**：学生读数、填入表格，对比理想值（$3.43\ \text{V}$、$0.86\ \text{V}$）与实测 $U_2$：
  1. $U_1/U_2$ 和 $n_1/n_2$ 有什么关系？
  2. 为什么实测 $U_2$ 总比按匝数比算出的值低一点？

### 环节 3：核心 3D 分步推导（P6，约 10–12 分钟，6 击）

- **画面与运镜设计**：
  - 0 击：整体变压器，原线圈接交流源（$U_1, n_1$），副线圈接负载（$U_2, n_2$）。
  - C1（推近左侧，变压器移到最右、右半出画）：原线圈交变电流 $I_1$ 来回流动，铁芯中出现交变磁通 $\Phi$。
  - C2（左侧推导，公式占左 2/3）：原线圈自身产生阻碍电流变化的感应电动势 $E_1 = n_1\dfrac{\Delta\Phi}{\Delta t}$，考虑线圈内阻 $r_1$，有用电端关系 $U_1 = E_1 + I_1 r_1$。
  - C3（绕竖轴旋转 $180^\circ$ 并移到最左、左半出画，公式占右 2/3）：同一磁通穿过副线圈，产生 $E_2 = n_2\dfrac{\Delta\Phi}{\Delta t}$；副线圈相当于电源，扣去内阻 $r_2$ 压降，有供电端关系 $U_2 = E_2 - I_2 r_2$。
  - C4（回看双侧磁路）：无漏磁、同一磁通 $\Phi$ 时，每匝电动势相同，得 $\dfrac{E_1}{E_2} = \dfrac{n_1}{n_2}$。
  - C5（理想化）：令内阻 $r_1 = r_2 = 0$、无漏磁、无铁损，则 $U_1 = E_1, U_2 = E_2$，得理想变压器电压比 $\dfrac{U_1}{U_2} = \dfrac{n_1}{n_2}$。
  - C6（功率与电流比）：理想变压器不损耗能量，$P_1 = P_2 \Rightarrow U_1 I_1 = U_2 I_2 \Rightarrow \dfrac{I_1}{I_2} = \dfrac{n_2}{n_1}$（单副线圈）。

### 环节 4：实际损耗与实测偏差（P7–P8，约 5 分钟）

- **P7 实际损耗（2 击）**：
  - C1：线圈有内阻发热（**铜损 $I^2 R$**），铁芯接缝有少量磁感线散出（**漏磁**）。
  - C2：铁芯交变磁场引起**涡流/铁损**（用绝缘硅钢片叠合减小）；能量关系 $P_1 = P_2 + Q_{\text{热}}$，效率 $\eta = \dfrac{P_2}{P_1}$。
- **P8 理想 vs 实测（1 击）**：
  - 0 击：$\dfrac{U_2}{U_1}$–$\dfrac{n_2}{n_1}$ 坐标图与理想直线 $\dfrac{U_2}{U_1} = \dfrac{n_2}{n_1}$。
  - C1：实测数据点落在理想直线下方一点——回扣铜损压降与漏磁。

### 环节 5：结尾回调——无线充电能当理想变压器吗？（P9，约 4–5 分钟，2 击）

- **0 击**：并排回看“手表无线充电”与“铁芯变压器”，提问：`它能当成我们刚学的理想变压器吗？`（学生先投票/回答）
- **C1**：揭晓两层答案——① 不能当理想变压器；② 物理上它仍是变压器，只是**两个线圈耦合很松散**（`空气磁路`、`漏磁大`、`没有闭合铁芯`，电压比不能直接用匝数比算）。
- **C2**：展示完整充电链路：`220 V → 适配器（降压+整流）→ 5 V DC → 充电盘（DC-AC）→ 线圈互感 → 手表整流`——真正把 $220\ \text{V}$ 降下来的是充电头（适配器）里的变压器。

## 三、课堂小结与练习（P10，约 3 分钟，0 击）

- **三句话小结**：
  1. 互感是地基；闭合铁芯把磁通管住。
  2. 无漏磁 $\rightarrow \dfrac{E_1}{E_2} = \dfrac{n_1}{n_2}$；理想（$r=0$、无漏磁、无铁损）$\rightarrow \dfrac{U_1}{U_2} = \dfrac{n_1}{n_2}$。
  3. 理想 $P_1 = P_2 \rightarrow \dfrac{I_1}{I_2} = \dfrac{n_2}{n_1}$；实际有铜损、涡流、漏磁，$U_2$ 偏低。
- **当堂两道题**：
  1. 课首原题再答：变压器能不能改变恒定直流的电压？再举一个匝数比与电压比的例子。
  2. 基础比值题：$n_1:n_2 = 5:1$，$U_1 = 10\ \text{V}$，求理想变压器副线圈电压 $U_2$。
- **课后必做（一原两副拓展）**：
  - $U_1 = 220\ \text{V}$，$n_1 = 1100$ 匝，$n_{2a} = 100$ 匝，$n_{2b} = 200$ 匝。求 $U_{2a}$、$U_{2b}$ 及比值；若 $R_a = 10\ \Omega$、$R_b = 20\ \Omega$，求两副线圈电流、功率和原线圈电流。
