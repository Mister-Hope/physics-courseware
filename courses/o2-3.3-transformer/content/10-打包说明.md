## 四、怎么生成（可复现）

### 1. 合并 Markdown

```bash
cd courses/o2-3.3-transformer/content
cat 00-先看这里.md 01-设计方案-v2.md 02-上场执行手册.md \
    03-案例与来源索引.md 04-术语表与借班.md 05-说课答辩与1.5年定位.md \
    09-原始报告索引.md 10-打包说明.md > combined.md
# 再用 pandoc 的 --metadata 加封面/目录；原始报告用 --file-scope 逐个追加
```

### 2. DOCX

```bash
# 实际用“封面 + raw openxml 分页 + 00–10 + 复核摘要 + 8 份原始报告”合并；
# 目录为手写页，未用 --toc（避免 DOCX 的 TOC 域不自动更新）。
pandoc combined.md -o 变压器公开课研究包-2026-11-20.docx
```

### 3. PDF

- 用 `office_convert` 工具：`input=...docx, format=pdf`，把返回的临时文件复制到 content 目录。
- 若 `office_convert` 不可用：macOS 备选 `textutil -convert pdf` 或 `cupsfilter`；再不行就只交付 DOCX + Markdown，PDF 在手机上用 WPS/Word 打开。
- 中文字体：DOCX 用系统字体；PDF 若出现方框，换 `--pdf-engine` 不可用，改走 Word/WPS 导出。

### 4. ZIP

```bash
zip -r 变压器公开课研究包-2026-11-20.zip \
  00-先看这里.md 01-设计方案-v2.md 02-上场执行手册.md \
  03-案例与来源索引.md 04-术语表与借班.md 05-说课答辩与1.5年定位.md \
  09-原始报告索引.md 10-打包说明.md \
  变压器公开课研究包-2026-11-20.pdf 变压器公开课研究包-2026-11-20.docx \
  原始报告/
```
