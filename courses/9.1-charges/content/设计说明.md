# 9.1 电荷 — 课件设计方案 v2

- 教材依据：`resources/textbooks/必修第三册/9-text.md` §9.1（行 11–83）、`9-question.md` §9.1 练习与应用（行 3–19）

### 1.3 与前一节 / 后一节的衔接

- **学生已有什么**：初中已学过"摩擦起电""两种电荷""同种相斥、异种相吸""验电器""导体与绝缘体"，本节第一次给出**电荷量**这个可比较、可计算的量，并把"带电"落到**电子的转移**上（行 29）。
- **下一节（9.2）要用什么**：$Q$、$q$ 的符号与单位（行 23）；电荷量是 $e$ 的整数倍（行 71）；**"完全相同的金属球接触后电荷平分"**（9.2 行 118、9-question §9.2 行 22/24）。本节只讲"平分"这一结论，**不讲** 9.2 那个"用第三个小球测作用力相等来断定电荷量相等"的实验逻辑（与 9.2 方案分工，见 §8 第 4 条）。
- **本课时学生最典型的错误理解（专门设计页去撞）**：
  1. 以为摩擦起电是"摩擦产生了正电 / 正电荷跑过去了"（→ P3 第 1 击、P8 只让电子当运动主体，正离子固定不动）；
  2. 以为"电荷量很小的电荷就是元电荷"、电荷量可以任意取值（→ P14 第 3 击、P15 滑块只能取整数、P21 练习 4）；
  3. 以为起电"创造了电荷"（→ P16 用 P11 的现象回扣：箔片张合只是自由电荷换位置）；
  4. 以为"电中和"是电荷消失了（→ P6 第 2 击按行 59、61 说清"代数和为零"）；
  5. 以为感应时电荷"铺满"导体内部（→ P11/P12 图上只用一枚净电荷标签表示两端，不铺满；"电荷只分布在外表面"属 9.4 行 311）；
  6. 以为金属屑和纸屑被吸起来的道理一样（→ P13 第 2 击专门对比）。

### 第 3 页 · 「两种电荷」（小档标题）

- 布局：`base-flex`

- 布局：`base-flex`，`half-grid` 左图右文

- 点击 1 → 右栏新增（行 27 原文）：每个原子中质子的正电荷数量与电子的负电荷数量**一样多**，所以整个原子对外界表现为**电中性**。
- 点击 2 → 右栏新增：**电中和**——等量的正、负电荷相遇会相互抵消，对外不显电性。**不是电荷消失了**：按行 59、61，电荷只是转移或重新分布，等量异种电荷合在一起时**代数和仍为零**。〔"电中和"这个说法是**教师补充内容**，教材未用此词〕

#### `FrictionChargeLab`（P8，无滑块、点击分步）

- **屏幕上长什么样**：占满左栏（viewBox 620×250）。两个圆角矩形（物体 1、2），每个 4 个正离子（红 $+$）+ 4 个自由电子（蓝 $-$）；下方一行读数（固定 3 列 grid，第 3 列从第 0 步预留）。

- **降级≠静态化**：电子飞过去的位移动画**必须保留**（复核员硬要求）。
- **不上屏的提示**：无。
