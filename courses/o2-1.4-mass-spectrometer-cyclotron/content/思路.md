## 四、组件实现约定（所有组件共通，硬约束）

1. **文件位置**：`courses/o2-1.4-mass-spectrometer-cyclotron/components/<名字>.vue`；`<script setup lang="ts">` + 模板 + `<style scoped>`。
2. **类名命名空间**：每个组件用一个概念前缀（如 `ss-`、`mg-`、`fm-`、`he-`），禁止裸词类名（`.step` / `.note` / `.map`）。
3. **色值全走 token**：`var(--c-*)`（SVG 表现属性里也合法）；透明度用 `color-mix(in srgb, var(--token) N%, transparent)`。禁止 `#hex` / `rgb()` 字面值；**SVG 属性里的颜色不能带空格**（UnoCSS attributify 会把数值当工具类，撑坏图形；dev 下看不出来，只有 build 产物中招，详见 `.agents/notes/svg-attributify-trap.md`）。
4. **圆角**：`var(--radius-*)`；胶囊 999px、正圆 50% 除外。**字号**：SVG 内按 16px 体系给 `font-size` 数字（不带单位）；HTML 层用 `.text-lg…5xl` / `.mini-note`，下限 0.65rem；别在 HTML 文本块上用 `text-6xl` 一类未定义的档位。
5. **公式**：HTML 里用 `<Latex tex="…" />`（全局注册，不用 import）；SVG 里嵌不了 KaTeX，物理量用 `font-family="KaTeX_Math" font-style="italic"`，单位用 `font-family="KaTeX_Main"`。
6. **共享组件直接用**（不用 import）：箭头 `<CourseArrow :from :to label stroke :stroke-width />`；磁场平铺 `<FieldDots :x :y :cols :rows dir="in|out" />`（裸 ×，不带圈）；单个方向记号 `<FieldMark dir label />`（**与 FieldDots 不得同图出现**）；电路元件 `<CircuitResistor>` / `<CircuitMeter kind="a|v">` / `CircuitBattery` / `CircuitSwitch` / `CircuitBulb`（导线要自己手画，止于元件两端，端点表见 `.agents/notes/electronic-symbols.md`）。**禁止手写 `<marker>`、禁止手画电阻/电表/电池/磁场叉点阵**。
7. **SVG 里不得出现空行**（空行之后元素的 SVG 命名空间会丢，静默消失）；HTML 块内缩进不要用 4 空格（会被当代码块）。
8. **数值必须由真实物理公式在 `computed` 里算**，滑块拖动时数字真实变化；不许把结果写死。
9. **交互分两类**：点组件本身播放/演示 → `@click` 触发（不占翻页）；跟着翻页逐步出现 → 用页面传入的 `:step`（本课统一用 `step` prop，不用 `$clicks` 上下文）。
10. **分步不许顶跑已可见元素**：组件内按 step 隐藏元素用 `visibility: hidden` 占位，不要用 `v-if` 把上方元素顶走（固定尺寸 SVG 内部用 `v-if` 无妨）。
11. **屏幕上不出现**：操作性提示（"拖动试试"）、给 AI/开发者的备注、emoji、学生看不到的说明文字。
12. **自验**：`pnpm exec oxlint <文件>`、`pnpm exec oxfmt <文件>` 通过；**不要启动 dev server**（`pnpm dev` / `pnpm shots` 一律不跑，避免与教师正在运行的 3030/3031 端口打架），截图与 e2e 由 Lead 统一跑。
13. 完成后回报：改了哪些文件、关键取舍、Lead 该看哪几页/哪个组件、已知不足。

## 五、组件规格（14 个）

### 1. `CoverDecorationSvg.vue`（无 props）

封面右下角装饰（`.cover-decoration` 插槽内）。内容：一片用**少量金色实心圆点**暗示的匀强磁场（3×3 或少量散点，不要 x 叉）+ 两条从同一点出发、半径不同的半圆轨迹（金色 / 蓝色）+ 轨迹上的小球（电荷）。viewBox 约 260×170、`width="300"`；整体透明度低、不抢标题。参考 `courses/o2-1.3-charged-particle-motion/components/CoverDecor.vue` 的尺寸与配色写法（但要更简洁，别堆渐变色）。类名前缀 `cd-`。

### 2. `MassSpectrometerFigure.vue`

props：`step?: number`（0–3，默认 3）、`diameters?: boolean`（默认 false）。

横向结构图（建议 viewBox 640×300）：电离室 `A`（左侧圆角小方框）→ 缝 `S_1` → 加速电场（两块平行极板 + 标注 `U`）→ 缝 `S_3` → 矩形磁场区（`<FieldDots>` 铺满，右上角标注 `B`）→ 竖直长条照相底片 `D`。
轨迹：从 A 出发的水平直线 → 进入磁场后做**半圆**（在 S₃ 处垂直进入）→ 打到 D 上；两条半圆：Ne-20 半径小、Ne-22 半径大（`r ∝ √m`），落点用短竖线 + 质量数标注。

- `step` 分步：`≥1` 出现 A + S₁；`≥2` 出现加速极板、`U`、S₃；`≥3` 出现磁场区、两条半圆轨迹、落点、底片 D。
- `diameters`：在两条半圆上各画一条直径双箭头，标注 `d_A`、`d_B`（斜体 KaTeX_Math）。

### 3. `MassSpectrometerLab.vue`（无 props，自含控件）

与第 2 项**同一套几何**（电离室、加速电场、磁场区、底片），两条半圆轨迹同时显示。控件在图下一行：

- 粒子对按钮组：`氖-20 / 氖-22`（默认）、`氢-1 / 氢-2`；
- `U` 滑块 100–2000 V（step 50，默认 1000）；
- `B` 滑块 0.05–0.5 T（step 0.01，默认 0.25）。

物理：`r = (1/B)·√(2mU/q)`，`q = 1.6×10⁻¹⁹ C`；Ne-20 `m = 20×1.66×10⁻²⁷ kg`、Ne-22 `m = 22×1.66×10⁻²⁷ kg`、H-1 `1.67×10⁻²⁷`、H-2 `3.34×10⁻²⁷`。画布内半径按比例映射（保证不滑出画面），但**必须保持 r₁/r₂ 的真实比例**，读数给真实值。

读数（`<Latex>`）：`r_1`、`r_2`、落点间距 `Δd = 2(r_2 − r_1)`（单位 mm），以及高亮的 `r_1/r_2 = √(m_1/m_2)`。
交互要点：拖 U 两条半径一起变大、间距拉开；拖 B 一起收紧；**比值始终不变**。底片落点旁标质量数。

### 4. `LinacCompareSvg.vue`（无 props，静态）

上部：多级直线加速器示意 —— 一串平行板 `P_1…P_8`，粒子沿水平直线依次穿过，每过一个加速区速度更大（用轨迹上递增的短划线/点密度表示）；下部：一条水平双向箭头标注"装置长度"。图上**不出现具体数值**。可选：右下用浅色虚线画出"粒子转圈圈可缩小装置"的轮廓。viewBox 约 620×260，类名前缀 `lc-`。

### 5. `CyclotronRun.vue`（无 props，自含控件，`@click` 播放）

俯视：两个半圆金属盒 `D_1`（左）`D_2`（右）+ 中间窄缝；盒区用 `<FieldDots>` 铺满（`dir="in"`）+ 标注 `B`；圆心处粒子源 `A`。质子参数 `m = 1.67×10⁻²⁷ kg`、`q = 1.6×10⁻¹⁹ C`，盒半径 `R = 0.5 m`（图上按比例映射）。

- 交互：点"加速"按钮 → 粒子从 A 出发画半径递增的半圆（r₁<r₂<…），每次过缝时缝隙高亮并显示 `+qU`，半径接近 R 时停止；可重来。
- 滑块：`B` 0.2–1.0 T（默认 0.5）、`U` 1–10 kV（默认 5）。
- 读数（`<Latex>`）：`r_n = mv_n/(qB)`、已获动能 `E_k = nqU`、加速次数 `n`。
- **必须体现**：`U` 只改变半径增长快慢与圈数，**不改变过缝的时间间隔**（`T = 2πm/(qB)` 与 r 无关）；建议用固定"节拍"提示（每次过缝同一处闪一下）。

### 6. `CyclotronSyncSvg.vue`（无 props，静态）

三条左右交替的半圆（`r_1 < r_2 < r_3`，圆心在同一条水平线上依次外移），每条半圆下方配一条**等长**的 `T/2` 时间条，对齐到一条水平时间轴 `t`；标注 `r_1`、`r_2`、`r_3`、`T/2`。表达"半径变大、用时不变"。类名前缀 `cs-`。

### 7. `CyclotronEnergy.vue`（无 props，自含控件）

左：D 形盒俯视 + 粒子螺旋到最外圈（半径 = 盒半径 R），标注 `R`。右：三个滑块 `B` 0.2–1.0 T（默认 0.5）、`R` 0.2–1.0 m（默认 0.5）、`U` 1–10 kV（默认 5）。质子参数同上。

三个读数（`<Latex>`，大号）：`E_{k\max} = q²B²R²/(2m)`（MeV）、`n = E_{k\max}/(qU)`（取整）、`t ≈ n·T/2 = nπm/(qB)`（μs）。
**必须体现**：拖 `U` → `n`、`t` 变而 `E_{k\max}` **不变**；拖 `B` 或 `R` → `E_{k\max}` 变。

### 8. `CyclotronFigure.vue`（无 props，静态，供 P11 题目页）

D 形盒俯视 + 粒子螺旋轨迹（4–5 圈递增半圆）+ 最外圈半径 `R` 双箭头标注（圆心到盒边缘）+ 出口（小缺口/箭头）+ 粒子源 `A`。**不画受力、不画速度箭头**，保持干净。类名前缀 `cf-`。

### 9. `RelativityLimitSvg.vue`（无 props，静态）

左右两组节拍对比：左侧（低速）三条等长的"半圆用时条"与等长的"电源周期条"逐条对齐，标`同步`（`--c-ok`）；右侧（高速）三条用时条逐条变长、电源周期条不变，第三条起错位，标`失步`（`--c-danger`）。不出现具体数值，`T` 用 KaTeX_Math 斜体。类名前缀 `rl-`。

### 10. `DeviceGallery.vue`（无 props，自含点击交互）

四张卡片横排，每张 = 装置名 + **卡片内部自绘的极简缩略 SVG**（不要引用其他组件）+ 点击后展开的一句话原理：

| 卡片         | 缩略图要素                                               | 一句话原理                            |
| ------------ | -------------------------------------------------------- | ------------------------------------- |
| 速度选择器   | 两平行板 + 竖直向下 E 箭头 + 向里磁场点 + 直线穿过的粒子 | 电场力与洛伦兹力平衡，$v=E/B$         |
| 磁流体发电机 | 两平行板 + 向里磁场点 + 水平束流 + 板上 +/−              | 正负离子被推向两板，$\varepsilon=Bvd$ |
| 电磁流量计   | 圆管剖面 + 向里磁场点 + 电极 M、N                        | $Q=\frac{\pi DU}{4B}$                 |
| 霍尔元件     | 长方体薄片 + 电流箭头 + 单个 ⊗ 记号                      | $U=aBv=\frac{IB}{nqd}$                |

交互：点卡片 → 该卡片高亮（金色描边/底色）并显示原理；再点收起；`@click`，不占翻页。类名前缀 `dg-`。

### 11. `SpeedSelectorDevice.vue`（前缀 `ss-`）

props：`mode?: "figure" | "lab"`（默认 `"lab"`）、`step?: number`（默认 0）。

几何：上下两块平行金属板（上板 `+`、下板 `−`），板间 4–5 个竖直向下的电场箭头 + 标注 `E`；板间用 `<FieldDots dir="in">` 铺满 + 标注 `B`（**有阵列就不要再画 ⊗B 图例**）；粒子从左端中线水平射入。
物理：`qvB = qE` → `v = E/B`；默认 `B = 0.5 T`、`E = 500 V/m`（→ E/B = 1000 m/s）。
lab 控件：`v` 滑块 500–2000 m/s（step 50）+ `+q` / `−q` 按钮组。
`step ≥ 1`：从**粒子几何中心**画电场力 `qE` 与洛伦兹力 `qvB` 两个箭头（长度正比大小），并显示两条大小对比条。
运动：`v = E/B` 严格水平直线穿过；`v > E/B`（+q）向上偏；`v < E/B` 向下偏；切到 `−q` 时两力同时反向、结论不变。
`mode="figure"`：只画结构（两板、E 箭头、磁场阵列、虚线路径、粒子、标注），不画受力与偏转。

### 12. `MHDGeneratorDevice.vue`（前缀 `mg-`）

props 同上。

几何：平行金属板 `A`（上）`B`（下），间距标注 `d`；板间 `<FieldDots dir="in">` + 标注 `B`；左侧喷入等离子体束（红正、蓝负小球向右运动）+ 标注 `v`。
物理：`qvB = qU/d` → `U = Bvd`；默认 `v = 1000 m/s`、`B = 0.5 T`、`d = 0.2 m` → `U = 100 V`。
lab 控件：`v` 200–2000 m/s、`B` 0.2–1.0 T、`d` 0.1–0.5 m 三个滑块 + 大号读数 `U = Bvd`。
`step≥1`：正负离子分别偏向上/下板的弯曲轨迹 + 板上 `+`／`−` 堆积；`step≥2`：板间电场箭头 + `U` 标注；`step≥3`：右侧用 `<CircuitResistor>` + 手画导线接一个电阻 `R`（外电路）。
`mode="figure"`：只有板、磁场、束流与 `v`/`B`/`d` 标注，不画偏转与堆积。

### 13. `FlowmeterDevice.vue`（前缀 `fm-`）

props 同上。

几何：一段圆形管道（立体管道或横截面圆管）标注直径 `D`；管中/管外 `<FieldDots>` + 标注 `B`；管壁左右两个电极标注 `M`、`N`，手画导线接到 `<CircuitMeter kind="v" />`（导线止于圆周）。
物理：`v = U/(BD)`、`Q = (πD²/4)·v = πDU/(4B)`；默认 `D = 0.2 m`、`B = 0.5 T`、`v = 0.02 m/s` → `U = 2.0×10⁻³ V`，`Q ≈ 6.28×10⁻⁴ m³/s`。
lab 控件：`v` 0.005–0.1 m/s、`B` 0.2–1.0 T、`D` 0.1–0.4 m；读数 `<Latex>`：`U = BDv`、`Q = πDU/(4B)`（单位 `\text{m}^3/\text{s}`）。
`step≥1`：正负离子偏向 `M`/`N` 壁的轨迹与堆积；`step≥2`：电压表出现读数 + 两壁电势高/低着色。
`mode="figure"`：只有管道、磁场、电极 `M`/`N`、电压表与 `v`/`D`/`B` 标注。

### 14. `HallElementDevice.vue`（前缀 `he-`）

props 同上。

几何：长方体薄片（透视：顶面 + 前面 + 侧面），标注长 `c`（电流方向）、宽 `a`（两侧面间距）、厚 `d`（沿磁场方向）；电流 `I` 用 `<CourseArrow>`；磁场用**单个** `<FieldMark dir="in" label="B" />`（三维薄片图，不铺满阵列）。
载流子：小球在元件内定向移动（带负电载流子蓝色 `−`、带正电载流子红色 `+`），带负电载流子的运动方向与电流方向相反。
物理：`qvB = qU/a` → `U = aBv`；又 `I = nqSv`（`S = ad`）→ `U = IB/(nqd)`。取 `a = 2.0×10⁻³ m`、`d = 5.0×10⁻⁴ m`、`n = 1.0×10²² m⁻³`、`q = 1.6×10⁻¹⁹ C`；`I` 滑块 0.5–5 mA（默认 1.6 mA）、`B` 滑块 0.1–1.0 T（默认 0.5 T）→ 默认 `U ≈ 1.0 mV`。
lab 控件：载流子按钮组（`带负电载流子` / `带正电载流子`）、`B` 滑块、`I` 滑块。
`step≥1`：载流子偏向一个侧面、另一侧面留下等量异号电荷（两面红/蓝着色 + `＋`/`−`）；`step≥2`：显示两侧面电势高/低与 `U` 读数。
**必须体现**：切换载流子正负时**电势极性翻转**。
`mode="figure"`：只有薄片、尺寸标注、电流、`B`、`I` 标注。

## 六、例题原文（P6 / P11 / P16 / P18 / P20 / P22 用）

1. **例 1（教材 1.4 练习 1）**：A、B 是两种同位素的原子核，它们具有相同的电荷、不同的质量。为测定它们的质量比，使它们从质谱仪的同一加速电场由静止开始加速，然后沿着与磁场垂直的方向进入同一匀强磁场，打到照相底片上。如果从底片上获知 A、B 在磁场中运动轨迹的直径之比是 1.08 : 1，求 A、B 的质量之比。→ `m ∝ d²`，`1.08² ≈ 1.17`。
2. **例 2（教材 1.4 练习 2）**：回旋加速器 D 形盒的半径为 r，匀强磁场的磁感应强度为 B。一个质量为 m、电荷量为 q 的粒子在加速器的中央从速度为 0 开始加速。估算粒子离开回旋加速器时获得的动能。→ `E_k = q²B²r²/(2m)`。
3. **例 3（导学案例 1，单选）**：平行板器件中 E 与 B 相互垂直，带电粒子（重力不计）从左端以速度 v 沿虚线射入后做直线运动，判断"一定带正电 / v=E/B / v>E/B 一定不能射出 / 从右端进入仍做直线运动"。→ **B**。
4. **例 4（导学案例 2 简化）**：两平行金属板 A、B 间距 d=0.2 m，板间 B=0.5 T（垂直纸面向里），等离子体以 v=1000 m/s 垂直磁场方向喷入。(1) 求电动势；(2) 哪块板是正极？→ `ε=Bvd=100 V`；由左手定则正离子偏向上板 → A 板为正极。
5. **例 5（导学案例 3 简化）**：圆形管道直径 D=0.2 m，磁场 B=0.5 T（垂直管道），测得两电极间电压 U=2.0×10⁻³ V。求流速 v 与流量 Q（π 取 3.14）。→ `v = 0.02 m/s`、`Q = 6.28×10⁻⁴ m³/s`。
6. **例 6（导学案例 4 简化，单选）**：厚度为 d 的霍尔元件，置于垂直表面的匀强磁场 B 中，通有沿长度方向的电流 I，测得两侧面电压 U。判断"增大 I 则 U 增大 / 增大 B 则 U 减小 / U 与 d 无关 / 电流反向则 U 方向不变"。→ 由 `U = IB/(nqd)`，**A**。
