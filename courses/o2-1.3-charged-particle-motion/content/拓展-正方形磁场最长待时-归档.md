## 结论速查（正方形，边长 $a$；$r=mv_0/(qB)$ 固定）

**从一条边的中点射入**

| 半径范围        | 最优构型                                                 | 最大的 $\theta$                                                                 |
| --------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------- |
| $r\le a/2$      | 轨迹圆整个装得进正方形（最大内切圆半径 $a/2$）           | 一直留在场内，时间无上界                                                        |
| $a/2<r\le 5a/8$ | 轨迹圆与对边相切（擦过角点附近射出）                     | $\pi+\arcsin\!\left(\dfrac{a}{r}-1\right)-\arccos\dfrac{a/2-\sqrt{2ar-a^2}}{r}$ |
| $r\ge 5a/8$     | 出射点取到对边的一个角点（弦最长 $=\dfrac{\sqrt5}{2}a$） | $2\arcsin\dfrac{\sqrt5\,a}{4r}$                                                 |

**从一个顶点射入**

| 半径范围     | 最优构型                                          | 最大的 $\theta$                                                      |
| ------------ | ------------------------------------------------- | -------------------------------------------------------------------- |
| $r\le a/2$   | 半圆，出射回另一条边上                            | $\pi$                                                                |
| $a/2<r\le a$ | 贴边擦入（轨迹圆在 $P$ 与入射边相切），出射在对边 | $\dfrac{\pi}{2}+\arcsin\!\left(\dfrac{a}{r}-1\right)$                |
| $r\ge a$     | 出射点取到对角顶点（弦 = 对角线 $\sqrt2 a$）      | $2\arcsin\dfrac{a}{\sqrt2\,r}$，且 $\sin\gamma=\dfrac{a}{\sqrt2\,r}$ |

- 与圆形对照：圆形里"最长弦 = 直径"总能实现，最优就是"弦过圆心"、单段公式；
  正方形有角，最长弦（指向角点）对应的弧常**穿出场区**，只有 $r$ 足够大时才可达，其余区间由"弧与边界相切 / 擦入"定出 ⟹ 必然分段。
- 两条不上屏的细节：① 边中点情形中段（$a/2<r<17a/32$）的最优弧可以是**优弧**；
  ② 顶点情形因角点几何**永远不出现优弧**（$\theta_{\max}\le\pi$）。
