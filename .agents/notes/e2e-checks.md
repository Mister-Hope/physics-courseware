# 笔记：E2E 检查（四张表 + 怎么跑）

> 什么时候读：改完课件要验证版面/交互时；或 e2e 报红要定位原因时。

```bash
E2E_COURSE=<slug> pnpm exec playwright test e2e/layout-overflow.spec.ts   # 只测一个课件（约 1.5–2 分钟）
pnpm test:e2e                                                             # 全部课件，**限流跑**（默认同时 4 个，见下）
E2E_CONCURRENCY=2 pnpm test:e2e                                           # 换并发上限（本机内存小就调小）
E2E_STRICT_STABILITY=1 E2E_STRICT_BLOCK_FIT=1 E2E_STRICT_WHITESPACE=1 …    # 严格模式：把"警告"变成失败
E2E_PAGES="14,15-17" E2E_COURSE=<slug> …                                   # 只检查指定页（支持 3 或 14,15-17）
E2E_BASE_PORT=30701 …                                                      # 只有"同一个课件"被两个进程同时跑时才需要（端口按课件固定分配，不同课件不冲突）
```

`pnpm test:e2e` 走 `scripts/e2e.ts` 的**限流调度器**：最多同时跑 `E2E_CONCURRENCY` 个课件（默认 4），跑完一个立刻补。
Playwright 的 `webServer` 会把**所有**课件的 dev server 一次性起起来（单个实测 ≈550MB，41 门会把 16GB 机器撑爆，
课件列表自动发现，**新增课件不用登记**。

自动为每个课件起 Slidev 服务，在 **1280×720（16:9）** 视口下逐页检查（画布 = 980×552 逻辑像素）。
产出（**按课件分家，多个 AI 进程同时跑不同课件不会互相覆盖/删除**，规则见 `e2e/artifacts.ts`）：

| 运行方式                                                         | 报告落在                                                                                                     |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 单课件（`E2E_COURSE=<slug>`）                                    | `courses/<slug>/.temp/layout-overflow/`：`layout-overflow.md` + `.json` + `screenshots/`（红框标出问题元素） |
| `pnpm test:e2e`（限流调度器，逐课件跑）                          | 同上：每个课件一个独立的 Playwright 进程，报告跟着课件落在各自的 `courses/<slug>/.temp/`                     |
| 手动 `pnpm exec playwright test`（会把所有 server 一次性起起来） | `e2e/reports/layout-overflow/`（只在内存够的机器上用；`pnpm shots` 等单课件命令不受影响）                    |
| `pnpm shots <slug> …`                                            | `courses/<slug>/.temp/shots/p<页号>-c<点击数>.png`（控制台打印绝对路径）                                     |

- 这些目录都已 gitignore，不用清理；**注意版面检查开跑会清空自己的报告目录**（所以它和 `shots/` 分开、单课件时也只清自己课件下的）；
- 同一个课件被两个进程同时跑时，用 `E2E_ARTIFACT_DIR=<别的路径>` 岔开产物。

## 四张表（报告里就是这四节）

| 检查                        | 口径                                                                                                                                                                                                                                                                                       | 阈值 / 开关                                                                                                   | 备注                                                                                                                                                                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **① 溢出画布**              | 元素"被祖先 overflow 裁剪后的可见矩形"是否越出 980×552；全透明（v-click 未展开）与零尺寸不计；顶栏/底栏单独查                                                                                                                                                                              | 容差 `E2E_OVERFLOW_TOLERANCE`（默认 2px，CI 用 6px 抵消 Linux 中文字体行高差异）                              | **硬失败**，不是警告                                                                                                                                                                                                                     |
| **② 上下留白**              | 量两条**边缘空白带**：顶部留白（画布顶 → 内容顶部）、底部留白（内容底部 → 画布底），任一超阈值记一条；**只看边缘**——元素少但**分散排布**（两端空白都不大、中间空一块）合格，中间的空隙一律不看（"内容"的排除口径：页面容器 / 铺满画布的元素 / 顶栏底栏 / `aria-hidden` 装饰 / 全透明元素） | `E2E_WHITESPACE_TOLERANCE`（默认 200px），**默认只警告**，`E2E_STRICT_WHITESPACE=1` 才失败                    | **只判「全部展开」**：初始态只进明细、不告警（`先问后答` 页点击前只有题干是设计使然；历史数据约 9 成告警来自初始态，全报会把真正的问题淹掉）。三种坏版面都报：挤在上半页（底部留白大）/ 挤在下半页（顶部留白大）/ 挤在中部（上下都留白） |
| **③ 点击稳定性**            | 每页从第 0 步走到 `clicksTotal`，相邻两步**都可见**的元素按稳定标识（祖先结构路径 + 语义 class/id/文本，**不含 DOM 下标**）配对，位置差 > 容差记一次位移                                                                                                                                   | `E2E_STABILITY_TOLERANCE`（默认 1px）；`E2E_STRICT_STABILITY=1` 才失败；白名单 `E2E_STABILITY_IGNORE=".a,.b"` | 报 `outermost` 根因，改它一处即可连带解决被牵连的子元素；手风琴式有意位移请加白名单                                                                                                                                                      |
| **④ 正文越出 `.page-grow`** | 可见内容元素的可见矩形 ∩ `.page-grow` padding box，**顶出上边界 / 超出下边界**超容差即记（这才能抓到"正文顶到标题上"，①抓不到）                                                                                                                                                            | `E2E_BLOCK_TOLERANCE`（默认 1px）；`E2E_STRICT_BLOCK_FIT=1` 才失败；白名单 `E2E_BLOCK_IGNORE=".a,.b"`         | 只对**用了 `.page-grow` 的课件**生效（现 41 门课正文都已用 `.page-grow`，基本全量覆盖；没用到的页面直接跳过）；有意出血/负 margin 请加白名单                                                                                             |

排除项（③④ 共用）：`.page-grow` 自身、跨页固定层（顶栏/底栏）、`aria-hidden` 纯装饰、`position:fixed`、
SVG 内部与 KaTeX 内部节点（固定画布内部换内容属正当，但 `<svg>` 根被顶跑仍会报）。

### 产物目录（按「操作」自动分家）

写 `dist/` 与 e2e 缓存的命令分三类，**各有各的目录，先后跑不会互相删文件**（`e2e/artifacts.ts` 按 `E2E_OPERATION` 派生）：

| 命令 | 产物目录（单课件） | 产物目录（多课件） |
| --- | --- | --- |
| `pnpm test:e2e`（版面检查） | `courses/<课件>/.temp/layout-overflow/` | `.e2e/layout/<范围>/` |
| `pnpm shots`（截图） | `courses/<课件>/.temp/shots/` | `e2e/reports/shots/` |
| `pnpm compare:shots` / 单页排查 | `courses/<课件>/.temp/compare/` | — |

- Playwright 自己的 `test-results/` / `html-report/` 落在 **`.e2e/<操作>/<范围>/`**（截图与版面检查各一份，互不覆盖）。
- **视口是 1920×1080**（演示屏幕常见分辨率）：Slidev 逻辑画布恒为 980×552，视口只决定缩放倍率（1920 宽 ≈ ×1.96），e2e 会按实测 scale 换算回逻辑像素 ⇒ 留白 / 位移 / 顶出的阈值口径不随视口改变。
  **换 1920 的价值已经兑现过**：它抓出了 `vh` 造成的视口相关版面（1280 下放得下、1920 下顶出 17px）——见 `slidev-layout.md` §3.6。
- **清产物**：`pnpm clean`（`--dry-run` 先看清单与体积）。删的是 `dist/`、`.e2e/`、`courses/*/.temp/`、`test-results/` 这类可再生目录，不碰源码与 `content/`。

## 其它坑（都踩过）

- **SVG `clip-path` 造成的"假越界"**：曲线点超出坐标轴范围时，`CoordAxes` 用 SVG `clip-path` 把它裁在坐标区内（屏幕上看不见），但外层 `<svg>` 是 `overflow: visible` ⇒ **路径包围盒**会探出画布，`visibleRect` 只按 CSS `overflow` 求交、**不识别 SVG clip-path**，于是报成 canvas 越界。判据：报告里元素路径是 `svg…> g:nth-of-type(N)` / `path`（不是文本块），且页面 `block-fit` 本来就是 0 ⇒ 是测量盲区，不是版面坏了。
  修法：给该页容器加 `overflow: hidden` 让测量范围=实际绘制范围（视觉零变化）；**别为此改共享组件尺寸**。
- **端口现在会自动避让**（`e2e/ports.ts`）：调度器起 server 前从基址往上找第一个**真能绑上**的端口，并打印 `↪ 端口 X 被占用（pid 进程名），改用 Y`。所以教师本机开着 dev server 撞上某个课件的默认端口也不会再 90s 超时；`E2E_BASE_PORT` 只在想整段挪开时才需要。真起不来时，调度器会直接打印该端口上监听的是谁。
- **同一台机器上不要同时跑多个 `e2e` 实例**：调度器自己的并发（默认 4）已经吃满内存，强行叠加可能导致超时，表现为**随机课件遇到 `waitForFunction` 超时假失败**。确实要并行，用不同的 `E2E_BASE_PORT` **且**把 `E2E_CONCURRENCY` 调小。
- **加载失败时 Slidev 渲染的是"带错误提示的占位页"**（`An error occurred on this slide` / `slide failed to load`）；`layout-overflow` 会识别并报 `⛔ 第 N 页渲染失败`（测试失败）。
- **不要复用已开着的 dev server**（配置里 `reuseExistingServer: false`）：Slidev 启动时解析 addon 组件，复用旧进程会拿到过期组件表，改了文件却测到旧状态
- **View Transitions**：Slidev v52 换页时整页会先平移再归位（实测可达数百像素），测完要等几何连续多帧稳定（`e2e/slidev-driver.ts` 的 `settle()`），否则把"正在入场"当溢出误报
- **`oxlint --fix` 会写坏测试文件**（vitest 插件会把 Playwright 的 `test`/`expect` 当 vitest 全局并自动插 import），所以 `e2e/` 已在 `oxlint.config.ts` 的 `ignore` 里（风格仍由 oxfmt 管）
- 新增课件目录自动纳入，无需登记；首次运行先 `pnpm test:e2e:install` 装 Chromium
- 代价：每个"页×步"约 1.3s（`nav.go` + 600ms + `settle`）——本地迭代用 `E2E_COURSE=<slug>` 只跑一个
