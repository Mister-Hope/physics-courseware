# 笔记：版面与排版（一页装得下、还不难看）

> 什么时候读：写/改 `slides.md`、`style.css` 的**版面**时。核心一句话：**"占满"但"不许溢出"**。

## 1. 每页固定结构（1.x-vectors 起的约定）

```html
# 标题

<div class="page-grow">…正文（下同）…</div>
```

- 标题 `h1` 固定在顶部；正文包一层 `.page-grow`（`flex:1; min-height:0; display:flex; flex-direction:column; justify-content:center; gap:var(--page-gap, 1.05rem)`，**共享 addon 的 `workspace/shared/styles/layout.css`**）
- 用 `.page-grow` 的页面必须挂在 **`layout: base-flex`** 上（共享 addon 的 `layouts/base-flex.vue`：
  flex 列 + 收紧内边距）；各课 headmatter 写 `defaults: { layout: base-flex }` 即可全课生效
- 纵向密度不用改规则，改 `:root` 里的 `--page-gap` / `--stack-gap` 就行（2.4-free-fall 就是 `0.7rem`）
- **内容少时垂直居中**（不留一大片底部空白），**内容多时靠 `gap`/字号/图尺寸调**
- ⚠️ **`.page-grow` 装不下时不会自动缩**：它把内容垂直居中，超出的部分**同时向上顶出**——
  第一行会叠到页面大标题上（看起来"标题和正文糊在一起"）。这正是老师两次肉眼发现、而旧检查全漏掉的问题；
  现在有专项检查（见 `e2e-checks.md` 的"正文越界"），**默认容差 1px**。

## 2. 卡片要克制（"连续叙述不用卡片，只有定义才用卡"）

只有**定义**（质点、参考系、位移这类要"立住"的一句话）才用 `.card`；提问、结论、并列条目、双栏对比、
连续叙述、习题一律不用，否则整页都是"气泡"。**一份课件卡片总数 ≤15**，实际应更少。
替代写法由共享 addon 的 `workspace/shared/styles/layout.css` 统一提供（新课件的 `style.css` **不用**再复制）：

- 提问（先问）：`.ask` —— 无卡片，加粗 + 问号立住即可
- 结论 / 定义 / 答案（后答）：`.key` —— 左侧一道强调竖线（`.key-blue` 蓝变体），比卡片轻
- 双栏对比：`.divider-l` —— 右栏加一条细分隔线
- 图标条目：纯 `text-center` 的 `div`
- 一道习题 = 题干（`.ask`）+ 选项（普通行）+ 答案（`.key`），**整题不用卡片**

> 只有一种情况要在本课 `style.css` 里重写 `.ask`：提问行是「大图标 + 一段话」两段式
> （如 `courses/1.2-time-displacement`），需要 `display: flex` 排布——纯文本行用 flex 会让行内 `<Latex/>`
> 各自变成 flex item、整行不再换行。

## 3. 常见"溢出"根因与对策

| 症状                                           | 根因                                                                                                 | 对策                                                                   |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 整页向右溢出 1000+px，e2e 报"渲染失败"         | 组件里那一行的**缩进 4 空格** → markdown 当成缩进代码块，包进 `<pre><code>`                          | `<v-clicks>` / `<v-click>` 及其子块**一律顶到第 0 列**（缩进 ≤3 空格） |
| 图"只剩空框"，路线/文字/端点全没了（还不报错） | SVG 块内**有空行** → 空行后的 `<path>/<text>` 被当 HTML 元素编译，丢了 SVG 命名空间，也不进 e2e 统计 | SVG 内部不要空行；要分组用 `<g>`                                       |
| 栅格被撑爆、整页向右溢出 2000px+               | `grid-template-columns: 1fr 1fr` 被 KaTeX 行内公式（不可断行）的 min-content 撑开                    | 写 `minmax(0, 1fr)`，并给子项 `min-width: 0; overflow-wrap: anywhere;` |
| 标题和正文糊在一起 / 底部被裁                  | 正文总高 > `.page-grow` 可用高度（见上）                                                             | 缩字号/图尺寸、精简文案、拆页；**不要硬压行距到重叠**                  |

## 4. 字号与"占满"的经验值

- 正文 22px 基准；小节标题（`.mini-title`）**必须明显大于正文**（1.28rem ≈ 28px），否则"标题比正文还小"
- 图别怕大：单图 `max-width` 常在 16–21rem 之间取值（**受该页剩余高度约束**，先用预算估一遍再动手）
- 一页内容密就拆页（老师明确说过：拆页完全可以，但不能挤成一坨）；同一标题可跨多页，不要写"（续）"
- **封面写 `layout: course-cover`**（共享布局，字段见 AGENTS.md「三」），⛔ 不要在 `slides.md` 里手写封面 HTML；**长课题名的封面要压字号**：课题名超过约 11 字时 3.5rem 会折行、渐变被截断；在该课 `style.css` 里把 `.cover-title` 压到 2.7rem 即可保持一行
- **图必须"占满"所在栏**：先估这页给图留了多少高（列宽 × 高宽比），再把 viewBox 的高宽比调到接近"可用高 ÷ 可用宽"。
  **图偏扁＝白白浪费后排的可见面积**——内容少时先放大图，而不是留白（`1.2-time-displacement` 第 13 页曾把 640×330 的图塞进 412px 宽的栏里，只渲染出 212px 高；拉成 640×420 后 264px 高，后排立刻看得清）。
- **标题只点主题、不写结论**：`# 长度的测量方式` ✅ ｜ `# 长度怎么量？——一次量到底` ❌（结论一出，学生的"想"就没了）。
- **标题要么承担信息、要么不写**（老师反复强调的一条）：
  - 写标题的唯一理由是**它本身带信息**（阶段/环节/操作名，如"器材安装""处理数据"）；
  - **引课页、向学生提问的页、纯叙述页 → 整页不写标题**，问题就写在 `.ask` 里（问题本身就是这一页的"标题"）；
  - **绝不写与封面重复的标题**：❌ `# 这节课：探究小车速度随时间变化的规律`（封面已经给了课题和章节，这行标题是零信息）；
  - 也**不写只复述阶段名的空标题**（"环节一""接下来"这类）。
  - 去掉标题顺带腾出 ~90px 竖向空间（`1.2-time-displacement` 第 11、14 页就是无标题的引课页；第 19 页也是把标题去掉后才不挤的）。
- **上屏的每一行都要有信息量**（老师原话的整理）：课件的职责是——
  ① **提出问题**（让学生对着问题想）；② **亮出核心结论**；③ 把**复杂推导的中间步骤**摆出来；④ 需要演示的**动态交互**。
  反过来，凡是**教师口头一句话就能带过的过渡句、注释性小字、对图/对表的赘述**，**一律不要上屏**：
  它们只会分散注意力、把页面变成废话。
  - 典型废话（本仓库真实踩过）："纸带记录了小车在不同时刻的位置——速度与时间的关系就藏在这条纸带里"、
    "数据挤在窄带里，直线被压平"（图自己就说明了）、"（热区已放大）"这类注释。
  - 判断口诀：**"这句话不写在屏幕上，学生就听不懂了吗？"** 不是 → 删掉，留给老师口述。
- **装饰要克制**：`.key`（左侧一条彩色竖线）只给**这一页的落点**用、**一页最多一处**；**公式、并列条目、叙述、图注一律不加框线**——
  给一个公式套彩色竖线没有传递任何信息（本仓库真实踩过：`v ≈ Δx/Δt` 被套了黄色竖线，老师直接要求去掉）。
- 一页塞两课时的内容是不允许的（一个 `courses/<slug>` = 一节课 40 分钟）；题量确实大就"一个课件、两课时"（第二课时另起 `layout: course-cover` 封面，页码接续，并在该页 frontmatter 里写自己的 `title` / `lesson`）

## 5. 量版面别靠肉眼

```bash
pnpm shots <课件> <页号> --clicks=all        # 截图看
E2E_COURSE=<课件> pnpm exec playwright test e2e/layout-overflow.spec.ts   # 逐页量
```

报告与截图都按课件分家：单课件跑 → `courses/<课件>/.temp/layout-overflow/`（含"溢出 / 留白 / 点击位移 / 正文越界"四张表），
截图 → `courses/<课件>/.temp/shots/`。细节见 `e2e-checks.md`。
