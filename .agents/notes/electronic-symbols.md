# 电路与磁场示意图符号：怎么用（读这一篇就能上手，不用看组件源码）

> 什么时候读：课件里要画**电路图**（电源 / 电阻 / 开关 / 灯泡 / 电流表 / 电压表）、**磁场图**（铺满区域的 ⊗/⊙ 阵列）、
> **带电粒子运动图**（磁场区域 + B 方向图例）时。
> 🔴 **不要再各课手画元件符号**：一律用共享 addon 的 `<CircuitBattery>` / `<CircuitResistor>` / `<CircuitSwitch>` /
> `<CircuitBulb>` / `<CircuitMeter>` / `<FieldDots>` / `<FieldMark>`（全局注册，**不用 import**；图元总则的正本见
> [shared-components.md §8](./shared-components.md#8-所有组件共同的规则)）——同一张图各课画法不一样，全仓视觉对不上（教师点名统一）。
> props 全表在第 3 节（不用读组件源码）；**导线、拐角、节点圆点、元件比例这些"组件管不到"的部分按第 4 节的手动约定画**。

## 1. 先记住五件事

1. **只能在 `<svg>` 里用**：这 7 个组件画出来的都是 `<g>`，写成 HTML 元素页面上什么都没有，也不能放进 ` ```comp `
   代码块——完整清单与原因见 [总览 §8](./shared-components.md#8-所有组件共同的规则)。写法：课件自己的 `components/*.vue` 里直接写标签，或 `slides.md` 的静态 SVG 里写。
2. **组件只画符号本身，导线由课件手画**：组件**不画任何背景 / 底板 / 托底矩形**（示意图要无缝嵌进页面）；
   导线用 `<path>` 手画，`stroke="var(--c-text)" stroke-width="1.6" fill="none" stroke-linecap="round"`，
   **止于元件两端**（电阻矩形边、开关触点、电表 / 灯泡圆周、电源极板），不穿过元件。
3. **`(x, y)` 都是"符号中心"**（导线轴线的中点）：先定回路的横竖导线，再把元件摆到线上，导线在元件处断开留空。
4. **`orientation` 说的是导线方向**：`horizontal` = 导线左右走（元件横放）、`vertical` = 导线上下走（元件竖放）；
   电池用 `flip` 换正负极朝向。极性 `+`/`−`、标签都画在 `v > 0` 一侧（水平导线时在元件**上方**、竖直导线时在**右方**），
   电动势标签自动画在另一侧，互不打架。
5. **磁场记号分两种，按用法选**：**平铺遍布区域的阵列**用 `<FieldDots>`（默认画裸 `×` / 裸 `·`，不带圈，见第 5 节）；
   **图例 / 单个方向标注**用 `<FieldMark>`（带圈 ⊙/⊗）。🔴 **两者不要同图并用**：铺满全屏的阵列与角落里的单点图例，
   说的**是同一个信息**，同时写就是重复——有 `<FieldDots>` 阵列时方向已经标清，
   再补一个角落 ⊗B 是把磁场标两遍；若为讲解刻意并置（区域 + 图例对照）也成立，按图判断。

## 2. 最短写法（一个完整回路 + 一片磁场）

```html
<svg viewBox="0 0 480 260" xmlns="http://www.w3.org/2000/svg">
  <!-- ① 导线：手画，止于每个元件两端 -->
  <g fill="none" stroke="var(--c-text)" stroke-width="1.6" stroke-linecap="round">
    <path d="M 80 70 V 122" />
    <path d="M 80 138 V 190" />
    <path d="M 80 70 H 120" />
    <path d="M 160 70 H 236" />
    <path d="M 284 70 H 400" />
    <path d="M 400 70 V 114" />
    <path d="M 400 146 V 190" />
    <path d="M 400 190 H 252" />
    <path d="M 228 190 H 80" />
  </g>
  <!-- ② 元件：写在导线的断开处，坐标给符号中心 -->
  <CircuitBattery :x="80" :y="130" orientation="vertical" polarity emf="E" />
  <CircuitSwitch :x="140" :y="70" label="S" />
  <CircuitResistor :x="260" :y="70" label="R" />
  <CircuitMeter :x="400" :y="130" kind="a" />
  <CircuitBulb :x="240" :y="190" label="L" />
  <!-- ③ 电流方向等标注最后写（在上层） -->
  <CourseArrow
    :from="{ x: 300, y: 70 }"
    :to="{ x: 380, y: 70 }"
    stroke="var(--c-accent)"
    stroke-width="2.4"
    label="I"
  />
</svg>
```

上面各段导线的端点是按**默认尺寸**算好的（改组件尺寸就要同步改导线端点）：

| 元件              | 沿导线的占位                      | 导线止于       |
| ----------------- | --------------------------------- | -------------- |
| `CircuitBattery`  | 板间距 16（极板在 y=122 / y=138） | y=122 与 y=138 |
| `CircuitSwitch`   | 触点间距 40（触点在 x=120 / 160） | x=120 与 x=160 |
| `CircuitResistor` | 长 48（x=236 … 284）              | x=236 与 x=284 |
| `CircuitMeter`    | 直径 32（r=16，y=114 … 146）      | y=114 与 y=146 |
| `CircuitBulb`     | 直径 24（r=12，x=228 … 252）      | x=228 与 x=252 |

### 配方：磁场区域（裸 × 铺满，**不要再加 ⊗B 图例**）

```html
<svg viewBox="0 0 320 220" xmlns="http://www.w3.org/2000/svg">
  <!-- 裸 × 铺满磁场区域（垂直纸面向里），不带圈；平铺阵列本身已标清方向，默认同图不再加 ⊗B -->
  <FieldDots :x="40" :y="40" :cols="10" :rows="7" dir="in" />
  <!-- 粒子 / 速度 / 力的箭头画在阵列之后（上层），不会被记号盖住 -->
  <CourseArrow
    :from="{ x: 60, y: 150 }"
    :to="{ x: 160, y: 150 }"
    stroke="#38bdf8"
    stroke-width="3.2"
    label="v"
  />
</svg>
```

- `<FieldDots>` 的 `(x, y)` 是**第一个（左上角）记号的中心**，阵列向右、向下展开，
  占位 = `(cols − 1) × spacing` × `(rows − 1) × spacing`；想在某区域里居中：
  `x = 区域左 + (区域宽 − (cols − 1) × spacing) / 2`（y 同理）。

## 3. props 一览（长度类都是 viewBox 用户单位，按 16px 体系给）

### 3.1 五个电路元件共有的 props

| prop                  | 出现在                                   | 默认              | 说明                                                                            |
| --------------------- | ---------------------------------------- | ----------------- | ------------------------------------------------------------------------------- |
| `x` / `y`             | 全部（含两个磁场组件）                   | `0` / `0`         | 符号中心（导线轴线的中点）                                                      |
| `orientation`         | 电池 / 电阻 / 开关 / 灯泡                | `horizontal`      | 导线方向：`horizontal` 左右走 / `vertical` 上下走（电表圆对称，无此项）         |
| `lineWidth`           | 全部                                     | `1.6`（磁场 1.4） | 元件线宽                                                                        |
| `color`               | 全部                                     | `var(--c-text)`   | 元件颜色（磁场组件默认 `var(--c-accent)` 暖金）                                 |
| `label`               | 电阻 / 开关 / 灯泡（`FieldMark`）        | `""`              | 标签；不传不画                                                                  |
| `labelColor`          | 电池 / 电阻 / 开关 / 灯泡                | `""`              | 标签颜色；不传跟随 `color`                                                      |
| `labelDx` / `labelDy` | 电阻 / 开关 / 灯泡（磁场记号 `labelDy`） | `0`               | 标签相对默认位置的**屏幕**偏移                                                  |
| `fill`                | 电阻 / 灯泡 / 电表                       | `none`            | 元件自身填充；**默认不画底色**，导线若必须穿过就传页面底色 `rgba(9,13,26,0.85)` |

标签字体已按学科口径内建：**纯数字走正体 `KaTeX_Main`**（阻值 `"10"`）、**其余走斜体 `KaTeX_Math`**（`"R"`、`"L"`），
开关与电表字母恒为正体 `KaTeX_Main`（`S`、`A`、`V`）——不用自己写 `<text>`。

### 3.2 `CircuitBattery`（电源：一长细＝正极、一短粗＝负极）

| prop         | 类型      | 默认    | 说明                                                                     |
| ------------ | --------- | ------- | ------------------------------------------------------------------------ |
| `flip`       | `boolean` | `false` | 沿导线镜像：长板（正极）换到另一端（正极朝右 / 朝下时用）                |
| `plateGap`   | `number`  | `16`    | 两根极板的中心距（沿导线）                                               |
| `longPlate`  | `number`  | `30`    | 长板（正极、细）长度（垂直导线）                                         |
| `shortPlate` | `number`  | `15`    | 短板（负极、粗）长度；**粗板线宽自动 = `2 × lineWidth`**                 |
| `polarity`   | `boolean` | `false` | 是否标 `+` / `−`（`+` 靠长板、`−` 靠短板、同一行；正体 `KaTeX_Main` 15） |
| `emf`        | `string`  | `""`    | 电动势标签：传 `"E"` 或 `"ℰ"`，斜体 `KaTeX_Math` 16，画在极板另一侧      |

### 3.3 `CircuitResistor`（电阻：长方形，默认 3:1、圆角 2px）

| prop        | 类型     | 默认 | 说明                                                                          |
| ----------- | -------- | ---- | ----------------------------------------------------------------------------- |
| `length`    | `number` | `48` | 沿导线的长边                                                                  |
| `thickness` | `number` | `0`  | 垂直导线的短边；`0` = 自动 `length / 3`（即默认长宽比 3:1，可按图给别的比例） |

圆角在组件里写死 `rx="2"`（不做成 prop）；这是默认样式（🟡），不是必须遵守的判据。

### 3.4 `CircuitSwitch`（开关：两触点 + 刀闸）

| prop    | 类型      | 默认   | 说明                                                      |
| ------- | --------- | ------ | --------------------------------------------------------- |
| `open`  | `boolean` | `true` | `true` ＝ 断开（刀闸抬起）；`false` ＝ 闭合（与导线重合） |
| `span`  | `number`  | `40`   | 两个触点的间距（沿导线），同时是刀闸长度                  |
| `angle` | `number`  | `30`   | 断开时刀闸与导线的夹角（度，默认 30；常用值，可调）       |

触点是实心圆 **r=3**；交互页把 `open` 绑到状态上即可（`:open="closed"`）。

### 3.5 `CircuitBulb`（灯泡：圆 + 圆内 ×，人教版）

| prop | 类型     | 默认 | 说明                                             |
| ---- | -------- | ---- | ------------------------------------------------ |
| `r`  | `number` | `12` | 圆半径（直径 24）；`×` 的四个端点落在圆周 45° 处 |

### 3.6 `CircuitMeter`（电表：圆 + 正体字母）

| prop   | 类型          | 默认 | 说明                                          |
| ------ | ------------- | ---- | --------------------------------------------- |
| `kind` | `"a"` / `"v"` | `a`  | `"a"` ＝ 电流表 **A**、`"v"` ＝ 电压表 **V**  |
| `r`    | `number`      | `16` | 圆半径（直径 32）；字母 20，正体 `KaTeX_Main` |

没有 `orientation`（圆对称）也没有 `label`；导线止于圆周即可。

### 3.7 `FieldDots`（磁场**平铺阵列**：默认裸 `×` / 裸 `·`，不带圈）

| prop            | 类型             | 默认      | 说明                                                      |
| --------------- | ---------------- | --------- | --------------------------------------------------------- |
| `x` / `y`       | `number`         | `0` / `0` | **第一个（左上角）记号的中心**                            |
| `dir`           | `"in"` / `"out"` | `in`      | `in` ＝ 垂直纸面向里（裸 `×`）；`out` ＝ 向外（裸 `·`）   |
| `cols` / `rows` | `number`         | `8` / `5` | 列数 / 行数                                               |
| `spacing`       | `number`         | `18`      | 相邻记号间距（默认 18；经验值：区域大取 24、区域小取 16） |
| `size`          | `number`         | `4`       | `×` 的半跨距（端点到中心）；`·` 的半径自动 = `size / 2`   |
| `lineWidth`     | `number`         | `1.4`     | `×` 的线宽（默认 1.4）                                    |
| `opacity`       | `number`         | `1`       | 整体透明度（压淡背景层用）                                |

### 3.8 `FieldMark`（**单个**带圈 ⊙/⊗ 记号：图例、B 方向标注）

| prop        | 类型             | 默认  | 说明                                                        |
| ----------- | ---------------- | ----- | ----------------------------------------------------------- |
| `dir`       | `"in"` / `"out"` | `in`  | `in` ＝ ⊗ 向里（圆内 `×`）；`out` ＝ ⊙ 向外（圆心实心点）   |
| `r`         | `number`         | `12`  | 带圈半径（默认 12）；`×` 半跨距 = `0.67r`、点半径 = `0.25r` |
| `lineWidth` | `number`         | `2.2` | 圈与 `×` 的线宽（比导线粗一号，远看也清楚）                 |
| `label`     | `string`         | `""`  | 记号**正下方**的字母（如 `"B"`），斜体 `KaTeX_Math`         |
| `labelSize` | `number`         | `16`  | 字号                                                        |

🔴 **只在图里没有 `<FieldDots>` 平铺阵列时才用它**——阵列已经铺满并标清了方向，再加一个角落图例就是同一个信息说两遍（见第 5 节）。
样式对齐既有画法（`o2-1.3-charged-particle-motion` 的 B 记号：r=12、线宽 2.2）——这是默认档，不是硬性规范。

## 4. 手动约定（组件管不到的部分，照这个画）

- **导线**：`stroke-width="1.6"`（与元件同宽）、`stroke-linecap="round"`、`fill="none"`；
  🟡 通常走**横平竖直**、拐角 **90° 直角**（圆角只属于元件自身的 `rx=2`）——斜导线的具体布线算有意为之，按图判断；
  🔴 **导线止于元件两端**，不穿过元件（这也是 `fill` 默认 `none` 的原因）。
- 🔴 **节点**（T 形 / 十字接线点）：实心圆点 **r = 3**、颜色同导线，只画在**确实相连**的交叉处；
  不相连的导线交叉**不点点**（点错＝电路关系错）：

  ```html
  <circle cx="240" cy="130" r="3" fill="var(--c-text)" />
  ```

- 🟡 **回路里的相对比例**（16px 体系默认值；一组尺寸尽量同步调，免得比例失衡）：

  | 元件            | 默认尺寸                                     | 与电阻长 48 之比                   |
  | --------------- | -------------------------------------------- | ---------------------------------- |
  | 电阻            | 48 × 16（长宽比 3:1、圆角 2）                | 1（基准）                          |
  | 电源            | 板间距 16、长板 30、短板 15（沿导线占位≈19） | 板间距 = 1/3，**整机明显比电阻短** |
  | 开关            | 触点间距 40（沿导线占位 40）                 | ≈ 0.83                             |
  | 电表            | 直径 32（r=16）                              | ≈ 2/3                              |
  | 灯泡            | 直径 24（r=12）                              | 1/2                                |
  | 导线 / 元件线宽 | 1.6（电源粗板 3.2、开关触点 r=3、节点 r=3）  | —                                  |

- 🟡 **电阻**：默认长宽比 3:1、圆角 2px（组件默认）；`thickness` 默认自动 = `length/3`，要别的比例也可以，按图判断。
- **开关**：断开时刀闸与导线夹角默认 **30°**（🟡 常用值，可调）；🔴 闭合时刀闸与导线**完全重合**——留缝就等于画成断开了。
- 🟡 **磁场平铺**：间距默认 **18**（`spacing`），区域大取到 24、区域小取到 16；`size=4`、`lineWidth=1.4`
  在 14~26 间距下密度都合适，一般不用跟着动。
- 🔴 **箭头与符号的层级**：**符号在下、标注在上**——先写 `<FieldDots>` 阵列与元件，再写 `<CourseArrow>` /
  `<FieldMark>` / `<text>`；带电粒子（圆 + 正负号）、束流、速度与力的箭头都画在磁场阵列**之后**，
  否则会被记号盖花、图看不清（参考 `o2-1.2-lorentz-force` 的做法：束流底下再垫一条半透明深色粗线）。
- **颜色**：元件默认 `var(--c-text)`、磁场记号默认 `var(--c-accent)`（暖金，与既有磁场页一致）；
  要区分正负可用设计系统的 `#f87171`（正）/ `#60a5fa`（负）。🔴 **SVG 属性里的颜色不能带空格**：一律写 `rgba(148,163,184,0.16)` 这种无空格形式——带空格的会被 attributify 撑坏图形，正本见 [总览 §8](./shared-components.md#8-所有组件共同的规则)。

## 5. 磁场记号的默认画法（🟡 审美与一致性，不作违规判定）

🔴 先说必须的：**别手画叉点阵**——铺满区域的阵列用 `<FieldDots>`、单点图例用 `<FieldMark>`（教师点名统一）。

🟡 下面是默认档，图上想另作安排都成立，按图判断：

- **阵列默认不画外圈**：铺满区域画**裸 `×`（向里）/ 裸 `·`（向外）**；带圈的 ⊙/⊗（`<FieldMark>`，默认 r=12）
  默认只用于"一个记号说清方向"的图例 / 标注。要表达"这片区域是向里的磁场"，默认就**只用 `<FieldDots>` 铺满**。
- **默认两类记号不同图**：有阵列时方向已经标清，再加角落 ⊗B 是把磁场标两遍；但为了讲解刻意并置
  （区域 + 图例对照）也成立。`<FieldMark>` 默认留给**图里没有平铺阵列**的场合（如纯轨迹图角落标一下 B）。

## 6. 坑速查

| 坑                                      | 记住                                                                                                                   |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 写进 HTML（不在 `<svg>` 里）            | 🔴 7 个组件都是 `<g>`，页面上什么都没有；也不能用 ` ```comp `（完整清单见总览 §8）                                     |
| 又手画了长方形 / 圆 / 两根极板 / 叉点阵 | 🔴 教师要求统一：电路元件一律 `<Circuit*>`，磁场记号一律 `<FieldDots>` / `<FieldMark>`                                 |
| 导线穿过元件                            | 🔴 导线止于元件两端（第 2 节对照表）；真要穿过就给 `fill` 传页面底色 `rgba(9,13,26,0.85)`                              |
| 磁场阵列给每个 `×` 套了圈               | 🟡 默认裸 `×` / 裸 `·`（第 5 节）；带圈只给单个图例记号                                                                |
| 磁场阵列 + 角落 ⊗B 图例同时出现         | 🟡 默认删掉 `<FieldMark>`（有阵列已标清方向）；要"区域 + 图例"对照就都留着，按图判断                                   |
| 改了元件尺寸没改导线端点                | 🔴 导线端点 = 元件边界（第 2 节对照表），同步改                                                                        |
| SVG 属性里的颜色写成 `rgb(1 2 3 / 4)`   | 🔴 attributify 把分量当工具类、撑坏图形（build 产物才暴露）；写无空格 `rgba(1,2,3,0.4)` 或 `var(--c-*)`，细节见总览 §8 |
| SVG 里出现空行                          | 🔴 空行后的元素被当 HTML 编译、**静默丢失**；组件模板里已经没有空行，往里加东西时也别加                                |
| 大 viewBox 里符号看不清                 | 🟡 这些符号按 16px 体系画（电阻长 48、电表直径 32）；viewBox 宽超过约 700 就整图缩 viewBox 或放进更窄的栏              |
