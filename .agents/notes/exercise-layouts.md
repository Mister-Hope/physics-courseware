# 笔记：题目页 / 思考页共享布局（exercise-split · focus-question）

> 什么时候读：要写"一道题占一页"的题目页、或"一个大问题长时间讨论"的思考页时。
> 两个布局都由共享 addon（`workspace/shared/layouts/`）自动注册，headmatter 里写 `layout:` 即可用。
>
> **选哪个**：有题干 + 示意图 + 解析 → `exercise-split`；整页只有一个大问题/大操作指引、学生讨论时长时间停留 → `focus-question`。

## 0. 🔴 先看这条：具名 slot 的写法

**`<template #stem>` 会被 markdown-it 转义成可见文字**（`#stem` 不是合法 HTML 属性名，
渲染成 `&lt;template #stem&gt;` 摆在屏幕上）。正确写法只有两种：

1. **`<template v-slot:stem>`**（推荐）——标签独占一行，**前后各留一个空行**，slot 内容就是正常 markdown：

   ```md
   <template v-slot:stem>

   题干内容（公式、图、v-click 都照常写）

   </template>
   ```

2. **`::stem::` 语法糖**（Slidev 内置 slot sugar）——行首写 `::stem::`，其后到下一个 `::xxx::` 之前的内容都算这个 slot：

   ```md
   ::stem::

   题干内容
   ```

   注意语法糖会把**第一个标记之前的所有内容**放进默认 slot，所以想让"解析"当默认 slot，
   要么把解析写在所有 `::` 标记之前（不直观），要么干脆用写法 1。

🟡 **写法偏好**：两种写法渲染结果一样，笔记与课件里习惯统一用写法 1（`v-slot:` 形式），可读性最好——
这条只是可读性习惯，不是渲染要求。

## 1. `exercise-split`：题目页（题干在上 + 窄图 + 解析）

**给什么页用**：一道题占一页、题干和题目图常显、解析点击分步出的例题/练习页。
题干是这一页的**主体内容**，用普通段落（整宽置顶）就好。🟡 不套 `.problem` 竖线、不包卡片是本仓库的版式习惯
（竖线只留给弱提示文字，style-guide §4）——换成别的写法不会坏页面，只是和全仓不一致。

### frontmatter 与 slot

```md
---
layout: exercise-split
---

<template v-slot:stem>

题干（常显；可含公式、图、v-click）。普通段落即可，不套 `.problem` 竖线、不包卡片（style-guide §4：题干是主体）。

</template>

<template v-slot:fig>

<InclineSvg />

</template>

解析正文（默认 slot；点击节奏自己用 v-click 控制）
```

| 位置            | 填什么                                                   | 显示时机                       |
| --------------- | -------------------------------------------------------- | ------------------------------ |
| `#stem`（具名） | 题干：文字 + 公式 + 干净题目图（若有独立图组件也可放这） | **常显**（学生第一眼就要看到） |
| `#fig`（具名）  | 示意图组件（`<XxxSvg />`），宽度自适应、通常越窄越好     | **常显**                       |
| 默认 slot       | 解析/推导步骤；用 `v-click` 分步                         | 点击逐条出                     |

**布局 props（写在页面 frontmatter 里）**：`analysisLabel`（解析区顶部那行小标签的文字，默认「解析」；想改成「解」「证明」就写它）、
`hideQaMark`（布尔，隐藏那行标签）——两者都只用在这两个标签上，不影响题干与图。

### 版面行为（写在布局组件 `<style>` 里，前缀 `ex-`）

- 🟡 顶部题干行整宽置顶；`.ex-stem` 只管版面、不挂 `.problem`——题干是主体内容，竖线只留给弱提示文字（版式习惯，非硬性）；
- 下方两栏 flex：图栏 `.ex-fig` 现在是 `width: max-content; max-width: 42%`（图按自身比例收窄，上限 42%）。
  **这个 42% 是当初调出来的经验值，不是硬指标**：要改它得动布局并重新量 e2e；写页面时能控制的是图的 `width`；
- **`#fig` 为空时自动退化**：布局用 `hasRealContent($slots.fig)` 判断（注释/纯空白不算内容），
  没图就不渲染图栏，解析栏直接吃掉整行——不会留一个空的窄栏；
- 🟡 任何栏都不加背景/圆角/边框，示意图无缝嵌入页面，靠留白与 `.fig-cap` 图注区分——加个框不会坏，只是本仓库的页面里没这么用过。
- 🟡 **题干 + 四个选项已经很吃高度时，选项里的公式用 `\tfrac` 而不是 `\dfrac`**：竖式分式会撑高行盒，选项区一高就把"解析"区顶下去（轻则越界报警、重则把解析标签顶进选项里）。真实案例：`11.2` 第 20 页那道小灯泡 I-U 图线题，四个选项 2×2 排布 + `\tfrac` 才装得下；解析里再出现同一个量时用 `\dfrac` 没问题（解析区行少）。

### 🔴 `#fig` 里的图**必须有固有尺寸**（否则整张图消失）

`.ex-fig` 的宽度是 `width: max-content`（图栏按图自己的宽度收、上限 42%）。
如果图组件根 `<svg>` **只写了 `viewBox`、没有 `width` / `height` 属性**，浏览器认为它没有确定宽度，
`max-content` 会算成 0 → **图栏塌成 0 宽、整张图直接消失**。这个坑**不报错、e2e 也抓不到**（页面上只是少了一块），
只有截图才看得见（2026-10 首次出现：7.1 第 15–18 页是 `#fig` 的第一个使用者，第一版截图整块空白）。

修法：给图组件补上与 `viewBox` 同比例的固有尺寸，**不用改共享布局**：

```html
<svg viewBox="0 0 520 300" width="340" height="196" ...></svg>
```

- `width` 不一定要等于 viewBox 宽：它同时决定图栏宽度（再受 42% 上限约束），
  想让解析栏更宽就把 `width` 收小——但**图内字号要相应放大**（渲染后 ≈ `字号 × 渲染宽 ÷ viewBox 宽`）；
- 🟡 反过来，42% 上限也可能把图压小（520 宽的图在 1280 画布下只剩约 371px），
  图内正文级标注（节气、太阳、分析标注）的经验值是 18–22px（按"最后一排看得清"给，不是规定值）；
- 图栏变宽会挤解析栏 → 解析可能"正文越界"，这两者的宽度要一起调（先量 e2e，再定 `width`）。

### 🔴 题目图先干净、分析点击后才出（物理与教学）

- **这一页第一眼必须是干净的题干 + 干净的题目图**：受力箭头、速度/加速度箭头、分力虚线等分析标注
  **一律点击后才出**（图组件加 `showForces?: boolean` / `showDecomp` 之类，把标注包进 `<g v-if="showForces">`，
  页面写 `:show-forces="$clicks >= 1"`）。理由：学生要先独立看图想题，标注提前出现等于给答案。
- **受力从几何中心出发、力只用 `F` + 角标**（$F_N$ / $F_f$ / $F_T$，不裸写 `N` / `f` / `T`）。
- 这两条的正本在 `AGENTS.md`「三·题目图与受力分析」，这里只留一句指向，细节不重复。

### 完整示例（可直接抄）

```md
---
layout: exercise-split
---

<template v-slot:stem>

物块以初速度 $v_0 = 4\,\text{m/s}$ 沿粗糙斜面上滑，斜面倾角 $\theta = 30°$，
物块与斜面间动摩擦因数 $\mu = 0.2$。求物块沿斜面上滑的最大距离 $x$。

</template>

<template v-slot:fig>

<UphillBlockSvg />

</template>

先看运动：物块沿斜面向上减速到零，加速度方向沿斜面向下。

该方向受力：重力分量 $mg\sin\theta$ 与滑动摩擦力 $F_f = \mu mg\cos\theta$ 均沿斜面向下。

<Latex tex="a = g(\sin\theta + \mu\cos\theta) = 6.7\,\text{m/s}^2" />

由 $0 - v_0^2 = -2ax$ 得 $x = \dfrac{v_0^2}{2a} \approx 1.2\,\text{m}$。
```

（解析里的三步按需包 `v-click`；题目图的常显/后出按上面「题目图先干净」那条处理，**点击前图必须是干净的**。）

## 2. `focus-question`：思考页（一个大问题占满整页）

**给什么页用**：整页只有一个大问题/大操作指引、学生讨论时**长时间停留**的页面。
🟡 不推荐"把大问题挤在上半屏、下面留一大片空"（如 10.4 第 19 页）——
这样讨论时学生视线无处落；但这是版面判断，不是硬指标，内容真需要靠上排就靠上排。

### frontmatter 与 slot

```md
---
layout: focus-question
---

<template v-slot:icon>

<mdi-lightbulb-on-outline />

</template>

弹簧测力计的示数，一定等于物体的重力吗？

<template v-slot:hint>

提示：先想想测力计倒过来测自己会怎样。

</template>

<template v-slot:answer>

只有物体静止且只受重力和拉力时，示数才等于重力。加速上升时示数大于重力（超重）。

</template>
```

| 位置                    | 填什么                                                                           | 显示时机                       |
| ----------------------- | -------------------------------------------------------------------------------- | ------------------------------ |
| 默认 slot               | 问题文字本身（默认 `.text-4xl`；整页更空时包一层 `<div class="text-5xl">` 放大） | **常显**（整页的主角）         |
| `#icon`（具名，可选）   | 大号图标 `<mdi-xxx />`（布局里兜底放大到 4rem）                                  | 常显                           |
| `#hint`（具名，可选）   | 讨论提示/操作指引                                                                | **点击后**（布局自带 v-click） |
| `#answer`（具名，可选） | 讨论结束后的解析/答案                                                            | **点击后**（再点一次）         |

### 版面行为（前缀 `fq-`）

- 布局默认整页垂直+水平居中（`.slidev-layout.focus-question` 是 flex 列 + `justify-content: center`）。
  🟡 "居中"是布局的默认行为，不是必须：**这一页本来就靠上、本来就分栏时，按内容走就好**，
  不必为了让大问题居中而把内容拆散或改回默认；
- 🟡 图标与问题文字不加背景容器（本仓库的默认做法；加个框不会坏页面，只是和别的思考页不一致）；
- 🟡 `#hint` / `#answer` 已由布局统一包 `v-click`，页面里再套一层只是多一次点击——不是错误，但通常没必要；
- 空 slot（写了 `::` 标记但没内容）自动不渲染，不留空容器。

## 3. 两个布局的共同约定

- 🔴 根元素保持 `.slidev-layout` + 自己的类名：`common.css` 的页面外壳、内边距、`.page-grow` 都按这个选择器生效，
  丢了它就不是一个合法的布局页面（页面会顶到边缘、版式全乱）；
- 🟡 内边距由 `common.css` 的 `.slidev-layout` 提供（`!important`），一般不用也不建议覆盖；
- 🟡 颜色只用 `var(--c-*)`、圆角只用 `var(--radius-*)`——跨课一致性的习惯（本批两个布局实际没用到圆角）；
- 🟡 类名前缀 `ex-` / `fq-` / `p<页号>-` 是这一批的命名习惯，**同一布局内保持一致即可，不是硬规定**；
  真正要防的是跨课碰撞，规范见 style-guide §6；
- 🟡 样式写在布局组件自己的 `<style>` 里（自包含），不动 `workspace/shared/styles/index.css`——
  共享样式一动就影响全仓课件，改前先评估；
- 验证：`pnpm shots <课件> <页号> --clicks=all` 截图自查，`E2E_COURSE=<课件> pnpm exec playwright test e2e/layout-overflow.spec.ts` 逐页量。
