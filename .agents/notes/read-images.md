# 笔记：老师发来的图片（题目照片 / 讲义截图）怎么读

> 什么时候读：老师把**手机拍的题图、卷子照片、讲义截图**丢进 `todo/` 或直接贴在对话里，要你把题目做成课件页时。
> 一句话：**图片能读，先用一句话复述题目再动手；绝不要拿"读不到图"当结论，更不要为了看图起服务、放大截图。**

## 1. 铁律：`view_image` 的返回里没有图片内容 ≠ 没有图

看到这样的返回：

```text
[Image was previously shown to you. Image URI: vscode-chat-response-resource://…/file.jpeg]
```

这是**"图已经在你的上下文里了，不用重发"**的意思，**不是报错、不是读失败**。
同一张图重复调 5 次只会拿到同样的这句话（下图内容仍然在上下文里）。

## 2. 正确流程（四步，一次成功）

1. **读一次** `view_image`，就一次。
2. **立刻复述**：把图里的**题干文字、选项、答案、图里的关键元素**写出来（写在回复或笔记里）。
   - 复述得出具体内容 ⟹ 读图**成功**，继续干活；
   - 复述不出 ⟹ 才是真的没拿到，这时候去问老师。
3. **有歧义就问**：示意图里"哪个点在上、箭头朝哪、哪条线是虚线"这类**必须准确**的细节，**一句话直接问老师**，
   比自己猜、自己试要快得多。老师明确说过：**不要为了不麻烦老师而浪费时间与成本**。
4. **上屏的图自己重画成 SVG**（照片只是**素材来源**，不是上屏素材）：
   题图一律画成 `components/XxxSvg.vue`（见 `slidev-svg.md` 与"题目图与受力分析"），
   **禁止**把照片直接嵌进 `slides.md`——清晰度、配色、字号都不可控，也无从做 `showAnalysis` 分步。

## 3. 反面教材（本项目真实踩过）

老师给了 5 张题目照片，我误判为"读不到"，然后：

| 我做的事                                     | 实际代价                               |
| -------------------------------------------- | -------------------------------------- |
| 同一张图反复调 `view_image` 5 次             | 拿到的返回一模一样，纯浪费             |
| 起一个临时 HTTP 静态服务，把图放进浏览器放大 | 多了两个进程、还得记得关               |
| 用浏览器放大 + 截图工具看图                  | **截出来严重失真**，比直接读图更差     |
| 准备让老师把 5 道题的文字**手工抄**给我      | 把我自己能干的事外包给老师，最贵的一步 |

**每次"确认读图失败"之前，先试着复述一句图里的话。** 这次一复述就发现 5 道题（题干、选项、答案）全都读得清清楚楚。

## 4. 自查

- 我复述过图里的内容了吗？（没复述过就没有资格说"读不到"）
- 同一张图我调了几次？>1 次就是错的。
- 我有没有为了看图去起服务 / 放大截图 / 换工具打捞？（有就是错的）
- 图里必须准确的几何细节，我是**问了老师**还是自己在猜？
