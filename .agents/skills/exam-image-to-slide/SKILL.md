# 题目照片 → 课件页

## 一、先复述，再动手（最重要的纪律）

读图后**先用一两句话复述**你看到的具体内容（题干条件、图里哪个点在上、箭头朝哪、哪条线是虚线）。
- 复述得出 → 说明图读到了，继续干活，**不要再反复读同一张图**；
- 复述不出 → 才是真没拿到，这时去问老师。
- **有歧义就问**：图里必须准确的细节（左右、方向、实线虚线、数值）**一句话直接问老师**，比自己猜、自己试快得多。
  老师明确说过：**不要为了不麻烦老师而浪费时间和成本。**

## 二、判断：重画还是嵌原图

**题目必须带图**（只有题干没有图 = 学生第一眼看不到题）。默认**重画成 SVG**：清晰、配色与字号可控、能做点击分步与图内标注。
但**不要一刀切禁止嵌原图**：个别**难以重画**的题图（真实照片——极光、实拍装置、天文照片）**直接嵌原图才是对的**，代价是投影偏糊、做不了分步标注。

判据：**能画得像样的就画**（示意图 / 几何图 / 受力图 / 坐标图一律画）；**画不像的实拍图就嵌**（放 `courses/<slug>/images/`，`<img src="./images/xxx.png" />`）。
画图一律用共享组件、别手画 —— 加载 `physics-figure` skill 走那套流程。

## 三、拆页与出图

1. **判断题量**：一个 `courses/<slug>` = 一节课（40 分钟）。题量大就拆成多页，或做成"一个课件、两课时"（第二课时另起 `course-cover` 封面，页码接续）。
2. **题目页**用 `layout: exercise-split`（一道题占一页）；一个大问题长时间讨论用 `focus-question`。
   具名 slot **不能**写成 `<template #stem>`（写错整页坏）→ 读 [exercise-layouts.md](../../notes/exercise-layouts.md) ⭐。
3. **题图组件**加 `showForces?: boolean`（分解图用 `showDecomp`），把分析类标注包进 `<g v-if="…">`，页面写 `:show-forces="$clicks >= 1"`。
   **题干类元素常显**：物体、斜面/地面、绳与弹簧、倾角 $\theta$、物体标签、题目已给的速度 $v$、"剪断/撤去""$F_T=?\ $" 这类设问。
   ⛔ 受力分析、速度/加速度箭头、分力虚线、辅助线、答案**都必须点击之后才出现**。
4. **配套文字**：符号与单位一律走 LaTeX（`<Latex tex="v_0" />`，不写 `v₀`/`θ`/`m/s²`）；题干里给的条件要和图上一致。
5. 拿不准的物理表述查 `resources/textbooks/` 对应章节，**以教材为准**。

## 四、自检

```bash
pnpm slide <slug> --grep <题干里的关键词>   # 定位到页
pnpm shots <slug> <页号>                     # 未点击态：必须是干净题干 + 干净题图
pnpm shots <slug> <页号> --clicks=each       # 每一次点击后各一张，确认分析类标注是"点出来"的
E2E_COURSE=<slug> pnpm exec playwright test e2e/layout-overflow.spec.ts
```

## 五、汇报口径

说清：**哪几张照片 → 做成了哪几页**、每张学到了什么（复述句）、哪些**重画**了、哪些**嵌原图**及原因、
哪些地方按老师口径做了取舍；有歧义没解决的点单独列出来问。备注（"热区已放大"这类）**绝不写进课件**，写 `content/` 或代码注释。
